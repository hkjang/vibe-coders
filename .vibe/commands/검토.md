다음 코드를 시니어 엔지니어의 시각으로 PR 리뷰처럼 검토해 주세요.

검토 영역:
- 정확성 (논리 오류, 누락된 케이스)
- 가독성 (이름, 구조, 주석)
- 성능 (병목, O 복잡도)
- 보안 (입력 검증, 인증, 데이터 노출)
- 일관성 (코드베이스 컨벤션, 기존 패턴)

각 발견사항을 다음 형식으로:
`[심각도] 파일:라인 — 요지`

심각도: blocker / major / minor / nit

직접 수정하지 말고 리뷰 코멘트만 작성. 한국어 격식체.
