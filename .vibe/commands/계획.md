---
description: 큰 작업을 시작하기 전 단계별 계획서를 .vibe-code/plans/ 에 저장합니다.
---

다음 절차를 따르세요.

1. 사용자의 요청을 분석해 큰 작업이라고 판단되면 (3개 이상의 단계, 여러 파일 수정, 1시간 이상 예상) 먼저 계획서를 작성합니다.

2. 계획서 형식:

```markdown
# 계획: <한 줄 요약>

작성일: <YYYY-MM-DD HH:MM>
예상 소요: <분 단위>
영향 범위: <파일/모듈 목록>

## 목적
<왜 이 작업을 하는지>

## 단계
1. [ ] <단계 1>
2. [ ] <단계 2>
3. [ ] <단계 3>
...

## 위험 요소
- <망가질 수 있는 부분>
- <롤백 방법>

## 완료 기준
- <어떻게 끝났다고 판단할지>
```

3. 계획서 파일 경로: `.vibe-code/plans/<YYYY-MM-DD>-<slug>.md`
   - slug는 작업의 핵심을 영문/한글 8단어 이내로 압축

4. 계획서를 작성한 후 사용자에게 보여주고 승인 받은 후 단계 1부터 실행 시작.

5. 각 단계가 완료될 때마다 계획서의 체크박스를 `[x]` 로 갱신.

6. 작업 중 계획이 바뀌면 계획서에 "변경 로그" 섹션을 추가해 사유와 함께 기록.

7. 작업 완료 후:
   - 계획서 상단에 `상태: 완료` 추가
   - 실제 소요 시간 기록
   - 다음 작업자를 위한 노트가 있으면 끝에 추가

이 계획서들은 나중에 비슷한 작업을 할 때 참조하거나, 작업 후 회고 시 사용합니다.
