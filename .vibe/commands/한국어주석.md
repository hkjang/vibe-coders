다음 코드의 모든 함수/클래스/주요 변수에 언어별 표준 주석을 한국어로 추가해 주세요.

- JavaScript/TypeScript → JSDoc
- Python → docstring (Google 스타일)
- Java/Kotlin → KDoc/Javadoc
- Go → // 한 줄 주석 (godoc 스타일)
- Rust → /// doc comment

주석 내용:
- 함수 목적 (한 문장)
- @param/매개변수 (이름, 타입, 의미)
- @returns/반환값
- @throws/예외 (있는 경우)
- 사용 예시 1개 (간단한 경우만)

코드 동작은 변경하지 마세요.
