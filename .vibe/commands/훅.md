---
description: Git 훅(pre-commit, commit-msg)을 설치하고 검증합니다.
---

다음 절차로 Git 훅을 설치합니다.

1. **`.husky/` 또는 `.git/hooks/` 위치 확인** — `package.json` 의 `husky` 의존성 또는 `simple-git-hooks` 확인. 이미 husky 가 설치되어 있으면 husky 경로 사용.

2. **권장 훅 구성**:

```bash
# .husky/pre-commit (또는 .git/hooks/pre-commit)
#!/bin/sh
. "$(dirname "$0")/_/husky.sh" 2>/dev/null || true

# 1. 시크릿 검사 (커밋 차단)
if git diff --cached --name-only | xargs -I {} grep -lE '(AKIA[0-9A-Z]{16}|sk-[A-Za-z0-9]{20,}|ghp_[A-Za-z0-9]{36}|BEGIN (RSA|EC|OPENSSH) PRIVATE KEY|\d{6}-[1-4]\d{6})' {} 2>/dev/null; then
  echo "❌ 시크릿 패턴 감지 — 커밋 차단됨"
  exit 1
fi

# 2. 린트 (있으면)
if [ -f package.json ] && grep -q '"lint"' package.json; then
  npm run lint --silent || exit 1
fi

# 3. 타입 체크 (TypeScript)
if [ -f tsconfig.json ]; then
  npx --no-install tsc --noEmit 2>/dev/null || true
fi

# 4. 빠른 테스트 (선택)
# npm test --silent
```

3. **commit-msg 훅으로 메시지 검증**:

```bash
# .husky/commit-msg
#!/bin/sh
MSG_FILE="$1"
MSG=$(cat "$MSG_FILE")

# conventional commit 형식 강제 (한국어 본문 허용)
if ! echo "$MSG" | head -n 1 | grep -qE '^(feat|fix|refactor|perf|test|docs|chore|style|build|ci|revert)(\(.+\))?:\s.+'; then
  echo "❌ 커밋 메시지 형식: type: 요약 (예: feat: 사용자 인증 추가)"
  exit 1
fi
```

4. **권한 부여**: `chmod +x .husky/pre-commit .husky/commit-msg` (Windows 는 `git update-index --chmod=+x`).

5. **테스트**: 임시 파일 변경 후 `git commit` 시도하여 훅이 동작하는지 확인.

주의:
- 사용자가 `--no-verify` 로 우회할 수 있음을 안내
- 훅 추가 전 기존 훅 백업 (`cp pre-commit pre-commit.backup`)
- **인터넷 가용 시**: husky 가 없으면 설치 명령(`npm i -D husky && npx husky init`) 안내 후 사용자 승인 받기
- **폐쇄망**: husky 의존 없이 순수 `.git/hooks/pre-commit` 파일만 직접 작성. 사내 npm registry 가 있으면 거기서 설치 가능.

사용자에게 어떤 훅을 설치할지, 그리고 인터넷 / 사내 registry 가용 여부를 먼저 확인하세요.
