# 감사 기록 조회와 CSV 다운로드

v0.86.150 개발 후보는 시스템 설정의 **변경 이력**에서 감사 CSV를 공통 인증·오류 처리로 내려받는다. 조회 전용 운영자도 기존 관리자 조회 권한이 있으면 사용할 수 있다.

다운로드 준비 중에는 중복 요청을 막고 한글 진행 안내와 취소 버튼을 제공한다. 다운로드 완료는 브라우저에 파일 저장을 시작한 상태를 뜻한다. 감사 기록과 알림 기록을 각각 최대 5,000건 요청하므로 합계는 최대 10,000건이다. 화면의 표시 건수와는 별도이며 현재 서버 상태를 조회한다. CSV는 기존 여섯 열·정렬·권한별 마스킹·UTF-8 BOM을 유지한다.

화면 이동, 계정·팀·역할·원문 조회 권한·세션 변경과 최종 조회 거부 시 이전 요청과 기록 캐시를 폐기한다. 취소된 요청의 늦은 응답은 파일을 만들지 않는다. 실패하면 안전한 오류 안내와 요청 ID를 표시하고 사용자가 재시도한다. 인증 만료는 기존 공통 클라이언트의 단일 갱신 흐름을 재사용한다. 직접 작성한 인증 헤더나 별도 업무 API를 추가하지 않는다.

서버는 감사·알림의 텍스트 필드를 기존 CSV 수식 보호 함수로 처리한다. 인증 및 원문 조회 권한의 투영은 그대로 유지하며 마스킹 후 수식 보호를 적용한다. GET 외 요청은 405를 반환하고 성공·실패 응답을 저장하지 않도록 no-store를 사용한다. 저장소 오류의 내부 정보는 응답에 담지 않는다. OpenAPI는 기존 CSV 경로의 조회 한도·텍스트 응답·오류를 명시한다.

화면 종료 뒤 늦게 도착한 응답이 다운로드를 시작하는 문제와 CSV 수식 보호 누락을 수정 전 실패로 재현했다. 전체 React 6,549개(464개 파일)와 기본 Node 검사 57개를 통과했으며 외부 산출물 선택 검사 15개는 기본 Node 명령에서 제외된다. 이후 취소 후 키보드 초점과 감사 화면 제목 단계를 보완한 최종 소스에서 관련 React/API 856개와 운영 CSP·내장 Go 서버 기반 브라우저·시각·키보드·접근성 회귀 94개를 통과했다. 최종 브라우저 검사는 기준 이미지 갱신·재시도·건너뜀·불안정 결과 없이 실행했으며, 관리 API는 공개 합성 응답을 사용한다. 새 기준 이미지 8장을 직접 확인했고 기존 이미지는 변경하지 않았다. 실제 HTTP 처리기·저장소·원문 권한·CSV 값은 SQLite 및 격리 PostgreSQL 17 race 14개로 별도 검증했다. 전체 Go 테스트·vet·API 표면(423 서버 경로/482 OpenAPI/369 React 연결), 실제 Go OpenAPI 생성 계약·린트·포맷·타입·빌드·번들 예산·통합 SBOM 19 Go/389 npm 패키지를 확인했다. 최종 초기 전송 크기는 268,016바이트다.

이 후보의 운영 Preview·Stable 승격, 선행 공개 릴리즈·후보 CI·독립 리뷰·메인 CI와 최종 공개 파일 검증은 별도 절차다. 기존 `/admin`과 `/app`의 병행 운영을 유지하며 전체 Phase 0–6 인수는 계속 진행한다.
