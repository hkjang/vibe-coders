# 인증 시작 설정 확인

**시스템 설정 → 런타임 설정 → 범주: 인증 · 시작 환경**에서 현재 파드가 시작할 때 읽은 인증 설정을 확인합니다. 한글 이름이나 설정 키로 검색하고 상세 주소를 공유할 수 있습니다.

| 항목 | 환경변수 | 의미 |
| --- | --- | --- |
| 계정 인증 사용 | `AUTH_ENABLED` | 계정 인증 모드 사용 여부. 실제 SSO·로컬 로그인 허용은 SSO 설정도 확인합니다. |
| 접근 토큰 유효기간 | `AUTH_ACCESS_TOKEN_TTL` | 새 접근 토큰의 유효기간. `15m0s`는 15분입니다. |
| 갱신 토큰 유효기간 | `AUTH_REFRESH_TOKEN_TTL` | 갱신 토큰·로그인 세션 유효기간. `168h0m0s`는 7일입니다. |
| JWT 서명 키 설정 여부 | `AUTH_JWT_SECRET` | 설정 여부만 표시합니다. 키 자체는 응답하지 않습니다. |
| 개인 API 키 관리 허용 | `SELF_SERVICE_KEYS_ENABLED` | 자신의 키 관리 허용 여부. 발급 권한은 기존 역할 범위를 따릅니다. |

모두 읽기 전용입니다. 변경은 배포 환경에서 적용하고 파드를 재시작해야 합니다. 기존 토큰·세션의 만료시각은 유효기간 설정 변경으로 소급 변경되지 않습니다. 서명 키 교체는 기존 로그인에 영향을 줍니다. 화면은 새로운 인증 방식이나 키 교체 기능을 만들지 않습니다.

기존 `/admin/settings`와 `/admin/settings/effective`가 같은 시작 설정을 제공합니다. 과거 DB에 읽기 전용 키의 값이 남아 있어도 실행값·출처·변경 가능 여부로 표시하지 않으며, DB 기록 자체는 변경하지 않습니다. 읽기 전용 키의 개별 변경은 기존 405, 일괄 변경·가져오기는 기존 검증 거부 동작을 유지합니다. 환경변수에 없는 값은 서버가 적용한 기본값이며, 현재 실행 중인 파드의 값입니다.

후보 검증에는 실제 HTTP 응답의 인증·비밀값 비노출·과거 DB 값 무시·혼합 일괄 변경의 원자적 거부, React 검색·읽기 전용 상세, Go embed 기반 브라우저의 실제 응답·주소 복원·키보드·좁은 표·명암 대비를 포함합니다. 생성 OpenAPI 응답 계약으로 프런트엔드 타입도 검사합니다. 운영 Stable 승격과 전체 Phase 0–6 인수는 별도로 계속합니다.
