# 콘솔 전환 기능 탐색

v0.86.162 개발 후보. 시스템 설정의 **콘솔 전환**에서 기능 이름·등록 ID를 검색하고 전환 상태와 쓰기 차단 설정을 함께 좁힐 수 있다. 조회한 설정 목록을 브라우저에서 검색하며 설정 값·사용자·비밀정보는 검색하지 않는다. 기존 설정 API, 편집 검토·동시 변경 보호·감사와 `/admin`을 유지한다.

## 사용 방법

- **전환 기능 검색**에 한글 이름 또는 등록 ID를 입력하고 **검색**을 누른다. 한글 조합 중에는 입력을 유지하며 검색을 실행하기 전까지 목록을 바꾸지 않는다.
- **전환 상태 필터**와 **쓰기 차단 설정**은 함께 적용된다. 쓰기 차단 필터는 해당 설정 값을 뜻하며 역할·권한·전환 상태까지 합산한 실제 쓰기 가능 여부를 뜻하지 않는다.
- 검색과 두 필터는 주소에 저장해 새로고침과 직접 이동 때 복원한다. 편집창 열기·닫기·뒤로 이동에서도 조건을 유지한다.
- **전환 조회 조건 초기화**는 세 조건만 지운다. 관측 기간, 다른 설정 탭의 검색과 선택한 설정은 유지한다.
- 지원하지 않는 상태나 누락·손상된 쓰기 차단 값은 **확인 불가**로 따로 찾을 수 있다. 조회 실패, 등록된 기능 없음, 조건에 맞는 기능 없음을 구분한다.

검색어는 200자까지 받으며 비밀값·제어문자는 거부한다. 직접 주소의 중복·잘못된 조건이나 제거된 민감 조건은 명시적으로 초기화하기 전 전체 결과로 넓히지 않는다. 입력한 비밀값은 URL에 쓰지 않는다.

기능 수는 현재 조회된 전환 설정 목록의 크기다. 사용자 수·채택률·운영 안정성 지표가 아니며 정식 상태를 운영 검증 완료로 해석하지 않는다. 실제 사용자별 접근과 변경은 기존 서버 권한 검사를 따른다.

## 검증과 출고

한글 입력·결합 필터·주소 복원·초기화·편집 대상 보존·민감 조건·오류 상태·접근성의 구성요소 검사를 추가했다. 밝은/어두운 테마와 1440/390px, 키보드 복귀·직접 주소 새로고침·조회 계정의 쓰기 거부는 실제 Go 내장 에셋과 합성 API를 사용하는 브라우저에서 검증했다. 이 검사를 실제 운영 설정 변경으로 표현하지 않는다.

검증 결과:

- 전체 React 6,687개(480파일)를 고정 소스에서 통과했다. 그 뒤 검색 도움말 위치·이름과 ID의 행 배치를 개선하고 테스트의 타입·CSP 적용을 보완했다. 이 최종 상태에서는 관련 구성요소 400개(22파일), 내장 브라우저 71개, 정적 파일 Go 66개를 통과했다. 전체 회귀와 후속 검증 범위를 구분한다.
- 최종 브라우저는 재시도·제외·불안정 결과 없이 통과했다. 밝은/어두운 테마와 1440/390px의 새 시각 기준 4장을 검토한 뒤 수정 없이 비교했으며 axe, 키보드 복귀, 설정 이탈 경고와 수동 갱신 상태도 확인했다. 사전 시각 기준 생성 검사는 34개이며 최종 71개와 중복 집계하지 않는다.
- TypeScript·린트·포맷·OpenAPI 생성 일치·프로덕션 빌드·번들 예산과 기본 Node 검사 64개를 통과했다. Node 선택 검사 16개는 제외이며 통과 수에 포함하지 않는다. 통합 SBOM은 Go 19개와 npm 389개 패키지를 포함한다.
- 초기 전송 계산은 277,474/350,000바이트, 시작 의존성은 4,435바이트다. 이는 압축된 파일 크기 계산이며 실제 운영 응답 시간을 의미하지 않는다.
- 초기 선택자 충돌·테스트 타입 오류·CSP로 차단된 axe 삽입 실패를 보존한 뒤 원인을 수정했다. 실제 인증·업무 API 코드는 변경하지 않았으며 이번 UI 검사를 운영 SSO 검증으로 대체하지 않는다.

후보 CI·리뷰·순차 메인 병합·공식 릴리즈와 운영 Preview 검증은 별도 단계다. 운영 Stable 및 Phase 0–6 전체 인수는 계속 진행한다.
