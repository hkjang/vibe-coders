# 공용 참고자료 조회

v0.86.130 후보는 `/app/prompts/library?tab=contexts`에 공용 참고자료의 읽기 전용 미리보기를 추가한다.
기존 등록·실행 로직과 `/admin` 화면은 유지한다. 로컬 검증을 마친 개발 후보이며 후보 CI·리뷰·메인·정식 출고와 Stable 인수는 별도 단계다.

## 조회 범위와 표시

- 전체 운영 범위의 등록 키·이름·사용 여부·예상 토큰·누적 활용·최근 활용·수정 시각을 표시한다.
- 사용 상태를 서버에서 필터링하고 등록 키 순서로 25/50/100건씩 조회한다. 상태·페이지·크기는 주소와 새로고침·뒤로 가기로 복원한다.
- 표의 열 표시·순서·너비를 조정할 수 있으며 이름과 등록 키는 항상 유지한다. 좁은 화면에서는 열 너비를 유지하고 키보드로 표를 가로 이동한다. 열 설정에는 행 데이터와 본문을 저장하지 않는다.
- `use_count`는 기존 참고자료 확장의 누적 기록이며 고유 요청 수·모델 호출 성공 건수가 아니다. 예상 토큰도 실제 과금량이 아니다.
- 조회 중·빈 페이지·갱신 실패를 구분한다. 일시적인 갱신 실패는 마지막 정상 자료를 유지하고, 401/403은 보관함의 이전 조회 결과를 정리한다. 권한 확인 후 명시적으로 다시 조회한다.
- 계정·팀·역할·인증 세션·원문 권한·허용 기능의 조회 수명은 기존 보관함 공통 경계를 따른다. 읽기 전용 관리자도 조회할 수 있으며 이 화면에는 등록·변경·실호출 작업이 없다.
- v0.86.130 미만 서버에는 지원 안내를 표시하며 원문 목록으로 자동 전환하지 않는다. 기존 UI에 같은 등록 목록 화면이 없으므로 해당 탭에서 부정확한 상세 이동 링크를 제공하지 않는다. 콘솔의 기존 관리자 홈 이동은 유지한다.

## 기존 API의 메타데이터 보기

`GET /admin/contexts?view=metadata&state=all&limit=25&offset=0`은 기존 `admin:read` 검사를 공유한다.
기존 `GET /admin/contexts`와 등록 POST의 응답·업무 의미는 유지한다. 메타데이터 보기는 `no-store`이며 중복·추가·형식 오류 인자를 거부한다.

본문과 변경용 ID는 SQL에서 선택하지 않는다. 이름과 키도 기존 비밀정보·개인정보 표시 검사를 적용해 부적합한 전체 값을 `[숨김]`으로 바꾼다. 모든 자연어 개인정보를 탐지한다는 보장은 아니다. 브라우저 계약은 본문 등 미정의 필드를 거부하며 캐시 전에 추가 비밀값 표시 검사를 적용한다.

총 건수와 현재 페이지는 같은 읽기 트랜잭션에서 조회한다. 페이지 사이에 다른 관리자가 자료를 바꾸면 결과가 달라질 수 있다. 페이지당 최대 100건, 최대 offset 1,000,000으로 제한한다. 저장된 잘못된 음수·시각은 임의로 0으로 바꾸지 않고 미확인으로 표시한다. 등록 키·이름 검색과 본문 편집, 운영 Stable 승격은 후속 범위다.

## 로컬 검증 결과

관련 React 1,290개(66개 파일)·내장 Go 브라우저 88개·실제 Go/OIDC/SQLite 인증 52개·실제 Keycloak HTTPS 5개와 사용자 DB 검증·보고서와 실패 산출물 29개를 통과했다.

전체 store/proxy/appui Go 테스트·vet, SQLite·PostgreSQL 17 race, 실제 서버 OpenAPI·재생성·SBOM·타입·린트·포맷·번들 검사를 통과했다. 실제 관리자와 읽기 전용 관리자에서 메타데이터 필드 허용 목록, 31건/25건/후속 6건 및 사용 안 함 15건을 확인했다.

초기 브라우저는 기능 검사 84개를 통과하고 새 시각 기준 4장이 없어 실패했다. 직접 검토한 모바일 표가 너무 좁아 열 너비·열 설정·키보드 가로 이동을 적용했다. 빈 페이지의 잘못된 페이지 번호도 제거했다. 수정 후 두 테마·1440/390px 시각 기준 4장과 키보드·axe·본문 넘침, 고정 브라우저·실제 인증 검사를 통과했다. 기존 시각 기준과 비교 허용치는 유지했다.

초기 압축 번들은 263,292바이트다. 후보 원격 CI·리뷰와 메인·이미지·공개 배포 파일 검증은 별도로 확인하며 운영 Stable 승격과 전체 Phase 0–6 개발을 계속한다.

최종 실행 준비 과정에서 새 실제 인증 시나리오가 선택 목록에 빠져 기존 50개만 실행된 것을 건수 검사로 발견했다. 선택 목록을 보완한 뒤 신규 2개를 포함한 52개를 실제로 통과했다. 모바일 표의 키보드 가로 이동 중 촬영으로 생긴 픽셀 흔들림은 `scrollend`를 기다리고 위치 0을 확인하도록 보완했다. 새 모바일 기준 2장을 다시 검토했으며 기존 기준과 비교 허용치는 변경하지 않았다.
