# 공용 참고자료 검색과 정렬

v0.86.134 개발 후보는 프롬프트 라이브러리의 공용 참고자료에 이름·등록 키 검색과 최대 세 가지 서버 정렬을 제공한다. 기존 `/admin`과 공용 참고자료의 본문·등록·활용 로직은 유지한다. 목록은 읽기 전용이며 실제 모델 호출이나 사용 상태 변경을 수행하지 않는다.

## 조회 흐름

검색 초안을 입력하고 **검색 적용** 또는 Enter를 누르면 전체 등록 목록을 검색한다. 이름과 등록 키의 대소문자를 구분하지 않는 부분 검색이며 `%`, `_`, `!`도 일반 문자로 취급한다. 본문과 변경용 ID는 검색하거나 반환하지 않는다. 검색 입력은 최대 200개 유니코드 코드 포인트이며 비밀값·제어 문자를 거부한다. 서버의 기존 표시 검사는 개인정보 모양의 검색값도 거부하며 오류에 원문을 넣지 않는다.

사용 상태, 검색, 정렬, 페이지와 크기를 주소에 보존한다. 검색·정렬·사용 상태·페이지 크기를 바꾸면 첫 페이지로 이동한다. 새로고침과 뒤로 가기는 적용한 조건을 복원하며 보내지 않은 검색 초안은 요청이나 주소에 저장하지 않는다. 조회 권한을 잃거나 계정이 바뀌면 기존 목록과 초안을 폐기한다.

열 머리글은 단일 정렬, **다중 정렬**은 최대 세 조건을 제공한다. 이름·등록 키·사용 상태·예상 토큰·누적 활용을 정렬할 수 있다. 같은 값의 마지막 기준은 고유 등록 키이며 미확인 수치는 양방향 모두 마지막에 둔다. 현재 적용된 정렬 순서를 한글로 표시한다. 비교는 현재 페이지가 아닌 전체 결과에서 수행한다. 별도 페이지 요청 사이에 자료가 바뀌면 결과도 바뀔 수 있다.

## 호환성과 서버 계약

기존 `GET /admin/contexts?view=metadata`에 선택적 `q`와 `sort`를 확장하며 응답 모양은 바꾸지 않는다. 기존 조건 없는 조회와 v0.86.130 UI의 엄격한 응답 검증이 유지된다. 새 검색·정렬 UI는 백엔드 v0.86.134 이상에서 제공한다. 이전 서버에 검색 조건이 담긴 직접 주소로 접근하면 안내와 조건 초기화를 제공한다.

검색값은 바인딩하고 LIKE 문자를 이스케이프한다. 정렬은 허용된 열과 방향으로만 생성하며 중복 열·알 수 없는 방향·세 개를 넘는 조건을 거부한다. 집계와 페이지는 하나의 읽기 트랜잭션으로 조회한다. 기존 관리자 조회 권한을 공유하고 변경 권한을 요구하지 않는다. 결과는 캐시하지 않는다.

주소 정렬의 `key:asc`는 등록 키 열을 뜻한다. 유한한 열·방향 문법을 검증한 경우에만 공통 비밀값 탐지의 할당값 검사에서 구분한다. 임의의 `key:값`, 비밀 검색어와 다른 화면의 정렬 매개변수에는 이 예외를 적용하지 않는다.

## 검증과 인수

SQLite·PostgreSQL의 한글·유니코드·리터럴 검색, 본문 제외, 상태와 다중 정렬, 미확인 수치, 동일 값의 페이지 순서를 검증한다. React에서는 명시 검색·주소·뒤로 가기·초기화·민감 입력·계정 전환·구버전과 잘못된 조건을 검사한다. 실제 Go 인증의 관리자와 읽기 전용 관리자가 동일한 검색·정렬 결과를 읽는지 확인한다. 두 테마·모바일·데스크톱에서 검색 및 정렬 창의 키보드·접근성·시각 기준을 검증한다.

관련 React 1,347개(71개 파일)·내장 Go 브라우저 120개·실제 Go/OIDC/SQLite 인증 60개·실제 Keycloak HTTPS 5개와 사용자 DB 검증·보고서와 실패 산출물 29개를 통과했다. 전체 store/proxy/appui Go 테스트·vet, SQLite·PostgreSQL 17 race, API 표면·실제 서버 OpenAPI·생성 계약·SBOM·타입·린트·포맷·번들 검사를 통과했다. 두 테마·1440/390px 검색 및 정렬 창 시각 기준 8장, 키보드 초점 복귀·axe·가로 넘침을 확인했다. 초기 압축 번들은 264,693바이트다. 기존 시각 기준과 비교 허용치는 유지했다. 초기 구성 테스트에서 잘못된 인증 모형 옵션과 래퍼 교체를 교정했고, 키 열 정렬의 비밀값 오인 문제를 유한한 정렬 문법 검증으로 수정해 회귀 검증했다. 최초 시각 검토에서 정렬 아이콘 옆의 제목 잘림을 확인해 해당 열의 최소 너비를 보완했다. 제목·단위 가시성을 검사하고 전체 화면 시각 기준과 실제 인증을 다시 검증했다. 원격 CI·리뷰·메인·정식 출고와 운영 Stable 인수, 전체 Phase 0–6는 별도로 진행한다.

### v0.86.134 직접 주소 리뷰 보완

리뷰에서 민감한 직접 주소가 전체 조회로 넓어지는 문제를 현재·구버전 서버 조건 4건으로 재현한 뒤, 값 없는 거부 표시를 보존하고 명시 초기화 전 조회를 차단했다. 새로고침 후 표시 유지도 검증했다. Zod 4.6.6의 코드 포인트 길이 지적은 재현되지 않았으며 9개 경계와 실제 브라우저의 200개 이모지 요청 원문 보존을 추가 검증했다. 수정 후 관련 React 1,368개(72개 파일), 내장 브라우저 125개, 실제 인증 60개, 실제 Keycloak 5개·DB 검증과 보고서 29개를 통과했다. 시각 기준 8장은 변경하지 않았고 초기 압축 번들은 264,686바이트다. 운영 Stable와 전체 Phase 0–6 인수는 별도다.
