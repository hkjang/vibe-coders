# 기본 관리자 콘솔

현재 소스는 `/app/`을 기본 관리자 콘솔로 사용합니다. 서버 주소 `/`에 GET 또는 HEAD로
접속하면 캐시하지 않는 302 응답으로 `/app/`으로 이동합니다. 루트 주소의 임의 쿼리는
전달하지 않으며, 콘솔 내부 첫 화면은 기존 `ui.app.default_entry` 설정을 따릅니다.

`UI_APP_ENABLED`가 없을 때의 기본값과 새 배포 환경 생성값은 `true`입니다.
관리자에 저장된 `ui.app.enabled`가 환경 변수보다 우선하며, 명시적으로 비활성화하면
루트 주소는 `/admin`으로 이동합니다. 기존 환경 파일의 명시 설정은 업그레이드 때 보존합니다.
기존 배포에서 전환하려면 저장된 `ui.app.enabled` 또는 `UI_APP_ENABLED`의 `false`를
`true`로 바꿉니다. `/admin` 직접 주소와 기존 API·인증·권한은 계속 사용할 수 있습니다.

사이드바·즐겨찾기 관리에서 기능 이름 옆의 미리보기/정식 배지를 표시하지 않습니다.
접힌 메뉴 툴팁과 스크린리더 이름도 같은 규칙을 사용합니다. 읽기 전용·기존 화면·
지원 종료 상태는 필요한 안내로 남습니다. 기능별 공개 역할·전환 설정과 쓰기 제한은 유지합니다.

이 변경은 사용자가 요청한 기본 진입 경로와 메뉴 표시 변경입니다. 각 기능의 운영 인수 결과나
모든 전환 상태를 일괄적으로 변경하지 않습니다.

검증: 기본 진입·실행 중 설정 전환 Go 검사, 관련 React 211개, 실제 Go 내장 브라우저
59개(재시도·생략·불안정 0), 컨테이너 기본 진입과 정적 파일 검사, OpenAPI 계약·
타입·린트·빌드·SBOM 생성을 통과했습니다. 모바일 메뉴 시각 기준 한 장은 변경 전후를
직접 확인한 뒤 갱신했습니다. PR/메인 CI와 공식 공개 릴리즈는 후속 게이트입니다.

## 기능별 기존 화면 링크

공통 페이지 제목, 기존 화면 연결 페이지, 개별 화면과 상세·오류 화면의 전용 링크는
링크가 가리키는 기능의 현재 설정을 확인합니다. 기능 간 이동과 수동 조치도 목적지
기능을 기준으로 검사합니다.
전체 Legacy 전환이나 해당 기능의 fallback이 꺼졌거나, 기능이 숨김·종료 상태이거나,
대상 기능 또는 기존 관리자 접근 권한을 확인할 수 없으면 해당 링크를 표시하지 않습니다.
지원 종료 예정(deprecated) 기능의 허용된 fallback은 유지합니다.

공통 제목은 현재 라우트의 기능을 사용하며, 다른 기능으로 가는 링크는 목적지 기능을
명시합니다. 서버 bootstrap의 `legacy_route_map`도 종료(retired) 기능을 제외하지만,
그 기능의 신규 화면 접근 허용 여부는 바꾸지 않습니다. 사용자 메뉴·오류 복구의
전체 `/admin` 진입은 별도의 전체 전환·권한 규칙을 따릅니다.

기능 전용 오류 복구 링크는 목적지 기능 ID와 주소를 함께 지정합니다. 확인할 수 없는
목적지는 링크를 표시하지 않으며, 전체 `/admin` 홈 복구는 명시적으로 구분합니다.
수동 조치의 비용·정책 링크는 서버가 실제 제공하는 두 목적지만 허용합니다.

종료(retired) 기능에 필요한 API 버전을 서버가 충족하지 못하면 서버 버전 확인 안내를
표시합니다. Legacy 연결 화면으로 되돌리지 않으며, 서버 업그레이드 후에는 신규 화면을
사용할 수 있습니다. Legacy 접근 권한이 없는 연결 화면에도 권한·전환 설정 안내를 표시합니다.

이는 링크 표시 정책입니다. `/admin` 직접 주소와 기존 API 권한을 변경하지 않습니다.
지원되는 리소스 ID·필터를 Legacy Query로 변환하는 공통 매핑과 기존 콘솔의 설정 가능한
신규 UI 진입 링크는 별도 범위이며, 이 변경이 전체 전환 요구사항의 완료를 의미하지 않습니다.
