# 실행 영수증 탐색 — v0.86.95 후보

업무 앱과 워크플로의 **실행 이력 → 영수증 보기**에서 실행 상세를 엽니다.
`/app/agents/apps?tab=runs&run=실행ID`와
`/app/agents/workflows?tab=runs&run=실행ID` 주소를 저장하거나 공유할 수 있습니다.
새로고침·로그인 복귀·브라우저 뒤로/앞으로 이동을 지원하며 닫을 때 검색·페이지 조건을 유지합니다.
실행 목록을 불러오지 못해도 정확한 ID의 영수증은 독립 조회합니다.

상태는 완료·오류·계획됨·승인 대기·조건 불충족·통과·중단·건너뜀으로 표시합니다.
알 수 없는 상태는 상태 확인 필요로 구분합니다. 앱의 구성 요소 계획 요약도 한글로 표시합니다.
조회한 메타데이터의 누락된 수치는 0으로 채우지 않습니다. 입력·출력 원문은 표시하지 않습니다.

워크플로의 단계 결과는 기본 25개씩 표시하고 10·25·50개로 조정합니다. 현재 단계의 번호·이름·
종류·상태·출력 길이를 확인합니다. 이는 내려받은 단계 메타데이터의 화면 페이지이며 서버
페이지 조회가 아닙니다. 실행 시간축·분기 편집이나 새로운 실행 기능은 추가하지 않습니다.

빈 ID·중복 ID·지나치게 긴 ID·제어문자·정의와 실행의 동시 선택은 오류 안내를 표시하며
상세 요청을 보내지 않습니다. 민감정보로 보이는 값은 기존 주소 보호 절차로 제거합니다.
서버가 다른 실행 ID를 반환하면 해당 내용을 숨기고 다시 조회하도록 안내합니다.
404는 없는 실행, 일반 조회 실패는 다시 시도, 401/403은 계정·권한 확인으로 구분합니다.

기존 실행 API의 소유자 검사를 그대로 사용합니다. 관리자라도 다른 사용자의 영수증을
조회할 수 없습니다. 계정·팀 변경과 화면 종료 시 조회를 취소·폐기하고 늦은 결과를 숨깁니다.
영수증과 정의 버전 이력은 분리된 캐시를 사용합니다. `/admin`과 기존 변경 API는 유지합니다.

## 검증

직접 주소·목록 오류·잘못된 주소·응답 ID·수동 재시도·계정 변경·늦은 응답·캐시 충돌과
단계 페이지를 포함한 최종 관련 검사 258개가 통과했다. 전체 React 5,767개도 통과했다. 실제 Go 내장 자산·운영 CSP·외부 네트워크 차단 관련 브라우저 43개가
재시도·건너뛰기 없이 통과했다. 두 테마와 1440px·390px의 시각 기준 8개, 키보드·초점·
axe·가로 넘침과 내장 자산 189개의 해시를 확인했다. 이 검사의 업무 API는 합성 응답이다.
별도 실제 Go 인증·OIDC·SQLite 브라우저 42개도 통과했다. 추가된 4개 시나리오는 직접
로그인 복귀·새로고침·본인/타인 권한·읽기 전용 계정과 404를 확인한다.

린트·포맷·TypeScript·OpenAPI 생성 계약, Go OpenAPI·인증 도구·정적 자산 처리와
통합 SBOM을 검사했다. 초기 압축 번들은 255,009/350,000바이트이고 일반 화면 47개와
선택 도구 5개도 예산 안이다. 새 의존성은 없다. 보조 도구 54개 검사가 통과했고 선택적 환경 검사 15개는 로컬에서
건너뛰었다. 최종 원격 CI·정식 출고·운영 Stable 인수는 진행 중이다.
