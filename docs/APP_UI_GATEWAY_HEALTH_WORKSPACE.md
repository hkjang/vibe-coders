# 게이트웨이 상태 조회와 복구 확인

v0.86.105 후보 마일스톤. 기존 `/admin`, 공개 상태 확인과 라우팅 API를 유지한다.

## 사용자 동작

- 게이트웨이 연결·요청 준비 상태·공급자 순위·회로 차단기·라우팅 알림·요청 분배를 확인한다. 기간은 주소에 저장하며 새로고침 후 복원한다.
- 공급자 분배 방식은 첫 공급자 우선, 순환 분배, 세션 해시 분배로 표시한다. API 경로 대신 운영상 의미를 설명하며 모바일 숫자 지표는 360px 이상에서 두 열로 비교한다. 표만 가로 스크롤되며 키보드로 표의 숨겨진 열을 확인할 수 있다.
- 비공개 라우팅 상태와 세션 고정 상태는 현재 계정·팀·세션·조회 권한에 연결한다. 전환 시 이전 조회·캐시·복구 확인을 폐기하며 늦은 조회나 작업 결과가 새 화면과 알림에 반영되지 않도록 한다.
- 두 비공개 조회 중 하나가 401/403을 반환하면 함께 닫고 자동 재조회를 멈춘다. 공개 연결·요청 준비 상태는 계속 표시한다. 기간 변경은 거부 상태를 해제하지 않으며 **권한 다시 확인** 또는 새로고침으로 명시적으로 재조회한다.
- 일시 오류에는 마지막 정상 상태와 갱신 실패를 표시한다. 실패하거나 갱신 중인 상태로 복구 작업을 실행하지 않는다. 읽기 전용 전환은 확인 대상을 유지하면서 제출을 차단한다.
- 회로 차단기·세션 고정 해제는 대상과 영향을 먼저 확인한다. 확인 뒤 조회 결과·기간이 바뀌거나 갱신 중이면 최신 상태에서 다시 확인한다. 실제 전송 직전에도 조회 소유권·확인한 스냅샷·변경 권한을 재검사한다.
- 현재 비밀 접두사가 포함된 공급자 이름·오류 요청 ID·진단 코드는 화면에 그대로 표시하지 않는다. 비공개 이름을 원문으로 재전송하는 개별 복구는 차단한다.

## 보호 범위

기존 조회 권한과 서버 변경 권한·감사를 재사용한다. 조회 스냅샷 확인은 브라우저가 검토한
운영 상태를 검사하는 것으로, 전체 서버 상태를 잠그거나 다중 pod의 동시 작업을 직렬화하는 기능이 아니다.
이미 전송한 작업의 서버 실행을 취소했다고 표시하지 않으며 현재 계정의 상태를 다시 조회해야 한다.
공개 상태 API는 비공개 관리 캐시와 구분한다. 공급자·진단 표시에는 현재 마스킹 기준을 적용한다.

522줄 화면은 상태 화면·공급자 표·조회 수명·복구 작업으로 나눠 화면 파일을 400줄 이내로 유지한다.

## 검증 상태

팀 변경과 늦은 조회·변경 응답, 조회 거부, 권한 회수, 같은 응답을 반환하는 기간 변경, 확인 기준 변경, 일시 오류, 비공개 이름·실패 요청 ID,
기존 읽기 전용·실제 전송 경계를 구성요소 검사로 확인한다. 브라우저에서 기간·새로고침·대상 확인·
키보드 초점·명시적 복구·두 테마·모바일·axe·시각 기준을 검증한다. 최종 결과와 원격 CI·출고는 별도 기록한다.
전체 Phase 0–6 완료나 운영 Stable 승격을 의미하지 않는다.

## v0.86.105 로컬 검증 결과

- 전체 React 5,915개 / 402개 파일, 보조 도구 54개 통과. 선택 환경 검사 15개는 로컬에서 건너뛰며 원격 CI로 구분한다.
- 게이트웨이 상태 집중 검사 39개 통과. 같은 상태 객체를 반환해도 조회 기간이 바뀌면 이전 확인으로 실행할 수 없는 회귀를 재현하고 보완했다.
- Go 바이너리 내장·외부 네트워크 차단 브라우저 52개와 읽기 전용 시각 비교 52개가 실패·건너뛰기·재시도 없이 통과했다. 1440px/390px, 밝은·어두운 테마, 키보드, axe, 기준 이미지 4장을 확인했다.
- 실제 Go/OIDC/SQLite 인증 46개, 기존 관리자 정적·행위 회귀, Go 정적 UI 검사가 통과했다. 인증 실행 쉘 종료 143은 따로 기록했으며 완료된 정제 결과 46개와 검사 입력 해시가 동일함을 독립 확인했다.
- 내장 자산 187개, 해시·CSP·캐시·MIME·깊은 주소·없는 에셋 404·잘못된 메서드 405·기존 관리자 200을 확인했다. 초기 압축 번들은 261,451/350,000바이트이며 화면 47개·선택 도구 6개가 예산을 충족한다.
- 타입·린트·포맷·OpenAPI 계약 검사와 프로덕션 빌드를 통과했다. v0.86.105 통합 SBOM은 Go 19개·npm 389개 패키지와 라이선스를 포함한다.

첫 브라우저 검사의 영문 분배 방식 기대값, 모바일 표의 End 키 기대값, 스크롤 직후 시각 비교 실패는 보존했다.
한글 표시 기대값과 가로 방향키를 맞추고 시각 캡처를 키보드 스크롤 검증보다 먼저 수행했다.
전체 React 검사 이후 변경은 이 브라우저 순서와 모바일 기준 이미지 2장뿐이며,
애플리케이션·단위 검사 소스가 동일함을 확인한 뒤 최종 브라우저와 타입·린트·포맷을 통과했다.
원격 PR·실제 메인 CI와 정식 배포 파일·이미지 공개 검증은 후속 출고 게이트다.

## 전체 CI의 권한 복구 회귀 보완

첫 PR 전체 브라우저 검사에서 1,626개 통과와 4개 실패를 확인했다. 실패한 기존 검사는
읽기 전용 중 공급자가 바뀌어도 이전 확인창으로 해제할 수 있다고 가정했다. 최신 조회
기준과 다른 확인을 막는 보호 동작은 유지하고 브라우저 시나리오를 보완했다.

두 읽기 전용 상태와 개별 차단기·전체 차단기·세션 고정을 각각 검사한다. 조회 결과가
같으면 쓰기 복구 후 수동 전송하며, 차단기 상태가 달라지면 복구 후에도 잠금을 유지하고
최신 대상으로 확인창을 다시 연 뒤에만 전송한다. DOM 활성화 시도는 이전 대상으로
요청을 보내지 않는다. 관련 Go 내장 브라우저 97개가 재시도·건너뜀 없이 통과했고
TypeScript·ESLint도 통과했다. 애플리케이션과 단위 검사 소스는 이전 검증과 동일하다.
수정 커밋의 전체 원격 CI를 다시 확인한 뒤 병합한다.
