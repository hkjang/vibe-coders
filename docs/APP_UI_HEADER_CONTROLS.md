# 상단 표시 설정과 사용자 메뉴

v0.86.75 후보는 작은 화면과 키보드에서 공통 상단 메뉴를 개선한다.

## 표시 설정

모바일을 포함한 모든 화면 크기에서 `화면 표시 설정`을 연다. 테마는 밝게·어둡게·시스템 설정,
정보 밀도는 조밀하게·기본·여유롭게, 자동 갱신은 끔·1분·5분 중에서 선택한다. 선택은 기존
브라우저 설정 저장 방식을 사용해 새로고침 후 유지한다. 데스크톱의 빠른 갱신 주기 선택도 유지한다.
이 설정은 기존 화면별 갱신 동작에 적용되며 새로운 서버 작업을 실행하지 않는다.

## 키보드와 닫기

- 상단 메뉴 버튼에 초점을 두고 Enter로 연다. Tab으로 내부 항목과 다음 상단 작업으로 이동한다.
- Escape로 닫으면 해당 메뉴 열기 버튼으로 초점이 돌아온다.
- 바깥 영역을 선택하거나 Tab으로 나가면 메뉴를 닫고 이동한 요소의 초점을 유지한다.
- 메뉴 안에서 Ctrl/Cmd+K 명령 팔레트나 `?` 단축키 도움말을 열면 메뉴가 닫힌다. 창을 닫으면
  숨겨진 입력·작업 대신 보이는 메뉴 열기 버튼으로 돌아온다. 일반 본문에서 연 단축키는 기존
  초점 복원 규칙을 유지한다.
- 다른 경로로 이동하면 열린 상단 메뉴를 닫는다. 작은 화면의 긴 메뉴는 내부에서 스크롤한다.

상단 메뉴는 비모달 펼침 영역으로 Tab 이동을 가두지 않는다. 명령 팔레트·단축키 도움말·모바일
탐색 대화상자의 기존 초점 보호는 유지한다. 사용자 메뉴의 역할·팀·버전·최근 화면·로그아웃과
권한에 따른 기존 관리자 연결도 유지한다.

## 검증

1440×900, 1024×768, 390×844, 844×390에서 설정 선택·새로고침 복원과 메뉴의 화면 내 배치를
검사한다. 밝은·어두운 테마의 axe 검사, Enter·Tab·Escape와 팔레트·도움말 초점 복귀를 실제
브라우저에서 확인한다. 시각 회귀는 기존 주요 화면과 함께 검사하며 메뉴 내용의 장기 운영
검증이나 전체 기능의 Stable 승격을 대신하지 않는다.

기존 `/admin`·인증·권한·API와 단일 Go 바이너리 배포를 유지한다. Phase 0–6 전환은 계속 진행한다.
