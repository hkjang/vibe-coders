# 내 홈과 표 목록의 읽기 편의 개선

내 홈의 `내 할 일`은 이웃 알림 카드의 높이 때문에 내용 사이가 벌어지지 않습니다. 할 일별 제목, 중요도, 설명과 작업 버튼을 묶고 건수를 표시합니다. 좁은 카드에서는 버튼을 설명 아래로 배치하며, 긴 한글 문구와 글자 확대에서도 읽고 조작할 수 있습니다. 기존 화면 이동, 오류 요청 필터, 키 확인, 리포트 이동, 7일 숨기기와 확인·취소 후 초점 복귀는 유지합니다.

표 목록은 긴 이름·식별자·모델 패턴·주소가 옆 열로 넘어가지 않도록 셀 안에 배치합니다. 공급자와 모델의 이름은 최대 두 줄로 표시하고, 주소·패턴은 말줄임과 기존 상세 보기로 확인합니다. 표시용으로 보호된 값만 도움말에 사용합니다. 자동 너비 표에는 읽을 수 있는 최소 열 폭을 두고, 사용자가 너비를 조절하는 표는 저장된 너비를 따릅니다. 좁은 화면에서는 표 안에서 가로로 이동합니다.

상태 배지, 코드, 보조 문구도 기본 13px 이상으로 표시하며 사용자 글자 확대를 따릅니다. 행 밀도와 열 설정, 검색·정렬·페이지 주소, 상세 열기, 선택 작업, 원래 값의 CSV 내보내기를 유지합니다. 줄바꿈과 말줄임은 저장 값이나 내보내기 값을 바꾸지 않습니다.

## 검증 범위

한 건·여러 건·긴 문구·알 수 없는 종류의 할 일을 390/768/1024/1440px, 밝은/어두운 테마, 확대 글꼴과 읽기 전용에서 확인합니다. 표에서는 긴 한글과 공백 없는 식별자·주소를 넣어 실제 글자 영역이 셀 안쪽 여백을 넘지 않는지 검사합니다. 작은 열 너비, 키보드 초점, 전체 값 보존과 CSV도 확인합니다.

전체 브라우저 첫 검사 2,158개 중 2,156개가 통과했고 새 글자 크기 검사 두 건은 대화상자 등장 중 투명한 문구를 읽어 실패했습니다. 문구가 실제 표시될 때까지 기다린 뒤 같은 크기 기준으로 검사하도록 고쳤습니다. 시각 비교에서 발견한 MCP와 Text2SQL의 자동 너비 열 과도 축소도 공통 최소 폭과 이름 표시로 보완했습니다. 기준 이미지의 허용 오차나 마스킹 범위를 늘리지 않습니다.

최종 전체 브라우저 2,164개와 집중 검사 23개를 재시도·제외 없이 통과했습니다. 변경된 이미지 156장(선행 후보와 동일한 9장 포함)을 검토한 뒤 이미지와 소스를 바꾸지 않은 시각 비교 364개도 통과했습니다. 후보 CI·리뷰·공개 출고 결과는 [인수 검증표](APP_UI_ACCEPTANCE.md)에 구분합니다. 운영 Stable 승격과 전체 Phase 0–6 목표는 계속 진행합니다.

후보 PR #245의 첫 원격 CI에서는 2,163개가 통과하고 긴 할 일의 키 화면 이동 검사 한 건이 실패했습니다. 목적지의 `/me/keys`·`/me/sessions` 응답이 테스트 준비에서 빠져 있었으며, 로컬에서는 비동기 조회 전에 검사가 끝나 이를 발견하지 못했습니다. 기존 개인 연결 준비 데이터를 재사용하고 실제 키 빈 상태와 로그인 세션 표시·정확한 조회·변경 호출 0건까지 확인하도록 보완했습니다. 같은 생산 빌드에서 홈·개인 연결 브라우저 24개와 엄격한 타입·관련 린트·포맷 검사를 재시도나 이미지 갱신 없이 통과했습니다. 새 후보의 원격 CI와 리뷰를 다시 확인합니다.
