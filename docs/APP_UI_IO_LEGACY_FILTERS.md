# 입출력 모니터의 기존 화면 연결

입출력 모니터의 `기존 화면에서 열기`와 상세의 `기존 화면에서 같은 요청 열기`는
현재 모델과 표시 건수(30건)를 기존 호출 이력 화면으로 전달합니다. 선택한 요청은
목록 필터와 별도로 유지하므로 검색 결과가 비어 있어도 원래 요청 상세가 열립니다.

기존 화면이 지원하지 않는 상태, 페이지 위치, 표시된 요청 안에서 찾기는 전달하지
않으며 링크 주변에 안내합니다. 페이지 위치를 전달할 수 없으면 첫 페이지부터
조회합니다. 화면 내 검색 문구와 입출력 본문은 이동 주소에 포함하지 않습니다.

기존 서버의 기능 지원 여부와 운영자가 지정한 이동 주소를 따릅니다. 사용자 지정
주소에는 임의의 필터나 요청 ID를 추가하지 않습니다. 기존 화면 이동이 비활성화되거나
현재 사용자에게 허용되지 않으면 링크와 이동 안내도 표시하지 않습니다.

긴 요청 ID는 원래 요청의 식별자를 우선 보존합니다. 필터를 함께 넣은 주소가 기존
SSO 복귀 한도를 넘으면 필터를 제외하고 안내합니다. 확장된 복귀 경로를 지원하는
서버에서만 긴 요청 선택 주소를 사용합니다. 원문 보기와 메모 저장은 이 이동으로
실행되지 않으며 기존 권한·감사 절차를 따릅니다.

검증에는 주소 인코딩과 길이 경계, 데스크톱·모바일의 빈 목록과 별도 상세, 지원하지
않는 필터 안내, 비활성화된 이동 정책, 실제 Keycloak SSO 복귀 및 SQLite 조회 결과
비교를 포함합니다. 이 개선은 기능별 운영 검증이나 전체 Phase 0–6 인수를 대신하지
않습니다.
