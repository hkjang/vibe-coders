# IP 사용량 탐색

v0.86.73 후보는 사용자와 팀의 IP 탭을 개선한다. `/app/access/users/ips`에서
보관된 요청 기록의 IP별 사용량을 조회한다. 기존 `/admin#/ips`와 두 관리 API의 인증·팀 범위·마스킹을 유지한다.
기존 `/app/access/users?tab=ips` 주소는 필터와 선택을 보존해 새 주소로 이동한다.
IP 화면은 별도 경로 청크로 로딩해 계정 관리 편집기를 함께 내려받지 않는다.

## 목록과 상세

- 목록은 요청 수가 많은 최대 200개 그룹이다. 검색·다중 정렬·페이지 이동·CSV는 받은 목록에 적용된다.
  요약은 표시한 그룹의 합계이며 전체 게이트웨이 트래픽을 뜻하지 않는다. 유효하지 않은 과거 주소는
  캐시와 링크에서 제외하고 제외 건수를 안내한다. IP 미기록은 서버의 `unknown` 그룹이다.
- IP 주소를 선택하면 상세 패널이 열린다. IPv6는 압축하거나 정규화하지 않고 저장된 표기를 그대로 보낸다.
  주소의 `ip` 선택은 목록 검색과 독립적이다. 새로고침·뒤로/앞으로 이동 후에도 상세와 표 조건을 복원한다.
- 요약·추이는 누적 사용량, 일별·언어별 집계를 제공한다. 일별 값은 서울 시간 기준 최근 60개 활성 날짜이며
  기록이 없는 날을 0으로 채우지 않는다. 언어는 최대 50개이고 여러 언어를 감지한 요청이 중복 집계될 수 있다.
- 모델·키는 각각 요청 수가 많은 최대 50개 그룹이다. 키는 비밀값 대신 기록의 키 ID를 표시한다.
- 최근 요청은 최대 100건이다. 요청 탐색기 권한과 기능 공개 상태가 허용하는 경우 해당 IP·요청 ID로 이동한다.
  기존 관리자 이동은 같은 IP의 Legacy 상세를 연다. 프롬프트·응답·오류 원문을 이 화면에서 표시하지 않는다.
- 열 표시·순서·너비는 공통 표 설정에 저장한다. 검색·정렬·페이지·페이지 크기·상세 탭은 URL에 저장한다.
  CSV는 필터·정렬을 적용한 수신 목록 전체를 저장하며 수식 입력을 이스케이프한다. 시각은 원본 ISO 값을 내보낸다.

## 기존 API 계약

| API | 기존 의미 |
| --- | --- |
| `GET /admin/ips` | 보관된 전체 기간에서 최대 200개 IP 그룹, 서버 페이지네이션·시간 필터 없음 |
| `GET /admin/ips/{ip}?limit=100` | 정확한 IP 그룹의 상세; `limit`은 최근 요청에만 적용, 최대 200 |

모델·키 집계는 `key`, 일별 집계는 `date`, 최근 요청 비용은 `estimated_cost`를 사용한다.
새 UI는 허용된 필드만 검증·투영한 뒤 Query 캐시에 저장한다. 미확인 수치는 0으로 대체하지 않는다.
자식 집계가 누락된 경우 빈 목록으로 보이지 않게 안내한다. 응답 대상 IP가 다르거나 중복 식별자·잘못된 수치가
있으면 오류를 표시한다. IP 단위 차단 API와 기존 키의 허용 IP 수정 API는 새로 만들지 않는다.

서버의 `admin:read` 검사를 유지한다. 팀 관리자는 같은 팀 범위의 하위 집계만 받으며 팀에 없는 IP는 404다.
잘못된 IP는 400, 인증·조회 스코프가 없으면 기존 401, 지원하지 않는 메서드는 405다.
두 응답은 성공·오류 모두 `Cache-Control: no-store`를 적용한다.

## 조회 수명과 실패 처리

계정·팀·역할·세션·조회 권한이 변경되면 이전 Query와 열린 화면을 폐기한다. 늦은 응답은 새 화면에 반영하지 않는다.
읽기 전용 전환은 조회를 유지한다. 서버 401/403 뒤에는 이전 목록·상세·내보내기를 숨기고 권한 재확인을 제공한다.
일시적인 조회 오류는 마지막 정상 데이터와 갱신 시각을 함께 보여준다. 초기 실패·성공한 빈 목록·누락 항목은 구분한다.
비활성 탭에서는 공통 자동 갱신 정책에 따라 폴링을 중단한다. 검색은 브라우저 내 수신 목록에만 적용한다.

## 검증 범위

실제 Go HTTP 검사는 IPv4·서로 다른 IPv6 표기·IP 미기록, 집계 필드와 서울 날짜, 캐시·메서드·오류 계약을 확인한다.
기존 팀 분리 회귀를 유지한다. React 검사는 응답 투영, 비밀값·잘못된 주소, 수식 보호, 다중 정렬, 주소 복원,
누락·오류·권한 변경·늦은 응답을 확인한다. 브라우저 검사는 실제 SPA 빌드에서 세 화면 크기와 두 테마,
키보드·초점 복귀·axe·CSV 다운로드·화면 비교를 수행한다. 합성 브라우저 응답 검사는 실제 Go 계약 검사와 구분한다.

운영 사용자 검증, 전체 Phase 0–6 인수, Stable 승격은 별도 검증이 남아 있다.
