# 관측된 MCP 도구 이름 검색

v0.86.96 후보는 명령 팔레트의 자원 검색에서 **관측된 MCP 도구**를 찾고,
정확한 서버·도구 필터로 MCP 운영 화면을 연다. 기존 MCP 서버 검색과 함께 사용한다.

- `Ctrl/Cmd + K` → `자원 검색`에서 도구 이름을 두 글자 이상 입력한다.
- 같은 이름의 도구는 서버 라벨로 구분한다. 서버를 기록하지 않은 기존 관측은
  `서버 미지정`으로 표시하되 실제 카탈로그의 `(none)` 식별자를 보존한다.
- 방향키와 Enter로 선택한다. 주소의 서버·도구·MCP 필터는 새로고침과 뒤로·앞으로
  이동에서 유지한다. 카탈로그와 신규 도구 수도 선택한 도구에 맞게 표시한다.
- 긴 이름은 검색창 안에서 줄바꿈한다. 빈 결과, 부분 실패와 수동 재시도를 지원한다.

## 조회 범위

기존 `POST /admin/resource-search`에 `mcp_tool` 종류를 추가했다. 기존 관측 카탈로그의
`is_mcp=1` 행에서 서버 라벨과 도구 이름만 선택한다. 서버 접속이나 도구 탐색·호출은
발생하지 않는다. 아직 관측되지 않은 도구, 스키마·설명·인수·결과는 검색하지 않는다.

기존 MCP 조회와 같은 `admin:read`, `observability:read` 및 기능 공개 조건을 적용한다.
쓰기 권한은 필요하지 않다. 이전 서버에는 새 종류를 보내지 않으며 계정·팀·세션·권한
변경 뒤 이전 검색 결과를 폐기한다. API와 브라우저에서 민감정보 형태를 걸러낸다.

검색어는 URL 대신 POST 본문으로 전달하고 저장하지 않는다. 2~128자 이름 부분 검색,
종류별 최대 10개, 공통 3초 제한을 유지한다. SQL 와일드카드는 문자 그대로 처리한다.
도구 이름은 256자/1024바이트, 서버 라벨은 512자/2048바이트 이내만 선택한다.
정렬은 도구 이름·서버 순이며 안전하지 않은 결과를 제외하므로 10개보다 적을 수 있다.
반환 한도는 스캔 행 수 제한이나 서버 페이지 기능을 뜻하지 않는다.

## 검증

SQLite 및 CI와 같은 PostgreSQL 이미지에서 기존·신규 자원 검색과 권한 검사를 통과했다.
PostgreSQL은 race 검사도 포함한다. 전체 React 5,775개, 최종 관련 검사 70개,
보조 도구 54개가 통과했다. 선택적 환경 검사 15개는 로컬에서 건너뛰었다.

실제 Go 내장 자산·운영 CSP·외부 네트워크 차단 환경의 브라우저 44개가 재시도·건너뛰기
없이 통과했다. 업무 API는 합성 응답이다. 신규 시나리오 7개, 두 화면 폭·두 테마의
시각 기준 4개, axe·키보드·긴 이름·주소 복원을 확인했다. 기존 MCP 접근성 테스트는
검사 도구를 페이지 로딩 전에 준비하도록 수정해 운영 CSP에서도 실행한다.

별도 실제 Go·OIDC·SQLite 인증 검사 42개가 통과했으며 실제 자원 검색 시나리오는
아홉 번째 검색 종류의 카탈로그 이동·주소·새로고침까지 확인한다. 내장 자산 189개의
해시·캐시·CSP·경로·기존 관리자 제공을 확인했다. 초기 번들은 255,034/350,000바이트이며
화면 47개와 선택 도구 5개가 용량 예산을 통과한다. 새로운 의존성은 없다.

기존 `/admin`, MCP 비즈니스 API와 기능의 미리보기 상태를 유지한다.
최종 PR·메인 CI, 정식 릴리즈와 운영 Stable 승격은 각각 별도 확인 대상이다.
