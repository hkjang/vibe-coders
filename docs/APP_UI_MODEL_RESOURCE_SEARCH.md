# 공급자별 모델 검색과 상세 연결

v0.86.102 후보 마일스톤. 기존 `/admin`과 모델 목록·상세·관리 기능을 유지한다.

## 사용자 동작

- 명령 팔레트의 **자원 검색 → 모델**에서 모델 이름을 검색한다. 같은 이름도 공급자별 결과로 구분하고 가상 모델 여부를 표시한다.
- 결과를 누르면 `/app/gateway/models?model=<모델>&model_provider=<불투명 참조>`의 기존 상세 화면을 연다. 새로고침과 직접 접근을 지원한다. 목록 캐시가 최신 데이터로 갱신되어도 같은 공급자의 모델을 찾도록 출처를 주소에 고정하지 않는다.
- **일부 목록만 확인됨**은 공급자 조회 실패, 오래된 캐시 또는 제한된 목록을 뜻한다. 확인된 안전한 결과는 계속 열 수 있고 검색을 재시도할 수 있다. 일부 결과가 없다는 사실을 전체 공급자에 해당 모델이 없다는 뜻으로 표시하지 않는다.
- 공급자가 느려도 다른 자원 종류의 조회 결과는 유지한다. 종류별 최대 10건이며, 더 많은 일치 항목이 있거나 목록 한도에 도달하면 검색 범위를 좁히도록 안내한다.
- v0.86.102 미만 서버에는 모델 검색 종류를 보내지 않는다. 기존 모델 화면은 계속 이용할 수 있다.

## 데이터와 권한

`POST /admin/resource-search`의 `model` 종류는 `admin:read`와 공개된 `gateway.models` 기능 권한이 필요하다. 모델 추론 권한만으로 관리자 메타데이터를 검색할 수 없다. 기존 인증·역할·기능 전환 경계를 재사용한다.

기존 `GET /admin/models`의 수집 함수를 공유한다. 별도 모델 저장소나 비즈니스 로직을 만들지 않는다. 같은 공급자 설정 지문, 20초 캐시, 동시 요청 통합, 공급자 조회 동시성·응답 크기·행 수 제한, 가상 모델과 중복 이름 처리를 사용한다. 최초 조회나 캐시 만료 후에는 공급자 모델 목록을 갱신할 수 있다. 검색 전체의 3초 기한 내에서 저장소 기반 종류를 먼저 조회하고 모델 목록을 마지막에 수집하며, 응답 순서는 사용자가 요청한 순서를 유지한다.

검색·응답은 안전한 모델 식별자, 표시 이름, 불투명 공급자 참조와 가상 모델 여부에 한정한다. 소유자·공급자 주소·모델 원문 메타데이터·키·프롬프트는 검색하지 않는다. 공급자별 설정 변경과 비활성화 이후 이전 캐시는 사용하지 않는다. 검색어를 URL이나 감사 이벤트에 넣지 않고 모델 실행을 호출하지 않는다. 물리 공급자와 가상 모델 공급자는 같은 표시 이름이어도 서로 다른 참조를 사용한다.

## 검증 범위

Go 검사는 최초 조회, 공유 캐시, 같은 모델 이름의 공급자별 구분, 가상 모델, 비밀·개인정보 제외, 권한, 기능 숨김, 설정 변경, 비활성화, 부분 실패, 취소, 상한과 정렬을 검증한다. 모델 조회 지연이 다른 자원의 기한을 소진하지 않는지 확인한다.

React 검사는 한글 결과·부분 실패 재시도·정확한 상세 주소·이전 서버·계정 및 기능 변경·계약 검증을 포함한다. 브라우저는 검색부터 상세와 새로고침, 키보드, 밝은·어두운 테마와 모바일 접근성·시각 회귀를 검사한다. 실제 Go/OIDC 인증 시나리오에도 모델 검색과 상세 복귀를 포함한다.

검증 결과와 출고 증빙은 완료 후 기록한다. 전체 Phase 0–6 완료나 Stable 승격을 의미하지 않는다.

### 후보 버전 로컬 검증 결과

- 전체 React 5,858개 / 395개 파일과 도구 검사 54개 통과. 선택 환경 검사 15개는 로컬에서 건너뛰었다. 관련 검색·모델 검사 92개도 통과했다.
- SQLite와 PostgreSQL 17에서 기존 모델 목록·검색 및 새 모델 검색의 race 검사가 통과했다. 마지막 SQLite 실행에는 관리자 조회 권한과 취소 기한 검사도 포함한다.
- 최종 내장 Go·운영 CSP·외부 네트워크 차단 브라우저 72개와 실제 Go/OIDC/SQLite 인증 46개가 실패·재시도·건너뛰기 없이 통과했다. 새 시각 기준 4개를 직접 확인하고 읽기 전용 비교 실행도 통과했다. 186개 에셋의 해시·캐시·MIME·CSP·직접 주소·404/405·기존 관리자 경로를 확인했다.
- 초기 압축 크기 261,364/350,000바이트, 화면 47개와 선택 도구 6개가 예산을 충족한다. 새 의존성 없이 Go 19개·npm 389개의 통합 SBOM과 라이선스를 갱신했다.
- 첫 브라우저 실행에서 새 검사의 화면 준비 순서와 기존 모델 정렬 검사의 CSP 도구 주입 방식을 보완했다. 실제 인증 검사는 기존 상세의 정확한 ‘가상’·‘에이전트 경로’ 표시를 검증하도록 정정했다. 이후 최종 브라우저·인증 검사는 동일한 운영 코드로 다시 통과했다.

원격 최종 CI, 실제 메인 CI와 정식 배포 검증은 별도 출고 단계에서 확인한다.
