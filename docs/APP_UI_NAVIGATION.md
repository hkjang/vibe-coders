# 한글 메뉴 탐색

v0.86.74 후보는 `/app` 공통 사이드바에서 메뉴 이름과 현재 위치를 더 쉽게 찾도록 한다.

## 메뉴 이름과 상태

- 펼친 사이드바와 모바일 메뉴는 긴 한글 이름을 줄바꿈한다. 전환 상태는 이름 아래에 표시한다.
- 축소 메뉴는 전체 이름과 상태를 툴팁과 접근 가능한 이름으로 제공한다.
- 기존 권한·점진 배포 설정으로 허용된 메뉴만 표시한다. 즐겨찾기와 메뉴 그룹 접기 설정은 유지한다.
- 모바일 탐색은 대화상자로 열리며 키보드 초점을 가두고 Escape로 닫은 뒤 열기 버튼으로 돌아간다.

## 현재 위치와 스크롤

화면 진입·직접 주소·새로고침·화면 크기 변경 시 현재 메뉴를 사이드바의 보이는 영역으로
이동한다. 본문 스크롤과 키보드 초점은 바꾸지 않는다. 즐겨찾기와 일반 메뉴에 같은 화면이
있으면 이미 보이는 항목을 유지한다. 사용자가 접어 둔 그룹을 자동으로 펼치지 않는다.

메뉴 정보가 그대로인 자동 갱신에서는 사용자가 직접 스크롤한 위치를 유지한다. 권한이나
전환 상태가 달라져 메뉴 구성이 바뀌면 현재 메뉴 표시를 다시 확인한다. 보이지 않는 메뉴의
권한을 추가하거나 기존 관리자 주소를 변경하지 않는다.

## 검증 범위

1440×900, 1024×768, 390×844, 844×390의 밝은·어두운 테마에서 긴 이름과 상태의 표시,
키보드 초점, 축소 설정 복원, 모바일 닫기·초점 복귀와 axe 검사를 수행한다. 많은 메뉴가 있는
데스크톱·가로 모바일에서는 첫 진입·새로고침과 갱신 후 수동 스크롤 보존을 검사한다.
기존 주요 화면의 시각 기준도 함께 검증한다. 브라우저 합성 검증은 모든 실제 사용자 환경의
접근성 인증이나 전체 기능의 Stable 승격을 의미하지 않는다.

기존 `/admin`과 API·인증·권한은 유지하며 기능별 Preview 검증과 Phase 0–6 전환을 계속한다.
