# 알림 표시 시간과 오류 확인

저장·내보내기·가져오기 중 발생한 오류는 짧은 시간이 지나도 사라지지 않습니다. 원인을 읽은 뒤 한글 `알림 닫기` 버튼으로 닫을 수 있으며, 키보드로도 조작합니다. 오류를 표시할 때 현재 입력 초점을 빼앗지 않습니다.

경고는 10초 동안 표시합니다. 성공·정보 알림은 기존처럼 자동 종료하며 기존 설명·요청 번호·닫기 콜백을 전달합니다. 공통 알림 모듈을 통해 직접 실행과 변경 요청의 표시 시간을 일치시키고, 제품 코드에서 외부 알림 함수를 직접 가져오면 린트가 실패하도록 검사합니다. 기존 인증·권한·작업 취소·민감정보 보호·변경 요청 재시도 정책은 유지합니다.

## 검증

선행 v0.86.168 생산 빌드에서 스킬 내보내기 서버 오류와 두 종류의 가져오기 검증 오류가 5.5초 후 사라지는 문제를 재현했습니다. 수정 전 실사용 브라우저 검사 5개 중 오류 유지 4개가 실패하고 성공 알림 자동 종료 1개는 통과했습니다. 잘못된 테스트 준비와 캡처 대상 때문에 실패한 중간 실행은 별도로 보존합니다.

실제 공통 알림·화면·변경 요청을 사용하는 관련 React 62개와 Node 65개(선택 검사 16개 제외), 수정된 생산 빌드의 브라우저 40개를 통과했습니다. 밝은 1440px과 어두운 390px·확대 글꼴에서 오류 문구와 키보드 닫기, 접근성, 가로 넘침을 확인했습니다. 가져오기 검증 실패 시 변경 호출은 없고 성공 파일은 한 번만 내려받습니다. 브라우저 검사는 재시도·제외·기준 이미지 변경 없이 실행했습니다.

전체 React 검사에서는 7,420개가 통과하고 기존 경고 호출 인자 기대값 한 건이 새 10초 규칙을 반영하지 않아 실패했습니다. 기대값과 새 검사 타입을 수정한 뒤 관련 62개를 통과했습니다. 최초 린트·타입 검사 실패와 수정 후 통과 기록을 구분하며 전체 검사 재통과로 표현하지 않습니다.

OpenAPI 계약·린트·포맷·엄격한 타입·생산 빌드·통합 SBOM과 실제 Go 내장 경로·기존 관리자·실시간 OpenAPI를 확인했습니다. 초기 전송은 284,073바이트이며 화면 48개와 선택 도구 9개가 성능 예산을 충족합니다. 최종 후보 리뷰·CI·메인 병합·공개 출고, 운영 Stable 승격과 전체 Phase 0–6 인수는 별도로 진행합니다.
