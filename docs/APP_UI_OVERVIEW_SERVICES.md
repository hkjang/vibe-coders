# 운영 개요의 연결 서비스 — v0.86.128 개발 후보

운영 개요의 운영 상태 탭에 MCP 도구 호출과 자연어 SQL 처리 요약을 추가한다.
메뉴와 같은 권한·전환 상태를 적용하며 숨겨진 기능은 조회하지 않는다. 기존 화면 단계와
이전 백엔드는 지원하지 않는 요약 API를 호출하지 않고 허용된 상세 화면을 연결한다.
백엔드 v0.86.128 이상이 필요하며 서비스별 실패는 다른 요약을 중단시키지 않는다.

MCP는 기존 `/admin/mcp/overview`를 사용한다. 최근 24시간 호출·오류 기록을 상위 500개
도구 목록에서 합산하던 방식 대신 전체 MCP 기록을 집계한다. 기존 전역 관리자 조회 범위와
전체 기간 `summary`는 유지한다. 오류 기록에는 결과 오류도 포함되므로 고유한 실패 호출 수나
실패 확률로 표시하지 않는다. 발견된 서버·도구와 마지막 발견 시각은 현재 연결 테스트 결과가
아니다. 저장소 조회 실패를 0건으로 처리하지 않고 민감한 오류 내용 없는 실패 응답을 제공한다.

`GET /admin/text2sql/summary?window=1h|24h|7d|30d`는 기존 팀별 권한 확인과 통계 함수를
공유한다. 질문·SQL·스키마·실행 결과·자격 증명을 읽어 응답하지 않는다. 검증 통과율은 검증
통과 건수/전체 건수이며 실행 성공률이 아니다. 검증 미통과와 오류 기록은 중복될 수 있다.
그림자 실행은 기존 통계와 동일하게 제외한다. 기본 기간은 24시간이며 중복·추가·잘못된
매개변수는 거부한다. 두 요약의 `since`는 포함 시작 시각이고 `generated_at`은 집계 관찰
시작 시각이다. 기존 Since 집계이므로 배타적 종료 시각을 보장하지 않는다.

요약은 활성 탭에서만 조회·자동 갱신한다. 계정·팀·원문 조회 권한 변경과 401/403 응답 뒤
이전 데이터·늦은 응답을 폐기한다. 일시적 오류는 마지막 정상 데이터와 갱신 실패를 함께
표시한다. 오류 상태에서도 허용된 상세 화면 링크와 키보드 재시도를 제공한다.
0건·미설정·비활성은 정상 성공률 0%로 표시하지 않는다.

React 1,197개(82개 파일)·내장 Go 브라우저 94개·실제 Go/OIDC/SQLite 인증 50개·실제 Keycloak HTTPS 5개와 사용자 DB 검증·보고서와 실패 산출물 29개를 통과했다.
SQLite와 PostgreSQL 17에서 MCP 503개 도구·기간 밖/일반 도구 제외·결과 오류 집계와 Text2SQL 관리자/읽기 전용/팀별 통계의 기존 API 정합성·원문 미포함·실패 응답을 검사했다. PostgreSQL 검사는 race 옵션으로 수행했고 CI에 추가했다. 실제 관리자·읽기 전용 관리자에서도 화면 수치를 인증 API와 대조했다.
두 테마·1440/390px 시각 기준 8장을 직접 검토했다. 새 연결 서비스 4장을 추가하고 게이트웨이 배너의 집계 범위를 명확히 한 기존 4장만 갱신했다. 모바일 지표명을 줄이고 고정 헤더가 긴 요소 캡처를 가리지 않도록 모바일 시각 검사 높이를 2,400px로 조정했다. 비교 허용치는 유지했고 키보드·axe·본문 넘침·고정 비교를 통과했다. 최초 문구 기대값 한 곳을 수정한 뒤 전체 관련 React 검사를 통과했다.
타입·린트·포맷·실제 OpenAPI·통합 SBOM·기존 관리자/도메인/내장 UI Go 회귀·vet·번들 예산을 통과했다. 초기 압축 번들은 262,748바이트다. 최종 운영 코드·실제 인증/제품 검사 소스와 내장 산출물의 해시 일치를 확인했다.
