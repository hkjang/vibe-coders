# 운영 추이의 시간 범위·구간 비교 — v0.86.122 개발 후보

## 화면 동작

운영 개요의 사용 현황에서 최근 1시간·24시간·7일·30일 추이를 선택한다. `trend` 주소를
직접 열거나 새로고침하고 탭을 다시 열어도 선택 기간을 유지한다. 기존 `/admin/timeseries`를
재사용하며 1시간·24시간 조회는 시간별, 7일·30일 조회는 일별 집계를 사용한다.

응답의 실제 집계 시작 시각, 한국 시간 기준, 집계 단위를 표시한다. 시작·현재 진행 중인
구간은 일부 시간만 포함하며 기록이 없는 구간은 응답에서 생략된다. 그래프는 수신된 기록을
시간순으로 연결한다. 분 단위 실시간 그래프나 빈 구간의 0건을 새로 만들어 표시하지 않는다.
요일·시간대 활동은 별도의 7일·30일 범위이고 다른 사용량 표는 보존 기록 집계다.

요청·토큰·비용의 수신 구간 합계와 한 표를 제공한다. 구간·요청·토큰·비용을 정렬하면 표와
CSV에 동일하게 적용되며 그래프의 시간순은 유지한다. CSV는 ISO 8601 UTC 시각과 응답 비용의
원래 수치를 사용한다. 0이 아닌 작은 비용은 소수 여섯 자리 또는 지수 표기로 구분한다.
좁은 화면의 차트는 축 글자 크기를 유지하며 키보드나 터치로 가로 이동할 수 있다.
서버가 보내는 구간은 이미 한국 시간이므로 브라우저의 시간대로 다시 변환하지 않는다.
잘못된 구간 원문은 표시·내보내지 않고 확인 불가로 안내한다.

조회 거부 시 추이·표·CSV를 정리하고 명시적으로 재조회한다. 계정·기간·응답·조회 객체 또는
화면이 바뀐 뒤 캡처된 이전 CSV 동작은 사용할 수 없다. 일시 오류는 마지막 정상 기록과 갱신
안내를 유지하며 실제 빈 응답에서는 내보내기를 비활성화한다. CSV는 브라우저에서 만들고
데이터를 URL이나 영속 저장소에 남기지 않는다. 기존 API·권한·관리자 화면을 유지한다.

## 검증

관련 React 1,264개(65개 파일), 고정 시각 기준을 포함한 내장 Go 브라우저 60개, 실제 Go/OIDC/SQLite 인증 48개를 통과했다.
관리자·읽기 전용 관리자가 실제 1시간 API 응답과 같은 순서·시각·반올림 전 비용을 CSV로 받는지 확인했다.
실제 Keycloak HTTPS 5개와 사용자 DB 검증, 보고서·실패 산출물 29개도 통과했다.
새 시각 기준 4장(밝은/어두운 테마·1440/390px)을 직접 검토했고 키보드 가로 이동·axe·본문 넘침을 검사했다.
최초 실행에서 잘못 지정한 재시도 버튼 이름·가로 이동 키를 보정했고, 새 기준 생성 후 60개를 재시도·건너뜀 없이 통과했다. 기존 시각 기준은 변경하지 않았다.
타입·린트·포맷·실제 Go OpenAPI 계약·통합 SBOM·1시간 하한/한국 시간 구간/읽기 권한 Go 계약·기존 관리자 회귀·내장 UI 전체·vet·번들 예산을 통과했다. 초기 압축 번들은 262,480바이트다.
후보 CI 11개·리뷰·최종 메인·정식 배포 검증은 별도 단계다.
합성 화면 검사는 실제 운영 데이터 인수를 대신하지 않으며 전체 Phase 0–6는 계속 진행한다.
