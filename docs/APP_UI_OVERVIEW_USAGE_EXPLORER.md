# 운영 개요 사용량 탐색 — v0.86.120 개발 후보

## 사용자 동작

`/app/overview?tab=usage`의 상태·API 키·모델·클라이언트 IP·언어 표를 공통 표로 정리한다.
각 표에서 한글 검색, 열 머리글 정렬, 수신 건수 대비 표시 건수, 검색 지우기를 제공한다.
키보드로 정렬·검색 지우기를 실행하며 지우기 후 입력으로 돌아간다.
기록 없음과 검색 결과 없음은 다른 안내로 표시한다.

‘상위 사용자’는 ‘요청량 상위 API 키’로 바로잡았다. 사용자 수나 전체 키 목록이 아니다.
기존 `/admin/stats`의 보존 기록 집계를 사용하며 추이 그래프의 기간 선택은 적용되지 않는다.
API 키는 요청 수 기준 최대 5개, 모델·IP·언어는 요청 수 기준 최대 50개다.
비용순으로 바꾸어도 이 수신 범위 안에서만 정렬되며 전체 비용 순위를 새로 조회하지 않는다.
언어별 요청 수는 한 요청이 여러 언어에 속할 수 있어 전체 요청 수와 다를 수 있다.
상태 비중은 검색 전 수신 상태의 요청 수 합계를 분모로 유지한다.

검색은 화면에 표시한 이름·팀·식별자만 대상으로 하며 원문, 숨겨진 소유자·키 값을 검색하지 않는다.
검색어·표 데이터는 URL·브라우저 저장소에 기록하지 않고 새로고침이나 탭 종료 시 초기화한다.
기존 주소의 기간·탭 상태, 인증·권한·조회 거부·부분 오류·갱신 흐름은 유지한다.
운영 API·기존 `/admin` 화면·의존성은 변경하지 않는다.

## 검증

관련 React 569개(25개 파일), 내장 Go 브라우저 80개, 실제 Go/OIDC/SQLite 인증 46개를 통과했다.
모바일·밝은/어두운 테마·키보드·axe를 검증하고 새 시각 기준 4장을 직접 확인했다.
첫 시각 실행에서는 새 기준 4장이 없어 생성 단계가 실패했으며, 검토 뒤 고정 비교 80개를 재시도·건너뜀 없이 통과했다. 기존 시각 기준은 변경하지 않았다.
타입·린트·포맷·실제 Go OpenAPI 계약·통합 SBOM·Go 기존 관리자 회귀·내장 UI 전체 검사·vet가 통과했다. 초기 압축 번들은 262,416바이트다.
브라우저의 합성 운영 통계 검사는 실제 운영 데이터 정합성 인수와 구분한다. 후보 CI·리뷰·최종 메인·정식 배포 검증은 별도로 진행한다.
운영 Stable 인수와 전체 Phase 0–6 완료를 뜻하지 않는다.
