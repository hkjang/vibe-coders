# 운영 개요 작업 공간

v0.86.104 후보 마일스톤. 기존 API를 재사용하고 `/admin`과 기능별 미리보기 단계를 유지한다.

## 사용자 동작

- 보존 트래픽·비용, 프로세스 런타임, 라우팅, 운영 위험, 운영 기반 영역에서 관련 관리 화면으로 이동한다. 메뉴와 같은 기능 공개 상태·역할·점진 배포·기존 화면 전환 정책을 적용하며 조회 권한이 없는 링크는 표시하지 않는다.
- 선택 기간의 라우팅 상태 링크는 같은 기간과 저하 판단 점수 70을 전달한다. 보존 요청·비용 등 다른 링크는 화면 이름을 명시하며 지원하지 않는 기간 필터를 임의로 적용하지 않는다.
- 각 조회 영역은 로딩·실패·마지막 정상 데이터를 구분한다. 401/403으로 조회가 거부된 영역은 이전 데이터와 캐시를 폐기하고 자동 재조회를 멈춘다. 해당 영역의 재시도 또는 전체 새로고침으로 권한을 다시 확인한다. 다른 정상 영역은 계속 표시한다.
- 일시적인 서버 오류는 마지막 정상 데이터와 갱신 실패 안내를 함께 표시한다. 요청 ID는 길이와 현재 자격 증명 접두사를 검사한 안전한 값만 표시하며 서버의 원문 오류를 그대로 출력하지 않는다.
- 전체 새로고침은 현재 열린 조회 영역을 한 번씩 갱신한다. 사용 현황의 추이·시간대와 기능 맵은 해당 탭이 열린 동안만 조회한다. 숨겨진 브라우저 탭에서는 자동 갱신을 중단한다.
- 게이트웨이 시작하기는 요청 통계와 운영 설정 조회가 성공한 경우에만 표시한다. 설정 정보를 확인하지 못한 상태를 미설정으로 단정하지 않으며 사용할 수 있는 기능만 연결한다.

360px 이상 모바일에서는 숫자 지표를 두 열로 비교하며, 더 좁은 화면에서는 한 열을 유지한다.

## 데이터와 권한

보존 트래픽·비용은 저장된 요청 로그의 전체 보존 기간, 프로세스 런타임은 재시작 이후,
라우팅은 선택한 기간, 운영 위험·기반은 현재 조회 시점의 의미를 유지한다.
기존 관리자 통계·운영·라우팅 API의 서버 권한 검사와 응답은 바꾸지 않는다.

조회 소유권은 계정·팀·세션·역할·조회 권한·기능 접근과 마스킹 기준에 연결한다.
변경 시 이전 요청을 취소하고 캐시를 제거하며 늦은 응답이 새 화면에 반영되지 않게 한다.
공개 `/health` 응답은 비공개 관리 데이터와 구분해 기존 공용 조회를 사용한다.

## 검증 상태

권한별 링크, 조회 거부와 독립 복구, 이전 계정의 늦은 응답, 중복 새로고침 방지,
정상 데이터 보존과 오류 표시를 구성요소 검사로 검증한다. 실제 브라우저에서 기간 전달,
키보드 이동, 새로고침, 첫 실행 안내, 두 테마·모바일·axe·시각 회귀를 확인한다.
최종 검사와 CI·정식 배포 결과는 완료 후 기록한다. 전체 Phase 0–6 완료나 Stable 승격은 별도 인수 대상이다.

### 후보 버전 로컬 검증 결과

- 고정 소스의 전체 React 5,900개 / 401개 파일, 보조 도구 54개를 통과했다. 선택 환경 도구 검사 15개는 로컬에서 건너뛰었으며 실제 인증 검증과 구분한다.
- 최종 Go 내장·외부 네트워크 차단 브라우저 45개와 실제 Go/OIDC/SQLite 인증 46개가 실패·재시도·건너뛰기 없이 통과했다. 최종 이미지 기준을 생성한 뒤 읽기 전용 시각 비교도 통과했다.
- 첫 브라우저 실행에서 합성 공급자 데이터의 필수 식별자 누락과 탭 재진입 초기 조회 완료 전 호출 수 측정을 발견했다. 응답 계약을 유지한 채 데이터를 보완하고 초기 조회 완료를 기다린 후 수동 새로고침의 정확한 한 번 호출을 검증한다.
- 새 시각 기준 4장과 기존 운영 개요 기준 3장을 검토했다. 1440px/390px의 두 테마, 키보드·axe, 모바일 가로 경계와 한글 줄바꿈을 확인했다.
- 내장 자산 186개의 해시·캐시·MIME, CSP, 깊은 주소·누락 자산 404·POST 405·기존 관리자 응답을 확인했다. 초기 압축 번들은 261,450/350,000바이트이며 화면 47개·선택 도구 6개의 예산을 충족한다.
- 기존 관리자 정적·행위 회귀와 Go 정적 UI 검사, 린트·포맷·타입·프로덕션 빌드·실제 OpenAPI 생성 계약을 통과했다. Go 19개·NPM 389개 의존성을 포함한 통합 SBOM과 라이선스를 갱신했다.

최근 공개 검증 기준선은 v0.86.101이다. 이 후보의 최종 PR·실제 메인 CI와 정식 배포 검증은 별도 출고 단계에서 진행한다.
