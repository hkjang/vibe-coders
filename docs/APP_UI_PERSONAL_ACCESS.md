# 개인 세션·개발 도구 연결 운영 안내

v0.86.72 후보는 `/app/me?tab=keys`의 로그인 세션과 연결 설정·진단을 개선한다.
내 키 발급·권한·회전·폐기와 기존 `/admin`을 유지한다. 기능 상태는 Preview이며 운영 Stable
승격과 전체 Phase 0–6 인수는 별도로 계속한다.

## 로그인 세션

활성 세션의 접속 IP·기기·현재 여부·SSO 연결·로그인과 만료 시각을 표시한다. 받은 목록 안에서
검색·정렬·페이지 이동·열 설정·CSV를 제공하고 주소로 조건을 복원한다. 조회 실패를 빈 목록으로
표시하지 않으며 이전 데이터와 갱신 시각을 구분한다. CSV에는 수식 실행 방지를 적용한다.

현재 세션은 사용자 메뉴에서 로그아웃한다. 종료할 기기·IP·세션 ID를 확인한 뒤 최신 목록을
다시 조회하고, 대상이 사라졌거나 일괄 종료 목록이 달라지면 재확인한다. 현재 세션을 확인하지
못하면 종료 버튼을 잠근다. 서버의 기존 DELETE는 본인의 현재 세션도 종료할 수 있으므로 이
보호는 React 화면의 작업 방식이다. API 키는 세션 종료로 폐기되지 않는다.

기존 일괄 API는 현재 JWT 세션을 제외한 본인의 미폐기 세션을 종료한다. 만료 기록도 포함하므로
서버 종료 건수는 화면의 활성 세션 수와 다를 수 있다. 확인 직후 생긴 새 세션도 종료될 수 있다.
사전 조회는 서버의 원자적 조건부 변경(CAS)이 아니다. 세션·연관 갱신 토큰의 저장은 하나의
트랜잭션에서 커밋하며 갱신 토큰 저장 실패 시 세션 변경도 되돌린다. 감사 기록은 기존대로
커밋 후 기록하므로 감사까지 원자적으로 보장하는 것은 아니다.

진행 중 작업은 중복 전송하지 않으며 대상·상태가 틀린 응답이나 응답 유실을 성공으로 표시하지
않는다. 동일 브라우저 QueryClient의 세션 작업을 잠그고 화면 탭을 바꿔도 잠금을 유지한다.
저장 상태를 확인한 뒤 페이지를 새로고침한다. 여러 브라우저 탭의 멱등성은 제공하지 않는다.

## 연결 설정과 진단

선택한 도구는 `connection_client`에 저장한다. 설정을 불러오면 모델 API·MCP 주소, 추천 모델,
권한과 모델 목록을 확인한다. HTTP(S)·동일 출처·정해진 경로를 검사하고 사용자 정보·쿼리·해시·
명령 삽입 문자가 있는 주소를 거부한다. 서버의 자유 형식 명령·설정은 브라우저 캐시에 넣지 않고
검증한 주소로 Python SDK·HTTP MCP JSON 예시를 만든다. 복사한 `<YOUR_API_KEY>`는 실제 개발
도구에서 본인 키로 교체한다. 클라이언트 버전별 HTTP MCP 지원 여부는 해당 도구에서 확인한다.

진단 POST는 버튼 또는 명시적 재조회로만 실행한다. 자동 갱신·창 복귀·전역 새로고침은 진단을
재실행하지 않는다. 브라우저 JWT에서는 본인의 가장 최근 활성·미만료 키 메타데이터를 검사하고
실제 모델·MCP 연결 검사를 건너뛴다. ‘검사 안 함’은 연결 성공이 아니다. 키 목록을 읽지 못하면
실패를 표시하고 권한·모델 검사를 건너뛰며 한도 조회 오류도 실패로 보고한다.

기존 API에 실제 프록시 키를 사용하는 도구는 모델 목록과 MCP initialize/tools-list를 검사한다.
모델 응답 생성이나 설정 저장은 하지 않는다. 익명 진단은 기존 HTTP 200 인증 실패 응답을
유지하며 비공개 키 정보를 반환하지 않는다. 설정 조회는 기존 JWT·프록시 키 인증을 재사용하고,
세션 조회·종료는 JWT만 허용한다. 관리자 권한을 새로 요구하지 않는다.

계정·팀·역할·인증 세션·조회 권한이 바뀌면 이전 조회와 늦은 응답을 폐기한다. 401/403은 접근
경계를 닫으며 변경·진단 POST는 인증 갱신 뒤 자동 재전송하지 않는다. 읽기 전용에서는 세션
종료·진단 재시도를 차단하고 설정 조회는 제공한다. 이미 전송된 서버 작업을 취소하는 것은 아니다.

## 검증

실제 Go HTTP·SQLite·PostgreSQL 검사는 본인 세션 범위, 현재 세션 유지, 갱신 토큰 동시 종료,
실패 롤백, JWT·프록시 키·익명 진단 차이, 만료 키 제외, DB 오류 표시와 기존 응답을 확인한다.
React 검사는 응답 계약·계정 전환·지연 응답·조회 권한·읽기 전용·불확실 결과·명시적 진단을
다룬다. 공개 합성 브라우저 검사는 검색·주소 복원·CSV·설정 복사·키보드·세 가지 화면 크기·두
테마·axe·시각 기준을 확인하며 실제 인증 브라우저 검사와 구분한다. 최종 실행 결과는 PR·CI와
릴리즈 기록을 기준으로 확인한다.

로컬 전체 React 5,513개/360파일과 Node 보조 검사 49개가 통과했다(브라우저 환경 전용 13개 제외).
세션·연결·기존 키 편집·공통 확인창 집중 검사 145개, 실제 Go 저장소·Proxy·AppUI 회귀와
PostgreSQL 개인 세션·진단 계약의 race 검사를 통과했다. 전체 Go 검사에서 발견된 기존 회귀
검증의 취소 테스트는 응답과 취소의 경합을 없애도록 fixture를 고정하고 50회 반복 확인했다.
운영 회귀 실행 로직은 바꾸지 않았다. 합성 브라우저와 시각 기준은 최종 PR 검증 기록을 함께 확인한다.
