# 개인 콘솔 운영 안내

v0.86.71 후보의 `/app/me`는 내 홈, 요청·영수증, 스킬·추천을 개선한다. 기존 내 키·연결 화면과
`/admin`은 유지한다. 기능은 Preview이며 운영 Stable 승격이나 Phase 0–6 전체 완료를 뜻하지 않는다.

## 조회와 수치

- 오늘·이번 달은 서버 UTC 날짜 경계다. 개인 리포트는 조회 시각부터 최근 7일 또는 30일이며 직전 같은 길이 기간과 비교한다. 이전 비용이 0이면 증감률을 표시하지 않는다.
- 최근 요청은 서버에서 최대 20·50·100건을 가져온다. 검색·상태 필터·정렬·페이지·CSV는 받은 목록에 적용하며 전체 이력 조회나 서버 페이지네이션으로 표시하지 않는다.
- 영수증은 주소의 `receipt`로 직접 열 수 있고 목록 필터와 독립적으로 조회한다. 본인 요청의 모델·비용·토큰·라우팅·정책·도구 메타데이터를 보여 주며 원문 질문·응답·SQL·도구 인자를 새로 노출하지 않는다.
- 스킬 실행 통계는 최근 30일 전체 사용자 기준, 만족도는 전체 저장 평가 기준이다. 성공률 응답은 0–100 퍼센트다. 실행·평가가 없으면 `—`로 표시한다.
- 모델 용도 추천은 30일 사용량과 관리자 태그, 팀 평가 우수 모델은 최근 90일 평가의 상위 3개다.
- 알림은 여러 운영 신호를 모은 목록이며 읽음 여부를 추적하는 알림함이 아니다. 일부 조회 실패는 경고로 표시하고 해당 수치를 확정된 0으로 취급하지 않는다.

## 추천과 변경

추천 목록은 기존 API에 `refresh=false`를 보내 저장된 목록만 읽는다. 자동 갱신·화면 재진입·의견
제출 때문에 추천 ID가 바뀌지 않는다. ‘추천 새로 계산’만 `refresh=true`로 다시 계산한다.
파라미터 생략과 true는 기존 재생성을 유지하므로 Legacy 호출과 호환된다. 재생성과 의견 전송은
같은 브라우저 QueryClient 안에서 직렬화하며, 의견 응답은 서버의 status·kind·action으로 확인한다.

할 일은 같은 종류를 7일 숨길 수 있다. 스킬 신청 사유와 평가 의견은 500자 이내로 검증하며
인증정보로 보이는 값과 제어 문자를 전송하지 않는다. 기존 값의 탐지 완전성을 보장하지는 않는다.
읽기 전용으로 전환되면 입력을 보존하고 제출을 차단한다. 이미 전송한 서버 작업을 취소하는 것은 아니다.

응답이 유실되거나 대상·상태가 맞지 않으면 성공으로 표시하지 않고 같은 작업의 재전송을 막는다.
탭을 바꿔도 진행 중·불확실 상태는 유지된다. 저장 상태를 확인한 다음 브라우저 페이지를 새로고침한다.
서버의 원자적 조건부 변경, 여러 탭의 멱등성 또는 중복 의견의 전역 방지는 제공하지 않는다.

## 권한과 데이터 수명

조회는 기존 개인 API와 인증을 재사용하며 관리자 스코프를 새로 요구하지 않는다. 개인 홈·요청·추천은
서버가 JWT 또는 소유자가 있는 API 키로 확인하고, 스킬·모델 용도는 기존 JWT 인증을 요구한다.
React는 인증된 사용자와 동일한 user_id·team·요청 ID를 확인하고 허용한 메타데이터만 캐시에 저장한다.
계정·팀·세션·역할·조회 권한이 바뀌면 이전 데이터·초안을 폐기한다. 서버 401/403 이후에는 이전
조회도 숨기며 수동 권한 재확인을 요구한다. 변경 요청은 인증 갱신 뒤 자동 재전송하지 않는다.

## 검증 경계

Go HTTP·저장소 테스트는 추천 조회의 무변경성·Legacy 재생성·JWT/API 키 요청 소유권·영수증의
도구 오류 boolean·스킬 퍼센트·실제 변경 응답·부분 실패를 검증한다. PostgreSQL에서도 개인
소유권과 추천·스킬 계약을 검사한다. React 회귀는 지연 응답·계정 전환·권한 거부·읽기 전용
초안·비밀값 입력·불확실 응답·URL 복원을 다룬다. 브라우저 fixture는 공개 합성 데이터로 화면·키보드·
반응형·테마·axe·CSV를 확인하며 실제 Go 로그인 브라우저 검사와 구분한다. 후보의 실제 실행 결과와
CI·릴리즈 검증은 해당 PR과 릴리즈 기록을 기준으로 확인한다.

로컬 검증: 전체 React 5,472개/357파일과 Node 보조 검사 49개 통과(브라우저 환경 전용 13개 제외),
추가 경로·권한·응답 검사 39개 통과. 실제 Go·PostgreSQL race·기존 Admin 회귀와 AppUI,
OpenAPI 재생성 일치·타입·정적 검사·배포 빌드가 통과했다. 합성 브라우저 13개는 재시도 없이
통과했으며 3개 화면 크기·2개 테마에서 axe·키보드 스크롤·초점 복귀를 확인했다.
시각 기준 이미지 4개를 검토했다. 로컬 검사는 PR·메인 전체 CI 및 최종 배포 이미지 검증을 대체하지 않는다.
