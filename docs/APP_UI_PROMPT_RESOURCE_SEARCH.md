# 프롬프트 자산·실험 이름 검색

v0.86.97 후보는 명령 팔레트의 자원 검색에서 프롬프트 자산과 실험을 찾고 기존 상세 화면을 연다.

- `Ctrl/Cmd + K` → `자원 검색`에서 이름 두 글자 이상을 입력한다.
- 같은 이름이라도 `프롬프트 자산`, `프롬프트 실험`으로 구분한다. 방향키와 Enter로 이동한다.
- 자산은 자산 관리소의 상세 패널, 실험은 선택한 실험의 테스트 케이스 영역을 연다.
- 선택 식별자를 주소에 유지해 직접 접근·새로고침·뒤로 및 앞으로 이동을 지원한다.
- 검색 실패나 일부 종류의 조회 실패는 재시도할 수 있다. 상세 로딩과 오류는 기존 화면을 사용한다.

## 조회와 권한

기존 `POST /admin/resource-search`에 `prompt_asset`, `prompt_experiment`를 추가한다.
기존 자산 목록과 실험 목록처럼 `admin:read`가 필요하며 각각 `prompts.library`, `prompts.lab`
기능의 역할·공개 상태를 적용한다. 쓰기 권한은 필요하지 않다. v0.86.96 이하 서버에는 새 종류를
요청하지 않는다. 계정·팀·세션·권한 변경 시 이전 검색과 늦은 응답을 폐기한다.

자산의 저장된 이름, 실험의 저장된 제목과 식별자만 선택한다. 본문·설명·실험 입력·결과·
소유자·팀·사용 통계는 검색하거나 반환하지 않는다. 실제 상세 조회는 기존 API 및 권한을 사용한다.
명령 팔레트에서 자원을 선택하는 것만으로 모델 호출이나 실험 실행이 일어나지 않는다.

검색어는 URL에 넣지 않는 읽기 전용 POST 본문이며 이 처리기에서 기록하지 않는다.
2~128자, 이름 부분 일치, 종류별 최대 10개, 공통 3초 제한을 유지한다. SQL 와일드카드는
문자로 처리한다. 이름은 256자/1024바이트, 식별자는 512자/2048바이트로 제한하고 기존
프롬프트 상세 화면의 512 UTF-16 코드 단위 제한도 지킨다. 민감정보 형태는 제외한다.
정렬은 이름과 식별자 순이다. 반환 한도는 스캔 행 수 제한이나 정확한 전체 개수가 아니다.

## 검증 범위

SQLite·PostgreSQL의 이름 전용 조회, 한글·대소문자·반환 한도·문자 그대로의 검색,
읽기 전용 인증과 기능 공개 상태, API 스키마 일치, 종류별 상세 주소와 계정 변경을 검사한다.
브라우저에서는 키보드 선택, 필터와 독립적인 상세, 새로고침·뒤로 및 앞으로 이동,
실패 후 재시도, 밝은/어두운 테마와 좁은 화면, axe 접근성 및 실제 인증 흐름을 검증한다.
실제 Go·OIDC·SQLite 인증 42개와 SQLite·PostgreSQL 검색 계약(race 포함), 관련 React 33개를 통과했다.
Go 내장 자산·운영 CSP·외부 네트워크 차단 브라우저 69개가 재시도·건너뛰기 없이 통과했다.
이 중 신규 7개와 시각 기준 4개를 확인했다. 업무 API의 합성 응답 검증과 위 실제 인증 검증은 구분한다.
초기 번들은 255,048/350,000바이트이며 화면 47개·선택 도구 5개가 예산 안이다.
전체 React 5,781개(386개 파일), 타입·린트·포맷·OpenAPI·Go 내장 경로 검사를 통과했다.
최종 CI·출고 결과는 PR과 릴리즈 기록에 남긴다. 운영 Preview 상태를 유지하며 전체 Phase 인수나
실제 운영 사용 검증에 의한 Stable 승격을 뜻하지 않는다.
