# 레드팀 증적 마스킹과 원문 조회

v0.86.146 개발 후보는 `/app/redteam`의 실행 결과와 증적 상세를 기본 마스킹본으로 제공한다. 원문 조회는 기존 `raw_prompt_view` 권한과 서버의 역할 검사를 모두 통과한 사용자가 **원문 보기**를 눌렀을 때만 수행한다. 변경·재실행 권한과 원문 조회 권한은 별개다.

## 화면 사용

1. 실행 이력에서 결과를 열고 검사별 **증적**을 선택한다. 요청·응답의 마스킹본, 제공자·모델·비용·지연과 도구 호출 건수를 확인한다.
2. 원문을 저장한 증적이고 조회 권한이 있으면 **원문 보기**가 표시된다. 버튼을 누를 때마다 서버가 권한을 다시 확인하고 조회 사용자·결과 ID·증적 ID를 감사 기록에 저장한 뒤 원문을 반환한다.
3. **원문 닫기**는 원문과 해당 조회 캐시를 폐기한다. 다른 증적 선택, 패널 종료, 계정·세션·조회 권한 변경도 기존 원문을 폐기한다. 새로고침·포커스 복귀·공통 캐시 갱신은 원문을 자동 조회하지 않는다.

원문 감사 기록 저장 실패 시 원문을 반환하지 않는다. 오류의 요청 ID와 수동 재시도 버튼을 제공하며 자동 재시도하지 않는다. 원문을 다시 열면 새로운 감사 기록을 남긴다. 보관된 원문이 없는 경우 이를 안내하며 원문 확인을 위해 실제 모델 재실행을 권하지 않는다.

원문이 없는 과거 데이터에서 마스킹본 대신 원문으로 자동 대체하지 않는다. 도구 인수와 임의 헤더·시드에는 별도 마스킹본이 없으므로 기본 화면에 넣지 않는다. 원문 도구 인수는 명시적인 원문 조회에서만 표시한다. 헤더 요약은 원문 조회에서도 허용된 운영 메타데이터만 표시하며 요청 시드나 임의 필드를 포함하지 않는다.

## API와 호환성

기존 GET API에 `view=app`을 지정한다.

- `/admin/redteam/runs/{id}/results?view=app`: `masked: true`와 실행·결과·마스킹 프롬프트를 반환한다.
- `/admin/redteam/results/{id}/evidence?view=app`: `masked`, `raw_allowed`, `raw_available`, `tool_call_count`와 마스킹 증적을 반환한다.
- 같은 증적 API에 `reveal=raw`를 추가하면 권한 검사와 `redteam.evidence.raw_view` 감사 저장을 거친 원문을 반환한다. 감사에는 원문·비밀정보·도구 인수를 넣지 않는다.

새 조회 매개변수의 중복·잘못된 값·알 수 없는 필드는 거부한다. 원문 권한 부족은 403, 증적 없음은 404, 저장소·감사 확인 실패는 내부 상세를 제외한 503이다. 응답은 `Cache-Control: no-store`로 제공한다. UI는 생성된 OpenAPI 타입과 런타임 계약으로 잘못된 표시 범위·다른 결과 ID·임의 필드를 거부한다.

`/admin` 화면은 유지한다. 매개변수 없는 기존 API는 전체 관리자에게 기존 응답을 유지하지만, 원문 권한이 없는 역할·읽기 전용 관리자 토큰에는 원문을 반환하지 않는다. `super_admin`, `admin`, `security_admin` 및 기존 전체 관리자 토큰의 원문 조회 권한을 재사용한다. 새 역할이나 별도 비즈니스 로직은 추가하지 않는다.

이전 서버에서는 신규 화면의 결과·증적 조회를 중단하고 v0.86.146 이상 업그레이드와 권한에 따른 기존 화면 이동을 안내한다. 실행 이력의 메타데이터 조회는 v0.86.145에서 계속 사용할 수 있다.

## 검증과 전환 범위

전체 React 6,502개(460개 파일)를 통과한 뒤 초점 복귀 수정에서 관련 179개를 다시 검증했다. 최종 내장 UI의 합성 화면·키보드·접근성·시각 회귀 132개와 실제 Go·SQLite·제공자·감사 업무 11개를 재시도 없이 통과했다. 실제 업무에는 관리자 원문 조회 감사와 읽기 전용 계정의 원문 미수신을 포함한다. 전체 Go 테스트·vet·SQLite 증적 race, PostgreSQL 17 레드팀 race 216개, 실제 Go OpenAPI·생성 계약·API 표면·린트·포맷·타입·빌드·통합 SBOM을 확인했다. 보고서·실패 산출물 검사는 35개 모두 통과했고, 두 테마·1440/390px의 새 시각 기준 4장을 검토했다. 초기 전송 번들은 267,865바이트다.

읽기 전용 계정에 원문이 반환되던 문제를 먼저 재현했다. 역할별 기본 마스킹·명시 조회, 원문 감사 실패, 오래된 마스킹 데이터의 현재 비밀정보 제거, 저장된 원본 불변성, 누락·잘못된 경로와 메서드를 서버 회귀로 검증했다. React 검사는 조회 수명과 취소, 공통 갱신 시 원문 재조회 방지, 계약·오류·이전 서버 안내를 포함한다. 실제 Go 로그인·원문 조회·감사 및 조회 전용 업무와 합성 화면의 키보드·접근성·시각 검증은 별도 실행한다.

이 문서는 개발 후보의 동작과 검증 범위다. 후보 CI·리뷰·메인·공개 릴리스 검증 및 운영 Preview·Stable 인수는 별도로 완료해야 한다. 전체 Phase 0–6 목표는 계속 진행한다.
