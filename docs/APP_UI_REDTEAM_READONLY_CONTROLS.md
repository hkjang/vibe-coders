# 레드팀 조회 모드와 변경 권한

v0.86.147 개발 후보는 레드팀의 읽기 전용 미리보기와 변경 기능을 일치시킨다. 관리자 쓰기 권한이 있어도 기능의 `read_only` 설정 또는 `preview_read_only` 상태에서는 변경할 수 없다. 화면에는 조회 모드 안내와 버튼별 비활성 사유를 한글로 표시한다.

- 빠른 시작은 캠페인을 생성하므로 조회 모드에서 차단한다.
- 캠페인 생성·수정·복제·승인·삭제, 검사 프롬프트 저장·삭제·CSV 가져오기, 일정 추가·활성 전환, 조치 생성·상태 변경·적용을 같은 변경 기준으로 검사한다.
- 버튼 상태뿐 아니라 변경 요청 직전에도 현재 화면, 기능 설정, 세션과 쓰기 권한을 검사한다. 실제 실행·재실행·긴급 중지는 기존 검토·확인 절차를 계속 사용한다.
- 사용자·역할·팀·범위·세션 또는 기능 접근 설정이 바뀌면 열린 폼과 실행 키를 폐기한다. 권한을 복구해도 이전 폼과 키를 되살리지 않는다.
- 이미 전송된 요청을 취소하거나 서버 변경을 되돌렸다고 표시하지 않는다. 화면 소유자가 바뀐 뒤 도착한 응답의 성공 알림·캐시 무효화·후속 요청은 실행하지 않는다. 다시 조회해 서버의 최종 상태를 확인한다.
- 실행 이력, 검사 묶음, 마스킹 증적과 내보내기는 기존 조회 권한을 사용한다. 별도 권한과 감사 기록이 필요한 원문 증적 조회는 변경 작업으로 취급하지 않는다.

기존 Go API와 서버 권한 검사는 유지한다. 이 변경은 신규 콘솔의 미리보기 정책을 보완하며 API 권한을 부여하지 않는다. 기존 `/admin`은 그대로 제공한다.

수정 전 읽기 전용 버튼 활성화와 일정 변경 요청을 두 실패 회귀로 재현했다. 직접 제출·설정 전환·늦은 응답을 검증했다. 전체 React 6,513개(461개 파일), 최종 내장 화면·시각·키보드·접근성 회귀 139개(건너뜀·재시도·불안정 결과 없음), 실제 Go·SQLite·제공자·결과 저장·감사 업무 11개를 통과했다. 전체 Go 테스트·vet·API 표면 423경로/369React 연결, 실제 Go OpenAPI·생성 타입·린트·포맷·타입·빌드·번들 예산·SBOM 19Go/389npm을 검증했다. 초기 전송 크기는 267,846바이트다. 두 테마·1440/390px 시각 기준 10장을 확인했고 모바일 키보드 스크롤 후 캡처 위치를 보정한 뒤 이미지 갱신 없이 최종 회귀를 통과했다. 브라우저 설정 전환은 공개 합성 API, 실제 업무는 격리 서버와 로컬 제공자를 사용한다. 이번 변경에는 DB·Go 업무 로직·의존성 변경이 없다. 운영 Preview 검증, Stable 승격 및 전체 Phase 0–6 완료를 의미하지 않는다.
