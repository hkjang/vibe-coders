# 레드팀 대상 검색

v0.86.143 후보는 `/app/redteam?tab=targets`에서 표시 이름, 한글 유형·위험도와 기존 대상·제공자·모델·MCP·팀 식별자를 검색한다. 한글의 완성형·분해형 입력을 동일하게 처리하며, 임의 메타데이터나 프롬프트 원문은 검색 대상에 추가하지 않는다.

검색 결과 수를 전체 대상 수와 함께 안내한다. 빈 결과에서도 검색 조건을 지울 수 있고 입력으로 초점이 돌아간다. 검색 조건은 기존 `q`에 보관하고 지울 때 현재 탭 등 다른 URL 상태를 유지한다. 기존 민감정보 검색 방지 규칙을 사용하며 API·권한·저장 계약과 `/admin`은 유지한다. 검색 범위는 기존 API가 반환한 대상 목록이다.

## 검증 결과

관련 React 1,190개(58개 파일), 최종 내장 화면·키보드·접근성·시각 회귀 108개, 두 테마·1440/390px 검색 화면 4장, 실제 Go·SQLite·로컬 제공자의 레드팀 업무 6개를 통과했다. 실제 Go OpenAPI·생성 계약·API 표면·Go App UI 회귀·타입·린트·포맷·빌드·번들·통합 SBOM을 검증했다. 초기 전송 번들은 265,400바이트다. 검색 화면 검사는 공개 합성 API fixture를 사용하며 실제 실행 업무와 구분한다. 백엔드 업무·인증 변경은 없고 이번 로컬 검증에서 전체 Go·SSO·PostgreSQL 검사를 새로 수행했다고 주장하지 않는다. 전체 후보 CI·리뷰·메인·공개 출고는 별도로 검증한다. 검색 조건 삭제 후 URL 변경이 반영된 화면에서 초점을 복원하고, 민감정보 입력은 주소에 저장하지 않는 회귀도 확인했다. 운영 Preview·Stable 및 전체 Phase 0–6 인수는 계속 진행한다.
