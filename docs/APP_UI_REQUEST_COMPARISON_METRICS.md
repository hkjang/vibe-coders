# 요청 비교의 지표·통화 표시 — v0.86.116 개발 후보

이 구현은 세션 기록 탐색과 함께 v0.86.117에 통합 출고할 예정이다. 아래 검증은 해당 개발 후보의 근거이며 최종 통합 메인·출고 검증과 구분한다.


요청 탐색기의 목록·상세·비교 화면에서 기록된 금액과 통화를 동일하게 표시한다.
이전 비교 화면이 모든 비용에 원화 기호를 붙이던 문제를 수정한다. 작은 비용도 0으로
사라지지 않도록 소수 여섯 자리까지 표시하며, 그보다 작은 값은 지수 표기를 사용한다.
금액 위에 포인터를 두면 API가 전달한 수치를 확인할 수 있다. 환율 변환은 수행하지 않는다.

## 사용 방법

1. 요청 상세에서 **비교할 요청 ID**를 입력하고 **비교**를 선택한다.
2. 모델·공급자·응답 상태와 전체 지연·첫 청크 지연·입력·출력·전체·캐시·추론 토큰을 확인한다.
3. **변화** 열은 비교 대상에서 현재 요청을 뺀 값의 증가·감소와 단위를 표시한다.
4. **같은 항목 숨기기**로 차이가 있는 항목에 집중한다. 이 선택은 추가 API 요청을 만들지 않는다.
5. 다른 통화, 통화 미확인, 비공개·생략·미기록 값은 **비교 제외**로 표시한다.
   비교할 수 없는 값은 같은 값으로 간주하지 않으며, 같은 항목을 숨겨도 계속 표시한다.

첫 청크 지연은 두 요청이 모두 스트리밍일 때 비교한다. 비스트리밍 요청에는 적용하지 않는다.
비용 차이는 표시 문자열이 아닌 API 수치로 계산한다. 퍼센트·환율·품질 판정은 추정하지 않는다.
새 요청 비교를 실행하거나 상세를 닫으면 같은 항목 숨기기는 초기화된다.

## 권한과 데이터 범위

기존 요청 요약 조회 계약과 권한을 유지하며 새로운 API를 만들지 않는다.
비교 전에 현재 요청을 다시 조회하고 정확한 ID·참조·시각을 검증한다.
계정·팀·권한·선택 요청이 바뀌면 진행 중이던 비교 결과를 표시하지 않는다.
프롬프트·응답·원시 오류는 비교하지 않으며, 서버의 비공개 표시와 기존 비밀정보 보호를 유지한다.
두 건의 조회가 같은 시점의 원자적 스냅샷은 아니라는 기존 안내도 유지한다.

## 검증 상태

관련 React 검사 716개가 통과했다. 통화·작은 비용·수치 차이·비교 제외·화면 필터,
기존 요청·추적 탐색과 권한·비밀정보 보호를 포함한다. 초기 검사에서는 테스트의 모의 비밀값이
기존 탐지 길이보다 짧았던 기대값을 고쳤으며 공통 탐지 정책은 변경하지 않았다.

Go 내장 바이너리의 업무 브라우저 시나리오 86개가 통과했다. 두 테마·두 화면 폭의 시각 기준
8장을 직접 확인했고 고정한 기준으로 재검증도 86개 모두 통과했다. 재시도·건너뜀은 없었다.
키보드·가로 스크롤·포커스 복원·axe 접근성, 요청 비교의 오류·계정 변경 보호와 공유 필터를 포함한다.
기존 비교 시나리오의 axe는 페이지 초기화 시 주입하도록 수정하여 실제 CSP를 유지했다.
업무 브라우저의 모의 데이터와 별도로 실제 Go·OIDC·SQLite 인증 46개가 통과했다.
검증 중 소스와 내장 에셋 일치를 확인했다.

Go 기존 관리자·요청·추적·내장 UI 회귀와 vet, 타입·린트·포맷·OpenAPI·통합 SBOM을 통과했다.
초기 압축 번들은 262,393바이트이며 48개 경로와 6개 선택 로딩의 예산을 통과했다.
의존성 추가는 없으며 SBOM은 Go 19개·npm 389개를 유지한다.
PR·실제 메인 CI와 최종 정식 출고 검증은 별도로 진행한다.
운영 Preview 검증과 전체 Phase 0–6 인수는 별도로 계속 진행한다.
