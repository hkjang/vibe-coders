# 요청 조회 조건 요약 — v0.86.125 개발 후보

요청 탐색기에서 현재 조회에 전달한 조건을 한글 이름으로 모아 보여 준다. 접힌 고급 필터에도
실제 조회 조건의 개수를 표시해 세션·추적·언어 등의 조건을 놓치지 않게 한다. 표시 시간대와
페이지당 건수는 조회 조건 개수와 구분하며, 입력 중인 초안은 조회 버튼을 누르기 전까지
적용 조건으로 표시하지 않는다.

조건 하나를 해제하면 나머지 주소 조건과 시간대·표시 건수는 유지하고 페이지 위치를 지운다.
입력 중인 변경을 취소한다는 안내를 제공하며 새 조회 결과로 포커스를 옮긴다. 기존 행 선택은
조회가 바뀌면 정리하고, 뒤로·앞으로·새로고침에서 주소의 조건을 다시 복원한다.

갱신 중이거나 실패했을 때는 적용 완료로 표시하지 않는다. 조회 거부·계정 변경 시 이전 목록과
함께 요약도 정리한다. 요약은 검증된 API 조회 조건에서 만들며 인증정보로 보이는 값은 새 요약과
툴팁에서 숨긴다. 조건을 추가로 저장하거나 새 API·쓰기 요청을 만들지 않는다. 긴 값은 열 안에서
축약하고, 한글 해제 버튼·키보드·작은 화면을 지원한다.

React 1,071개(76개 파일)·내장 Go 브라우저 125개·실제 Go/OIDC/SQLite 인증 50개·실제 Keycloak HTTPS 5개와 사용자 DB 검증·보고서와 실패 산출물 29개를 통과했다.
실제 관리자·읽기 전용 관리자에서 조건 해제 후의 API 조회와 뒤로 가기 복원을 확인했다.
두 테마·1440/390px 시각 기준 4장을 직접 검토하고 키보드·axe·긴 값·본문 넘침을 검사했다. 최초 브라우저 검사에서 긴 조건의 모바일 가로 넘침을 재현해 요약 목록의 최소 너비를 보완했고, 자동완성 요청 모의 응답을 추가했다. 새 기준 생성 후 고정 브라우저 검사를 재시도·건너뜀 없이 통과했다. 새 요약 카드가 뒤에 보이며 달라진 기존 모바일 밝은 대화상자의 위쪽 가장자리 2px 영역을 직접 비교해 해당 기준 1장만 갱신했다. 비교 허용치는 유지했다.
타입·린트·포맷·실제 OpenAPI·통합 SBOM·요청 계약/기존 관리자/내장 UI Go 회귀·vet·번들 예산을 통과했다. 초기 압축 번들은 262,491바이트다. 검증한 소스와 내장 산출물의 해시 일치를 확인했다.
후보 CI·리뷰·메인·정식 배포와 운영 인수는 별도 단계다. 기존 `/admin`, 업무 API, 인증·권한과
단일 바이너리를 유지하며 모든 도메인의 필터 이관이나 전체 Phase 0–6 완료를 뜻하지 않는다.
