# 요청 탐색기 공유 필터 — v0.86.115 개발 후보

이 구현은 세션 기록 탐색과 함께 v0.86.117에 통합 출고할 예정이다. 아래 검증은 해당 개발 후보의 근거이며 최종 통합 메인·출고 검증과 구분한다.


`/app/observability/requests`에서 목록에 적용한 조회 조건을 저장하고, 다른 관리자가 저장한
조건을 확인·적용·이름 변경·삭제한다. 기존 `/admin/saved-filters` API와 감사 기록을 사용한다.
개인 필터가 아니며, 관리자에게 공유되는 범위를 화면과 삭제 확인에 표시한다.

## 사용 방법

1. 요청 탐색기의 필터를 적용한 뒤 **현재 조건 저장**을 선택한다. 아직 적용하지 않은 입력값은 저장하지 않는다.
2. 저장 대화상자에서 조건과 이름을 확인한다. 이름은 80자 이내이며 비밀 정보와 제어 문자를 허용하지 않는다.
3. **공유 필터**를 펼치고 저장된 항목을 선택한다. 선택만으로 요청 목록을 바꾸지 않는다.
4. 한글 조건 미리보기를 확인하고 **이 조건으로 조회**를 선택한다. 조건은 URL에 기록되며 새로고침 후 복원된다.
5. **이름 변경**은 조건을 덮어쓰지 않는다. **삭제**는 모든 관리자의 목록에서 해당 필터를 제거하며 확인 절차를 거친다.

저장 시 만료될 수 있는 페이지 커서를 제외한다. 적용은 첫 페이지에서 시작하며 지정한 시각을 그대로 사용한다.
시작·종료 시각을 모두 생략하면 전체 기간을 조회한다. 상대 기간을 자동으로 갱신하는 기능은 제공하지 않는다.
기존 화면에서 저장한 조건에 지원하지 않는 필드·커서·중복 조건·잘못된 값이 있으면 전체 적용을 막는다.
일부 조건을 생략해 조회 범위가 넓어지는 동작은 하지 않는다. 기존 화면에서 조건을 확인하거나 새 필터를 저장한다.

## 권한과 전환 상태

- 요청 탐색기는 공유 필터 관리에 한해 Preview로 전환한다. 요청 기록 자체는 읽기 전용이다.
- `admin:read`로 목록과 조건을 조회·적용한다. 저장·이름 변경·삭제에는 `admin:write`와 기능의 쓰기 허용이 필요하다.
- 런타임 `readonly` 설정은 계속 우선한다. 기존 역할 대상·점진 공개 비율·최소 API 버전은 유지한다.
- 읽기 전용 토큰을 포함한 실제 API 권한 검사는 기존 서버가 수행한다. 공유 필터에 소유자 전용 제한을 새로 만들지 않는다.
- 계정·팀·세션·조회 권한이 바뀌면 이전 목록과 초안을 폐기한다. 쓰기 제한만 바뀌면 초안을 유지하고 저장을 차단한다.
- 조회 실패는 요청 목록을 중단하지 않으며 요청 ID와 재시도를 제공한다. 쓰기 실패 후 자동 재전송하지 않는다.

## 검증 기록

관련 React 테스트 674개가 통과했다. 조건의 완전 검증, 공유 범위, 커서 제외, 저장 시점의 조건 유지,
이름 변경 시 조건 보존, 중복 삭제 방지, 늦은 응답 격리, 조회 거부 후 재시도와 권한 변경을 포함한다.
초기 검사에서 기존 전환 상태 기대값 두 곳과 새 테스트의 타입 오류를 수정했다.
Go의 공유 필터 읽기 전용 권한, 이름 변경 시 조건 보존과 생성·변경·삭제 감사 기록 및 기존 관리자 회귀 검사를 통과했다.
타입·린트·포맷·OpenAPI·SBOM·Go vet·내장 정적 파일 검사와 프로덕션 번들 예산을 확인했다.
초기 압축 번들은 262,392바이트이며 48개 경로와 6개 선택 로딩 예산을 통과했다.

Go 내장 바이너리의 업무 브라우저 시나리오 75개가 통과했다. 테스트 응답에 잘못 넣은 파생 필드와
공통 대화상자의 최초 키보드 위치 기대값을 수정한 뒤 저장·적용·새로고침·이름 변경·삭제,
조회 실패 재시도, 읽기 전용 적용, 두 테마·두 화면 폭의 시각 기준 8장과 axe·키보드를 확인했다.
테스트는 격리된 모의 업무 데이터를 사용한다. 시각 기준을 고정한 재검증도 75개 모두 통과했으며,
별도의 실제 Go·OIDC·SQLite 인증 검사 46개가 통과했다. 검증 중 소스와 내장 에셋 일치를 확인했다.
PR·최종 메인·정식 출고 검증은 별도 진행한다.

이 문서는 개발 후보의 범위를 기록한다. 운영 Preview 검증과 전체 Phase 0–6 인수 완료를 의미하지 않는다.
