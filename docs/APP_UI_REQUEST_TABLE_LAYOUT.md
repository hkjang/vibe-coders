# 요청 표의 열 표시·순서·너비 — v0.86.124 개발 후보

## 화면 동작

요청 탐색기의 **열 설정**에서 표시할 열과 순서를 정한다. 시각과 요청 ID는 항상 표시하며
상태·모델·공급자·지연·토큰·비용은 숨기거나 다시 표시할 수 있다. 한글로 이름 붙인 이동
버튼과 체크박스를 키보드로 조작하고, 완료나 Escape 후 열 설정 버튼으로 포커스를 돌린다.

머리글 경계를 마우스·터치로 끌거나 키보드 좌우 화살표로 너비를 조절한다. Home·End는
공통 최소·최대 너비를 적용한다. **기본값으로 초기화**로 표시·순서·너비를 함께 복원한다.
설정은 기존 공통 표 환경설정 형식으로 저장해 새로고침 후에도 유지한다. 브라우저 저장소에는
허용된 열 ID·순서·표시 여부·너비만 남기며 요청 행·필터·페이지 위치·선택 항목은 저장하지 않는다.

열을 바꿔도 현재 페이지의 행 선택과 서버 순서는 유지한다. CSV는 기존 전체 운영 항목을
담으며 표시 열 설정과 구분해 안내한다. 읽기 전용 관리자도 조회 범위 안에서 열을 조정한다.
조회 거부·계정 변경 시 기존 행·선택·상세의 수명 관리와 명시적 재시도는 그대로 적용한다.
조회 거부로 대화상자가 사라질 때 이미 오류 안내로 옮겨진 포커스를 유지한다. 열기 버튼이
사라지고 별도의 포커스 대상도 없을 때는 기존처럼 본문으로 복귀한다.

좁은 화면에서는 표만 가로 이동하고, 추가 열이 있으면 이동 안내를 제공한다. 열이 좁아지면
긴 본문은 줄바꿈하고 요청 ID는 열 안에서 축약한다. 선택 체크박스와 상세 작업은 열 설정에서
제거하지 않는다. 공통 너비 조절 구성 요소를 기존 표와 재사용하며 기존 업무 API·서버 권한·
`/admin`·단일 바이너리·폐쇄망 배포를 유지한다.

## 검증과 범위

요청·공통 표의 관련 검사 205개를 먼저 통과했다. 표시·순서·너비 복원, 초기화, 저장값 정리,
필수 열 보호, 선택 CSV 유지, 설정 중 조회 거부와 포커스를 확인했다.
실제 관리자·읽기 전용 관리자 인증 흐름에 열 숨김·선택 CSV·새로고침 복원 검사를 추가했다.

React 1,064개(75개 파일)·내장 Go 브라우저 118개·실제 Go/OIDC/SQLite 인증 50개·실제 Keycloak HTTPS 5개와 사용자 DB 검증·보고서와 실패 산출물 29개를 통과했다.
실제 관리자·읽기 전용 관리자의 열 숨김·선택 CSV·새로고침 복원을 확인했다. CSV의 숨긴 모델·원래 비용·ISO 시각을 실제 API 응답과 대조했다.
두 테마·1440/390px에서 요청 표 4장과 열 설정 4장을 직접 검토했다. 키보드 너비 조절·마우스 이동·마지막 열까지의 키보드 탐색·포커스 복원·axe·본문 넘침을 확인했다.
최초 브라우저 검사에서 권한 오류 안내의 포커스를 대화상자 종료가 본문으로 덮어쓰는 문제를 발견했다. 실제 본문이 있는 구성 요소 검사에서도 실패를 재현한 뒤 이미 옮겨진 포커스를 유지하도록 수정했다. 기본 열 너비에 맞춰 초기화 기대값을 갱신했고, 최종 브라우저 검사는 재시도·건너뜀 없이 통과했다.
타입·린트·포맷·실제 OpenAPI·통합 SBOM·요청 계약/기존 관리자/내장 UI Go 회귀·vet·번들 예산을 통과했다. 초기 압축 번들은 262,497바이트다. 검증한 소스와 내장 산출물의 해시 일치를 확인했다.
기존 요청 표의 시각 기준 4장은 새 열 설정·너비 조절·가로 이동 안내에 맞춰 검토 후 갱신했고
열 설정 대화상자의 시각 기준 4장을 추가했다. 다른 표의 기존 시각 기준은 유지한다.
후보 CI·리뷰·메인·정식 배포 및 운영 Stable 인수는 별도 단계다. 모든 도메인의 표 이관이나
전체 Phase 0–6 완료를 뜻하지 않으며 후속 개발과 운영 검증을 계속한다.
