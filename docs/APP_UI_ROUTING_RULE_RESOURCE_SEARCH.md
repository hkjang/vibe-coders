# 라우팅 규칙 검색과 읽기 전용 상세

v0.86.103 후보 마일스톤. 기존 `/admin`, 규칙 편집·삭제·순서 검토와 미리보기 상태를 유지한다.

## 사용자 동작

- 명령 팔레트의 **자원 검색 → 라우팅 규칙**에서 ID, 모델 패턴, 대상 모델로 검색한다. 결과는 대상 모델과 규칙 ID를 표시하며 메모·공급자·요청 원문은 검색하지 않는다.
- 대상 모델이 비어 있는 기존 규칙도 ID·패턴으로 찾을 수 있으며 **대상 모델 미지정**으로 표시한다.
- 검색 결과나 규칙 목록의 **상세**를 누르면 `/app/routing/rules?rule_id=<규칙 ID>`를 연다. 한글·슬래시가 있는 ID도 정확히 인코딩하며, 직접 접근·새로고침·뒤로/앞으로 이동을 지원한다.
- 상세는 상태, 우선순위, 모델 패턴, 복잡도 범위, 대상 모델·공급자, 메모, 생성 시각을 표시한다. 이 정보는 저장된 규칙이며 실제 요청에 대한 전체 라우팅 결과나 영향도 분석을 대신하지 않는다.
- 닫으면 다른 주소 매개변수를 보존하고 목록에서 열었던 링크로 초점을 돌린다. **기존 라우팅 화면**으로 이동할 수 있다.
- 없는 규칙, 조회 실패와 요청 ID, 다시 시도를 구분한다. v0.86.103 미만 서버에는 새 검색이나 ID 조회를 요청하지 않는다.

## 데이터와 권한

`POST /admin/resource-search`의 `routing_rule` 종류는 기존 `routing:read`와 공개된 `routing.rules` 기능 권한을 요구한다. `admin:read`만으로 라우팅 규칙을 검색할 수 없다. 저장소의 고정된 열과 바인딩된 검색어를 사용하며, 종류별 결과 상한과 기존 검색 기한을 유지한다. `%`, `_` 등의 문자를 검색 문법이 아닌 입력 문자로 취급한다.

기존 `GET /admin/routing-rules`에 정확한 `id` 조회를 추가한다. ID 조회는 최대 한 건을 반환하고 `Cache-Control: no-store`를 사용한다. 빈 값·중복 ID·다른 쿼리와의 조합·잘못된 인코딩·제어 문자를 거부한다. ID가 없는 기존 목록과 `view=order`의 규칙은 유지한다. 조회는 규칙·감사·라우팅 캐시를 변경하거나 공급자를 호출하지 않는다.

현재 계정·팀이 바뀌면 이전 목록·상세의 요청과 캐시를 폐기하고 새 조회자를 위한 화면을 연다. 목록 또는 상세가 401/403을 반환하면 두 화면을 함께 닫고 **권한 다시 확인**으로 명시적으로 재조회한다. 표시 마스킹과 변경 권한 갱신은 기존 편집 초안을 유지하면서 검토 유효성을 다시 확인한다.

## 검증 범위

SQLite·PostgreSQL에서 검색 열, 정확한 ID, 한글·특수 문자, 입력 상한, 권한, 기능 숨김, 취소와 기존 순서·편집 계약을 검증한다. React/API 클라이언트 검사는 URL 보존, 이전 서버, 응답 계약, 계정 전환과 늦은 응답·권한 거부를 포함한다.

브라우저는 검색부터 상세·새로고침·오류 복구·초점 복원, 밝은/어두운 테마, 데스크톱/모바일, axe와 시각 회귀를 확인한다. 실제 Go/OIDC 인증 검사에서도 저장된 규칙 검색과 상세 조회를 수행한다. 최종 결과와 출고 증빙은 검증 후 기록한다. 전체 Phase 0–6 완료나 Stable 승격을 의미하지 않는다.

### 후보 버전 로컬 검증 결과

- 전체 React 5,889개 / 399개 파일을 두 그룹으로 분할해 모두 통과했다. 보조 도구 54개 통과, 선택 환경 검사 15개는 로컬에서 건너뛰었다. 전체 실행에서 드러난 기존 생성·삭제 회귀의 목록 준비 순서는 새 계정의 자동 조회에 맞게 수정하고 전체를 재검증했다.
- SQLite·PostgreSQL 17에서 검색·정확한 ID·권한·기존 규칙 관리의 race 검사를 통과했다. 대상 모델이 없는 규칙의 검색 누락을 먼저 재현하고 고정 안내 제목으로 보완했다.
- 최종 Go 내장·운영 CSP·외부 네트워크 차단 브라우저 97개와 실제 Go/OIDC/SQLite 인증 46개가 실패·재시도·건너뛰기 없이 통과했다. 목록 링크 교체 뒤 초점 복원, 지연된 조회와 권한 회수, 기존 순서 검토를 포함한다.
- 1440px/390px의 두 테마 시각 기준 4장을 검토하고 읽기 전용 비교와 axe를 통과했다. 접근성 검사는 패널의 열림 애니메이션 중간 상태를 측정하지 않도록 모션 감소 설정으로 실행한다.
- 내장 자산 188개와 해시·캐시·MIME·CSP·깊은 주소·404·405·기존 관리자 접근을 확인했다. 초기 압축 번들은 261,458/350,000바이트이며 화면 47개·선택 도구 6개의 예산을 충족한다.
- 린트·형식·타입·프로덕션 빌드·실제 OpenAPI 스냅샷과 생성 타입을 확인하고 Go/NPM 통합 SBOM·라이선스를 갱신했다. 최종 브라우저·인증·React 검증 중 소스 해시는 바뀌지 않았다.

최근 공개 검증 기준선은 v0.86.100이다. 이 후보의 최종 PR·실제 메인 CI 및 정식 배포 검증은 별도 출고 단계에서 진행한다.
