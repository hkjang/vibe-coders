# 전역 검색 작업 공간 — v0.86.100 후보

명령 팔레트의 자원 검색에서 검색할 종류를 선택하고 종류별 결과를 탐색한다.
기존 12개 자원의 조회 API와 상세 연결을 유지한다.

## 사용 방법

- `Ctrl/Cmd + K` → `자원 검색` → `검색 대상`에서 전체 또는 한 종류를 선택한다.
- 조회 권한과 서버 버전이 지원하는 종류만 표시한다. 메뉴·명령 검색은 별도 모드다.
- 선택 직후 검색 입력으로 초점이 돌아온다. 현재 검색어는 유지되며 선택한 종류만 서버에 전달한다.
- 결과는 종류별 제목·표시 개수·일부 결과 여부로 구분한다. 표시 개수는 전체 자원 개수가 아니다.
- 일부 조회가 실패하면 실패 종류를 확인하고 해당 종류만 골라 다시 조회할 수 있다.
- 입력에서 위/아래, Home/End, Enter로 결과를 이동·연다. 종류 버튼은 Tab과 Enter로 선택한다.
- 검색창을 닫거나 메뉴 모드로 전환하면 입력과 종류 선택을 초기화한다.

## 상태와 권한

검색어와 선택한 종류는 메모리에서만 유지한다. URL이나 브라우저 저장소에 기록하지 않는다.
조회 중 범위를 바꾸면 이전 요청을 취소하고 이전 결과 이동을 차단한다. 늦은 이전 응답은
현재 결과를 바꾸지 못한다. 현재 요청 범위 밖 결과·상태도 표시하지 않는다.
계정·팀·역할·조회 권한·공개 기능이 바뀌면 검색 입력·선택·결과를 함께 폐기한다.
검색 API는 기존 인증·권한·기능 공개 상태 검사를 계속 수행한다.

## 검증

종류별 요청, 응답 순서와 키보드 순서 일치, 지연 응답 폐기, 권한 변경과 부분 실패를 검사한다.
실제 Go 내장 화면에서 검색·상세 연결, 두 테마·두 화면 폭·키보드·접근성과 시각 기준을 확인한다.
실제 Go 인증·SQLite 검색에도 종류 선택 검사를 포함한다. 최종 검증 결과와 출고 상태는 PR과
릴리즈에서 확정하며 이 변경으로 전체 Phase 인수나 운영 Stable 승격을 선언하지 않는다.

로컬 검증에서 전체 React 5,825개(390개 파일)와 후속 표시 보완을 포함한 관련 UI 94개가
통과했다. 보조 도구 54개가 통과했고 선택 환경 검사 15개는 로컬에서 건너뛰었다.
최종 Go 내장 브라우저 52개와 실제 Go/OIDC/SQLite 인증 46개가 재시도·실패·건너뜀 없이
통과했다. 두 테마·1440px와 390px에서 새 시각 기준 8개와 기존 검색 기준 16개를 갱신하고
읽기 전용 비교로 확인했다. 처음에는 기존 기준 이미지 디렉터리가 읽기 전용이어서 갱신
16건이 실패했으며, 검토한 검색 화면 디렉터리에만 쓰기를 허용한 뒤 최종 비교를 통과했다.
검사 중 소스 변경은 없었다. 초기 번들은 261,302/350,000바이트, 검색 화면은
11,311/250,000바이트이며 화면 47개·선택 도구 6개 예산을 충족한다. 내장 에셋 해시·캐시·
CSP·MIME와 직접 주소·404/405·기존 관리자 접근, 타입·린트·포맷·API 계약도 검증했다.
PR·실제 메인 CI와 정식 릴리즈 검증은 별도로 진행한다.
