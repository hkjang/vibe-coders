# 세션 비행기록 탐색 — v0.86.117 개발 후보

세션 상세의 수신 기록을 요청 유형·오류·위험 신호·도구 호출로 좁히고 표시 순서를 바꾼다.
기존 `/admin/sessions/{session_id}/flight-recorder` 응답에서만 선택하며 추가 조회나 쓰기를 하지 않는다.
세션의 전체 이력을 새로 수집하는 기능은 아니다.

## 사용 방법

- **요청 유형**에서 대화·임베딩·응답 생성·메시지·텍스트 완성·기타 요청을 선택한다.
- **기록 조건**에서 오류, 위험 신호, 도구 호출이 있는 기록을 선택한다. 유형과 조건은 함께 적용한다.
- 오류는 서버의 `is_error` 표시를 따른다. HTTP 200으로 저장된 오류도 포함하고, 색상 외에 **오류 기록** 문구를 표시한다.
- 위험 신호는 비밀정보 탐지·정책 차단·높은 코드 위험이다. 여러 신호가 있어도 기록은 한 번만 표시한다.
- **표시 순서**로 첫 기록 또는 최근 기록부터 읽는다. 같은 시각의 항목도 수신 순서를 유지하거나 뒤집는다.
- **CSV 내보내기**는 현재 표시한 범위와 순서를 사용한다. 기존 15개 열과 수식·따옴표 이스케이프를 유지한다.
- 조건의 빈 결과와 수신 기록이 없는 응답을 구분한다. **모든 수신 기록 보기**로 조건을 초기화한다.

상단 집계·서버 요약은 필터 적용 전 수신 기록을 나타낸다. 상대 시간의 기준도 원래 첫 기록 시각을 유지한다.
필터는 열린 상세에 한정되며, 세션·계정 변경 또는 상세를 닫고 다시 열면 초기화한다.
재조회 동안에는 필터와 이전 기록을 보존하고 새 응답에 같은 필터를 적용한다.
조회 중·실패·무효화·권한 변경 후에는 기존의 현재 응답 확인 절차로 CSV 생성을 차단한다.

## 검증 상태

최종 소스의 관련 React 검사 815개가 통과했다. 필터의 교집합·중복 없는 위험 기록·HTTP 200 오류,
표시 순서와 CSV 일치·원래 시간 기준 유지·빈 결과 복구·재조회 실패·계정 및 세션 전환을 포함한다.
초기 검사에서 기존 선택자·설명 기대값과 새 브라우저 다운로드 검사의 타입 참조를 정리했다.

Go 내장 바이너리의 업무 브라우저 72개가 통과했다. 두 테마·두 화면 폭의 시각 기준 8장을 직접 확인했고,
색상에만 의존하던 HTTP 200 오류를 글자로도 표시한 뒤 브라우저와 고정 시각 기준 재검증 모두 72개가 통과했다.
재시도·건너뜀 없이 키보드·모바일·axe·실제 CSV 다운로드와 기존 세션·공유 필터·요청 비교를 검사했다.
업무 모의 응답과 별도로 실제 Go·OIDC·SQLite 인증 46개가 통과했으며 검증 중 소스·내장 에셋 일치를 확인했다.

Go 세션 계약·기존 관리자·내장 UI 회귀와 vet, 타입·린트·포맷·OpenAPI·통합 SBOM을 통과했다.
초기 압축 번들은 262,421바이트이며 48개 경로·6개 선택 로딩의 예산을 통과했다. 새 의존성은 없다.
공유 필터·요청 비교 후보와 v0.86.117에 통합 출고할 예정이며 각 PR의 전체 CI, 최종 메인과 정식 배포 검증은 별도로 수행한다.
전체 Phase 0–6 및 운영 Preview·Stable 인수는 계속 진행한다.
