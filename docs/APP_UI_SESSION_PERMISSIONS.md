# 현재 로그인 권한 확인

사용자 메뉴에서 **내 권한 확인**을 선택합니다. 역할, 팀, 인증 방식과 함께 현재 로그인에 부여된 권한 코드가 표시됩니다. 처음에는 부여된 권한만 표시합니다. 한글 이름·코드·설명으로 검색하고 **부여됨 / 미부여**로 목록을 좁힐 수 있습니다.

## 표시 범위

- 기존 `/admin/ui-bootstrap`과 인증 상태의 `user.scopes`를 사용합니다. 역할 카탈로그를 조회하거나 역할 이름으로 권한을 추정하지 않습니다. 관리자 권한이 없어도 자신의 로그인 정보를 확인할 수 있습니다.
- **요청 원문 열람**은 별도의 서버 응답 `capabilities.raw_prompt_view`를 사용합니다. 관리·조회 권한 코드가 있다고 원문 열람을 허용하지 않습니다.
- 토큰 갱신·인증 상태 갱신 때 현재 값을 다시 표시합니다. 역할 정의 변경은 새 로그인이나 토큰 갱신 이후 적용될 수 있습니다.
- 기존 관리자 토큰과 개방 모드는 공유 관리자 연결임을 표시합니다. 로그인 정보가 없는 경우와 서버가 빈 권한 목록을 반환한 경우를 구분합니다.
- 실제 조회·변경에는 팀, 대상 리소스, 정책, 기능 전환 상태와 각 API의 추가 검사가 적용됩니다. 미부여 표시는 해당 세션 코드가 없다는 의미이며 모든 리소스별 작업의 최종 허용 여부를 계산하지 않습니다. 생성·삭제·승인 등 권한 체계를 새로 만들지 않습니다.
- 검색어와 권한 목록은 URL·브라우저 영구 저장소·사용 분석에 저장하지 않습니다. 비밀번호·토큰·API 키를 표시하지 않습니다.

## 화면과 검증

긴 팀 이름은 두 줄로 정리하고 키보드로 전체를 펼칠 수 있습니다. 권한 코드는 자신의 영역에서 줄바꿈합니다. 작은 화면에서는 대화상자 본문을 스크롤하고 닫기 버튼을 유지합니다. 키보드로 열고 탐색할 수 있으며 종료하면 사용자 메뉴로 초점을 돌려줍니다. 화면 코드는 버튼 선택 후 로드하고 기존 초기·화면 성능 예산을 유지합니다.

검증 대상은 권한·원문 상태의 독립 표시, 갱신과 계정 전환, 한글·코드 검색, 빈 권한과 정보 누락, 알 수 없는 코드의 텍스트 처리, 키보드·접근성, 밝은/어두운 테마와 좁은 화면입니다. 실제 Go 로그인에서도 관리자·읽기 전용 계정의 표시가 서버 응답과 일치하는지 확인합니다.
