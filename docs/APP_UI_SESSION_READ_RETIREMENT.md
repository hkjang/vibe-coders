# 세션 조회 거부 후 기록 정리 — v0.86.118 개발 후보

## 문제와 사용자 동작

세션 목록과 비행기록의 재조회가 401·403으로 거부되어도 이전 정상 응답을 화면과 Query Cache에
유지하던 문제를 수정한다. 기존 인증·기능 허용 정보가 그대로인 조건에서 두 화면의 401·403
재현 검사 4개가 모두 실패했으며 수정 후 통과했다.

거부된 목록은 조회 기간별 캐시와 행·합계를 지운다. 거부된 상세는 요약·타임라인·CSV를 숨긴다.
안내에 포커스를 이동하고 **권한 확인 후 다시 조회** 버튼을 제공한다. 목록 기간을 바꾸거나
탭을 다시 활성화해도 거부된 범위를 자동 복원하지 않는다. 다시 조회할 때 새 조회 수명을 만들어
이전 요청·행 선택·새로고침·내보내기 콜백이 같은 데이터를 다시 받아도 유효해지지 않게 한다.

목록과 열린 상세의 수명은 독립적이다. 목록 자동 갱신만 거부되면 허용된 상세의 데이터·CSV·
포커스를 유지한다. 상세만 거부되면 허용된 목록은 유지한다. 503 등 일시적 갱신 실패는 기존대로
마지막 정상 데이터를 표시하고 최신 조회가 성공할 때까지 선택·CSV를 보호한다.

서버 오류 원문을 안내에 표시하지 않는다. 요청 ID는 허용 문자·길이와 자격 증명 접두사 검사를
통과한 값만 표시한다. 권한이 복구되었는지는 다음 요청에서 기존 서버 API가 다시 판단한다.

## 구현 범위

공통 조회 수명 도우미를 재사용하고 목록·상세에 별도 소유 표식을 부여한다. 기존 세션의
기간·대상·필터·응답 최신성 검사와 `/admin/sessions` 및 비행기록 API는 유지한다.
인증 주체, 팀, 세션 세대, 자격 증명 접두사·원문 보기 권한이 바뀌면 이전 조회 수명을 폐기한다.
기존 `/admin`과 Go 비즈니스 로직, 운영 Node.js 불필요 구조는 변경하지 않는다.

## 검증 상태와 한계

- 수정 전 실컴포넌트·Query Cache 재현: 목록/상세 × 401/403 모두 이전 데이터 잔존 확인.
- 수정 후 세션 React 검사 110개 통과: 다중 기간 캐시 정리, 이전 queryFn·행·CSV·새로고침 콜백 차단,
  명시 복구와 독립 조회 범위, 진단 값 제한을 포함한다. 기존 일시적 오류·늦은 응답 검사도 유지한다.
- 최종 관련 React 826개/40파일, Go 내장 화면의 합성 HTTP 브라우저 81개와 고정 시각 기준 재검사
  81개를 통과했다. 재시도·건너뜀·불안정 통과는 없다. 실제 Go/OIDC/SQLite 인증 46개는 별도로 통과했다.
- 모바일 390px·데스크톱 1440px, 밝은·어두운 테마 4장의 안내를 직접 확인했다. 키보드 복구·포커스 유지,
  axe 검사와 실제 CSV 다운로드를 포함한다. 원본 소스와 내장 에셋 해시를 검사 전후 확인했다.
- 타입·린트·포맷·실제 Go OpenAPI 계약, 통합 SBOM(Go 19개·NPM 389개), Go 세션·기존 관리자 회귀와
  내장 UI 전체 검사·vet를 통과했다. 초기 압축 번들은 262,423바이트이며 의존성 변경은 없다.
- 최초 타입 검사에서 신규 테스트의 잘못된 Testing Library 옵션 2곳과 fixture 인수 누락 1곳을
  발견해 바로잡았다. 이후 관련 React·전체 프런트엔드 게이트와 브라우저·인증을 최종 소스로 검증했다.
- 합성 HTTP 검사는 실제 서버의 권한 배정·팀 범위를 증명하지 않는다. Query Cache 정리는 이미
  내려받은 파일이나 외부 코드가 참조하는 모든 JavaScript 객체의 물리적 삭제를 뜻하지 않는다.
- 후보의 CI·PR 검토, 실제 메인과 정식 배포 검증, 운영 Preview 인수는 별도다. 전체 Phase 0–6는 계속 진행한다.
