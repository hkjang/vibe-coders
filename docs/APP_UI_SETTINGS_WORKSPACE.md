# 설정 작업 공간과 상세 주소

v0.86.98 후보는 시스템 설정의 런타임·콘솔 전환 작업을 개선한다. 기존 설정 API,
권한 검사, 감사 이력, 버전 조건 저장과 복구 절차를 재사용한다. 기존 `/admin`과
미리보기 전환 상태는 유지한다.

## 사용 방법

- 런타임 목록의 설정 키 링크 또는 행 작업으로 상세를 연다. 주소의 `setting`은
  설정 키만 포함하며 값·비밀값·변경 사유를 담지 않는다.
- `/app/system/settings?tab=runtime&setting=cache.chat_enabled`를 공유하거나
  새로고침하면 같은 설정을 연다. 목록 검색·범주와 독립적으로 상세를 조회한다.
- 잘못된 키, 없는 설정, 조회 실패를 구분하고 재시도를 제공한다. `ui.app.*` 키는
  기존 콘솔 전환 탭에서 관리한다. 이번 상세 주소는 런타임 설정만 지원한다.
- 담당 범주 관리자(`ops_admin`, `ai_admin`, `security_admin`)는 서버의 `can_write`
  허용 항목을 변경한다. 일반 계정의 쓰기 권한이나 다른 범주 권한을 확대하지 않는다.
  연결 테스트는 기존 전역 쓰기 권한 조건을 유지한다.

## 초안과 변경 보호

설정·이력 캐시와 열린 초안은 인증 세션, 계정, 팀, 역할에 묶인다. 이 정보가 바뀌거나
최종 조회 응답이 401/403이면 이전 자료를 버린다. 권한 복구 후에는 명시적으로 다시
조회한다. 이전 작업의 늦은 성공·오류 알림, 화면 닫기와 백업 다운로드는 실행하지 않는다.
조회만 허용하도록 전환된 경우 초안은 유지하되 저장·복구·연결 테스트를 막는다.

열린 편집기의 값과 버전은 최초 검토한 상태를 유지한다. 최신 조회에서 권한이 회수되면
저장을 막는다. 버전 충돌, 저장 후 런타임 반영 대기, 이력 조건을 확인한 복구와 사유 입력은
그대로 적용된다. 반영 대기 안내는 동일 계정의 탭 이동 후에도 유지하고 새 정상 조회가
현재 서버의 적용 완료를 확인한 경우 해제한다. 모든 서버의 반영 완료를 뜻하지 않는다.

## 검증 범위

설정 회귀·계정 전환·권한 회수·늦은 응답·직접 주소 테스트, 실제 Go의 범주 관리자
권한 및 버전 충돌 계약, 내장 자산과 운영 CSP의 브라우저, 실제 Go/OIDC 인증,
모바일·테마·키보드·접근성 검사를 수행한다. 최종 CI와 공개 릴리즈 검증은 별도 확인한다.
운영 사용자의 Preview 검증과 Stable 승격, 전체 Phase 0–6 인수는 계속 진행한다.

### 로컬 검증 결과

- 설정 관련 269개, 전체 React 5,803개(387개 파일)와 보조 도구 54개 통과.
  전체 검사 이후 추가한 반영 대기 메타데이터 검사와 지연 로딩 변경은 관련 269개로 재검증했다.
  보조 도구의 선택 환경 검사 15개는 로컬에서 건너뛰었다.
- 실제 SQLite와 고정 PostgreSQL 17의 범주 권한·동시 수정 조건 race 검사 통과.
- 운영 CSP·Go 내장 자산·외부 네트워크 차단 브라우저 70개 통과. 신규 10개, 기존 설정
  회귀 60개를 포함하며 두 테마·두 폭의 시각 기준 4개를 확인했다. 표시 애니메이션 종료 후
  axe를 실행한다. 별도 실제 Go/OIDC/SQLite 인증 44개는 설정 저장·복구·조회 계정 거부를 포함한다.
- 초기 압축 크기 261,264/350,000바이트, 설정 화면 231,905/250,000바이트.
  복구 확인은 명시적 작업 선택 후 불러오며 5,232바이트(전송 2,730바이트)로 별도 예산을 충족한다.
  화면 47개·선택 도구 6개 모두 예산 안이며 기준을 완화하지 않았다.
- 내장 에셋 185개의 해시·캐시·MIME, 깊은 주소·없는 파일 404·쓰기 405·기존 관리자 200을 확인했다.
  새 의존성 없이 Go 19개·NPM 389개 통합 SBOM과 라이선스를 갱신했다.

최종 PR 및 메인 CI, 정식 컨테이너와 공개 배포 파일 검증은 출고 시 별도 완료한다.

PR 검토에서 확인한 설정 키 링크의 목록 필터 손실을 수정했다. 링크는 허용된 기존 검색·범주를
보존하며, 초안 폐기 후 라우터가 처리하는 이동에 편집창이 중복 주소 변경을 추가하지 않는다.
후속 설정 269개, 내장 자산 브라우저 70개와 실제 Go/OIDC 인증 44개를 재검증했다.

라우터 이동을 승인해 초안을 폐기한 경우 편집창과 라우터는 같은 본문으로 포커스를 복원한다.
이전 편집 버튼과 본문 사이의 포커스 경합을 없애고 최종 설정 269개·브라우저 70개·실제 인증 44개를 재검증했다.
