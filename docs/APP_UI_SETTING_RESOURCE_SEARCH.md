# 설정 검색과 콘솔 상세 주소

v0.86.99 후보는 전역 자원 검색에서 시스템 설정을 찾고 정확한 편집 화면을 연다.
기존 `/admin`과 설정 API, 권한·감사·버전 조건 저장 및 미리보기 상태를 유지한다.

## 사용 방법

- `Ctrl/Cmd + K` → **자원 검색**에서 설정 키, 범주 또는 한글 설명을 두 글자 이상 입력한다.
  종류별 최대 10개를 표시하고 설정은 키 순서로 정렬한다. 결과가 많으면 검색어를 구체화한다.
- 결과에는 한글 설명과 설정 키를 함께 표시한다. 실제 값, 비밀값, 환경변수 값,
  변경 이력과 사유는 검색하거나 결과에 포함하지 않는다. 비밀 설정의 키·정적 설명은 조회 가능하다.
- 런타임 설정은 `/app/system/settings?tab=runtime&setting=cache.chat_enabled`처럼 연다.
- 콘솔 전체 설정은 `?tab=console&setting=ui.app.enabled`, 기능별 전환 설정은
  `?tab=console&setting=ui.app.feature.system.settings.rollout`처럼 연다.
  기능 편집기는 선택한 키를 표시하고 해당 기능의 전환 조건을 함께 보여 준다.
- 주소 공유·새로고침·뒤로/앞으로 이동 시 같은 항목을 복원한다. 목록 필터와 독립적으로
  상세를 열며, 누락·잘못된 주소·조회 실패를 구분한다. 닫으면 선택 키만 제거한다.

## 권한과 안전성

설정 검색에는 기존 `admin:read`와 `system.settings` 공개 조건이 필요하다. 숨김·기존 화면
상태에서는 검색하지 않는다. v0.86.99보다 이전 서버에는 새 검색 종류를 전송하지 않는다.
계정·팀·역할·세션 변경 시 이전 검색과 초안을 폐기하고 조회 전용 전환 시 저장을 막는다.

조회 요청은 기존 읽기 전용 POST를 사용하고 검색어를 URL에 넣지 않는다. 설정 정의의 키·범주·
한글 설명만 검색하며 실제 값 계산 함수나 외부 서비스를 호출하지 않는다. 전체 검색은 기존
3초 제한, 종류별 부분 실패, 민감 문자열 제외와 캐시 금지 정책을 유지한다.

상세에서 저장할 때 기존 변경 전후 비교, 버전 조건과 감사 절차를 따른다. 검색과 주소 연결은
새 쓰기 권한을 부여하지 않는다. 새 응답이 도착해도 편집기가 검토한 값·버전과 초안을 보존하고
최신 권한 회수는 즉시 적용한다. 운영 Preview 검증과 Stable 승격은 별도 인수 대상이다.

## 검증

정적 메타데이터 검색·값 비조회·권한·취소·결과 상한의 Go 계약, SQLite·PostgreSQL race,
계정별 검색과 콘솔 상세 주소의 React 테스트, 실제 Go/OIDC 로그인 및 외부 네트워크가 차단된
Go 내장 자산 브라우저에서 키보드·테마·모바일·axe·시각 회귀를 확인한다. 최종 CI와 정식
릴리즈 배포 파일 검증까지 완료한 뒤 공개 기준선에 반영한다.


### 로컬 검증 결과

- 전체 React 5,820개(389개 파일)와 보조 도구 54개 통과. 선택 환경 검사 15개는 로컬에서
  건너뛰었다. 후속 주소·포커스 보완은 설정 279개로 다시 검증했다.
- 기존 검색 계약을 포함한 SQLite·PostgreSQL 17 race 검사를 통과했다. 등록 정의의 값 계산을
  실행하지 않는지, 키·범주·한글 설명 검색과 취소·상한·숨김 기능·조회 권한을 확인했다.
- 최종 Go 내장 자산·운영 CSP·외부 네트워크 차단 브라우저 115개 통과. 실패·건너뛰기·재시도 없이
  검색·설정·기존 회귀와 한글·두 테마·두 화면 폭의 시각 기준 4개를 확인했다.
  초안 폐기·뒤로가기·포커스 복원은 3회씩 별도 반복한 6개 검사도 통과했다.
- 실제 Go/OIDC/SQLite 인증 45개 통과. 초기 실행의 기존 관리자 인증 갱신 동시 요청 검사
  한 건 실패를 확인한 뒤 최종 코드 전체를 재검증했다. 신규 검색은 실제 조회 계정으로 확인한다.
- 초기 번들 261,280/350,000바이트, 설정 화면 232,830/250,000바이트이며 화면 47개·선택 도구 6개
  모두 예산을 만족한다. 내장 자산 185개의 해시·캐시·MIME와 깊은 주소·404·405·기존 관리자도 확인했다.
- 새 의존성 없이 Go 19개·NPM 389개 통합 SBOM과 라이선스를 갱신했다.

최종 PR·메인 CI와 정식 배포 파일 공개 검증은 출고 시 별도 완료한다.
