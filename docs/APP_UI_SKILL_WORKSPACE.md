# 스킬 관리의 계정별 조회와 작업 — v0.86.94 후보

스킬 목록·통계·후보·의존성·실행 로그·승격 이력·준비도·적합성 근거를 현재 계정과
화면의 조회 수명에 묶는다. 계정·팀·역할·인증 세션이 바뀌거나 조회 권한을 잃고 화면을
떠나면 해당 조회를 취소하고 캐시·초안을 폐기한다. 늦은 응답도 새 화면에 표시하지 않는다.

조회 API가 401 또는 403을 반환하면 이전 정보를 숨기고 조회 권한을 다시 확인하라는
한글 안내를 표시한다. 자동 재조회를 멈추며 **다시 시도**를 선택하면 새 수명으로 조회한다.
명시적으로 실행한 보안 스캔·추천 조회·정책 시뮬레이션·내보내기도 같은 경계를 적용한다.
이전 계정의 번들은 뒤늦게 다운로드하거나 완료 알림을 표시하지 않는다.

생성·수정·승격·삭제·후보 채택·추천 적용·가져오기·근거 기록은 기존 API를 사용한다.
전송 직전 권한을 확인하며 인증 오류 후 자동 재전송을 하지 않는다. 완료 뒤에는 현재
계정의 조회만 갱신한다. 계정 변경 뒤의 응답은 새 화면의 초안·알림·조회를 바꾸지 않는다.
읽기 전용이나 쓰기 권한 회수만 발생하면 기존 초안을 보존하고 제출을 막는다.

정책 시뮬레이션 결과는 실제 제출한 스킬·모델·도구·팀 입력과 연결한다. 입력이 바뀌면
이전 결과를 숨기고 **정책 확인**으로 현재 입력을 다시 검증한다. 실제 모델·도구를 호출하지
않는다. 스킬 상태 필터와 같은 이름의 스킬 준비도, 적합성 근거는 서로 다른 캐시를 사용한다.

기존 `/admin`, 서버 권한·승격 조건·저장 방식과 Preview 상태를 유지한다. 서버 페이지,
새 승인 절차나 운영 Stable 승격은 이번 범위에 포함하지 않는다.

## 검증

기존 화면에서 계정 전환 후 목록·초안이 남고 늦은 번들이 다운로드되는 네 사례를 재현했다.
수정 뒤 스킬 관련 132개 검사가 통과했다. 계정·팀·권한·화면 종료, 401/403 후 수동 복구,
쓰기 중 권한 변경, 적합성 초안, 특수 상태의 캐시 충돌, 시뮬레이션 입력 변경을 포함한다.
전체 React 5,733개와 보조 도구 54개 검사가 통과했다. 보조 도구의 선택적 환경 검사
15개는 로컬에서 건너뛰었다. 실제 Go 내장 자산·운영 CSP·외부 네트워크 차단 환경에서
브라우저 50개가 재시도·건너뛰기 없이 통과했다. 업무 API는 합성 응답이며, 새 서버
비즈니스 로직은 추가하지 않는다. 기존 편집기와 적합성 근거의 모바일 화면 5개를 확인하고
키보드·초점·axe·가로 넘침 검사를 유지했다.

린트·포맷·TypeScript·OpenAPI 생성 계약, Go OpenAPI·정적 자산 처리 테스트와 통합
SBOM을 검증했다. 초기 압축 번들은 254,967/350,000바이트이며 화면 47개와 선택 도구
5개도 예산 안에 있다. 새 의존성은 없다. 최종 원격 CI·정식 출고·운영 Stable 인수는
진행 중이다.
