# 신규 콘솔 시작 안내와 복구

`/app`의 코드가 내려오거나 실행되기 전에도 한글 시작 안내와 **콘솔 처음 화면 열기** 링크를 표시합니다. React 본체·공통 모듈·스타일 로딩이 실패하면 **신규 콘솔을 불러오지 못했습니다** 안내와 **현재 주소로 다시 시도** 버튼을 제공합니다. 사용자가 버튼을 눌러야 현재 주소를 다시 열며 자동 재시도하거나 변경 API를 실행하지 않습니다.

작은 시작 코드 자체를 불러오지 못하거나 JavaScript가 꺼져 있어도 HTML 안내와 고정된 `/app/` 링크가 남습니다. 이 단계에서는 인증과 권한이 확인되지 않았으므로 관리 기능 링크나 사용자 정보를 표시하지 않습니다. 정상 화면에 진입한 뒤에는 기존 권한에 따른 `/admin` 이동을 그대로 제공합니다. 오류 원문·토큰·주소 매개변수를 복구 안내나 별도 로그에 기록하지 않습니다.

밝은/어두운 시스템 테마, 좁은 화면, 키보드 이동을 지원합니다. 실패 안내가 표시될 때 아직 조작하지 않은 사용자의 초점을 제목으로 옮기며, 이미 복구 링크에 도달한 사용자의 초점은 유지합니다. 정상 로딩 후에는 React 화면이 시작 안내를 대체합니다.

## 빌드와 성능

시작 코드는 인증·React·업무 모듈과 분리합니다. 빌드 도구의 공통 로딩 도우미도 별도 작은 파일로 유지합니다. 실제 첫 화면에 필요한 React 본체는 지연 import 형식이어도 기존 초기 350,000바이트 예산에 포함합니다. 복구 코드의 정적 의존성에는 별도 8,000바이트 상한을 적용하여 큰 업무 모듈이 다시 연결되는 것을 검출합니다. 외부 에셋·Service Worker·Node 운영 프로세스를 추가하지 않습니다.

## 검증 범위

모듈 네트워크 실패·실행 실패·공통 모듈 실패·작은 시작 파일 실패·JavaScript 중지·스타일 실패와 명시적 복구를 실제 Go 내장 자산에서 검증합니다. 합성 인증 응답을 사용하는 화면 검사는 실제 인증·Keycloak 검증과 구분합니다. 운영 사용자 검증, Stable 승격 및 전체 Phase 0–6 인수는 계속 진행합니다.

전체 React 6,644개(473개 파일)와 기본 Node 61개를 통과한 뒤, 시작 의존성 상한을 포함한 최종 번들 검사 31개를 통과했습니다. 기본 Node의 외부 산출물 선택 검사 15개는 제외 항목입니다. 최종 Go 내장 브라우저 94개는 재시도·건너뜀 없이 통과했고 밝은/어두운 테마의 1440/390px 새 시각 기준 4장을 검토한 뒤 변경 없이 비교했습니다. JavaScript 중지 검사는 검사 도구가 검색에서 제외하는 `noscript` 부모 대신 실제 하위 문단의 표시·문구와 링크 이동 완료를 확인합니다.

실제 Go/OIDC/SQLite 인증 60개와 Keycloak HTTPS 5개 및 사용자 저장 검증을 통과했습니다. 그 뒤 바꾼 내용은 브라우저 테스트의 검색·대기 방식뿐이며 제품 코드는 동일합니다. 기존 관리자·인증·초기 설정 Go 회귀 145개, 정적 파일 처리 패키지 66개와 해당 패키지 vet를 통과했습니다. 일반 Go 실행에서 제외된 제품 브라우저 진입점은 위 별도 Keycloak 검사로 실행했습니다. 실제 서버 OpenAPI 생성 계약·빌드·통합 SBOM(19 Go·389 npm)을 검증했으며 초기 전송은 275,825바이트, 시작 코드와 정적 의존성은 3,845바이트입니다. 이는 파일별 압축 용량이며 실제 화면 로딩 시간이나 운영 환경 인수 결과는 아닙니다.

## 첫 안내의 저장 테마 적용 보완

후보 CI에서 정적 안내가 저장 테마보다 먼저 나타나는 문제를 확인하고 두 테마 사례로 재현했다. 본문 파싱 전에 같은 출처의 작은 해시 파일로 테마·밀도를 적용한다. 외부 모듈·React·인증·네트워크 API에 의존하지 않으며 인증정보를 읽거나 브라우저 저장값을 수정하지 않는다. 손상된 설정·지원하지 않는 저장 버전·저장소 접근 거부는 시스템 테마와 기본 밀도로 처리한다. 표시 파일을 받지 못해도 HTML 안내와 기존 시작 복구를 유지한다.

파일을 Vite 빌드 명세와 초기·시작 성능 예산에 포함하며 기존 CSP와 장기 에셋 캐시를 유지한다. 기존 첫 콘텐츠 테마 검사 2개와 본체 실패·저장소 오류·표시 파일 실패 검사 7개를 통과했다. 프롬프트·설정 검색 검사는 정적 안내의 제목을 작업 화면으로 오인하지 않고 실제 화면이 열린 뒤 단축키를 입력한다.

보완된 같은 소스로 Go 내장 브라우저 118개와 검색 15개를 각 5회 반복한 75개를 재시도·건너뜀 없이 통과했다. 관련 React 34개, 기본 Node 62개(외부 산출물 선택 검사 15개 제외), 정적 파일 처리 Go 66개, 실제 인증 60개와 Keycloak HTTPS 5개도 통과했다. 전체 React 6,644개 검증은 보완 전 결과이며 새 후보의 전체 CI는 별도로 확인한다. 최종 초기 전송은 276,410바이트, 시작 의존성은 4,430바이트로 예산 안에 있으며 형식·린트·OpenAPI 계약 검사도 통과했다. Vite 개발 서버에서도 표시 파일의 GET·HEAD와 잘못된 메서드 거부를 확인했다.
