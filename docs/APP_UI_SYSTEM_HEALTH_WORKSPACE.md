# 시스템 상태 탐색과 독립 조회

v0.86.106 후보. 기존 `/admin`과 운영 조회 API의 권한·통계 의미를 유지한다.

- 상태, 운영 홈, 백그라운드 작업·배포 점검, 인덱스 탭을 주소에 보존한다. 상단 새로고침과 자동 갱신은 현재 탭의 조회만 수행하며 비활성 탭에서는 멈춘다.
- 각 조회는 현재 계정·팀·세션·조회 권한에 속한다. 팀 변경은 이전 데이터와 SQL 검색·열린 창·배포 점검 요청 의도를 폐기한다. 늦은 응답은 새 화면에 반영하지 않는다.
- 조회 거부는 해당 영역의 이전 데이터를 폐기하며 다른 정상 영역을 유지한다. 수동 재시도로 복구한다. 일시 오류에는 마지막 정상값과 오류를 함께 표시한다.
- 조회 실패나 누락된 인덱스 요약을 ‘불일치’, ‘모두 정상’, 빈 후보로 단정하지 않는다. 사용 가능한 비교와 미확인 영역을 구분한다.
- 운영 카드 이동은 메뉴와 같은 권한·전환 상태를 적용한다. 기존 화면 전용 기능은 허용된 기존 경로로 연결한다.
- 작업·배포 점검 이름을 한글로 표시한다. 현재 비밀 접두사가 포함된 운영 문자열·진단 코드·오류 요청 ID는 그대로 노출하지 않는다.
- 긴 마이그레이션 SQL은 검색·구분·차이 필터를 유지하면서 한 번에 최대 50문장씩 표시한다. 검색 조건을 바꾸면 첫 페이지로 돌아가며 검색어를 주소나 영속 저장소에 보관하지 않는다.
- 배포 점검과 SQL 조회는 사용자가 요청한 경우에만 실행한다. 이 화면은 DDL을 실행하지 않으며 새로운 변경 API를 추가하지 않는다.
- 모바일 지표는 두 열로 비교하고 표 영역만 가로로 읽는다. SQL 본문은 13px 이상이며 다이얼로그 안에서 읽는다.

## 로컬 검증 결과

기존 문제 6개를 회귀 검사로 재현했다. 현재 탭 새로고침, 팀 변경 시 배포 점검·SQL 의도 폐기,
인덱스 실패 표시, 조회 거부 데이터 폐기, 접근 권한이 없는 바로가기를 보완했다.
최종 검토에서 장애 후보·작업·SQL 조회 실패의 0건·정상 빈 목록 표시 3건도 재현하고 보완했다.
전체 Phase 0–6 완료 또는 운영 Stable 승격을 의미하지 않는다.

- 전체 React 5,934개 / 403개 파일, 시스템 집중 28개 통과. 보조 도구 54개 통과와 선택 환경 15개 로컬 건너뜀을 구분한다.
- Go 내장·네트워크 차단 브라우저 110개가 재시도·건너뜀 없이 통과했다. 현재 탭 새로고침·비활성 탭 갱신 중지·직접 주소·오류 복구·SQL 페이지·키보드 초점을 확인했다.
- 네 탭의 밝은/어두운 테마와 1440px·390px 시각 기준 16장, axe와 페이지 넘침 검사를 통과했다. 기존 앱 셸·게이트웨이 상태·읽기 전용 전환도 함께 검사했다.
- 새 내장 자산의 실제 Go/OIDC/SQLite 인증 46개, Go App UI와 기존 관리자 회귀, ESLint·포맷·타입·OpenAPI 계약·프로덕션 빌드를 확인했다.
- 내장 자산 188개와 해시·CSP·캐시·MIME·직접 주소·누락 자산 404·잘못된 메서드 405·기존 관리자 접근을 확인했다. 초기 압축 261,494/350,000바이트, 화면 47개와 선택 도구 6개가 예산 안이다.
- Go 19개·npm 389개의 통합 SBOM과 라이선스 목록을 갱신했다. 최종 검사 도중 추적 소스와 자산의 변경이 없음을 대조했다.

첫 브라우저 실행은 63개 통과·2개 실패였다. 운영 카드 주소의 중복 `/app`을 수정했고,
자동 갱신 선택은 실제 접근성 역할과 이름으로 찾도록 교정했다. 최종 시각 비교는 허용 오차를
완화하지 않았다. 배포 전 PR·실제 메인 CI, 정식 컨테이너와 공개 파일 검증은 별도 게이트다.
