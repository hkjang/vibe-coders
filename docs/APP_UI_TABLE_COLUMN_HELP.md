# 요청 목록의 열 단위와 설명

요청 탐색기의 지연·토큰·비용 열에 설명 버튼을 제공합니다. 지연은 밀리초(ms), 토큰은 개수를 헤더에서 확인할 수 있습니다. 비용은 요청에 기록된 추정 금액과 통화를 그대로 표시하며, 임의로 원화 환산하거나 통화 간 합산하지 않습니다. 캐시·추론 토큰을 전체 토큰에 다시 더하지 않는다는 점과 사용량 기록이 없을 때의 0 표시도 설명합니다.

설명은 마우스를 올리거나 키보드 초점을 두면 열립니다. 설명 위로 마우스를 옮겨도 유지되며, 클릭·터치로 고정할 수 있습니다. 다시 누르거나 바깥을 선택하거나 Escape를 누르면 닫힙니다. Escape 뒤에도 조작한 버튼의 초점은 유지됩니다. 표의 스크롤 경계에 설명이 잘리지 않으며, 연결된 열이 화면 밖으로 사라지면 설명도 닫힙니다.

새 기본 너비는 지연 144px, 토큰 136px입니다. 기존에 저장한 사용자 너비·열 순서·표시 여부를 변경하지 않습니다. 최소 80px 열에서도 설명 버튼과 너비 조절 손잡이를 분리합니다. 표의 값, 정렬, 행 선택, CSV 원본 값과 서버 조회는 그대로 유지합니다.

## 공통 컴포넌트 적용

열의 `meta.help`에 정적인 `description`과 선택적인 `unit`을 정의합니다. 공통 `DataTable`은 `headerContent={DataTableHeaderContent}`로 설명을 사용하는 표에서만 동작 코드를 참조할 수 있습니다. 별도 표 구현인 요청 목록도 같은 헤더 컴포넌트를 사용합니다. 행 데이터나 비밀값을 도움말 메타데이터에 전달하지 않습니다.

기본 헤더 스타일은 기존 표 디자인 시스템에 포함하고, 떠 있는 설명의 위치·스크롤·초점 처리는 사용자 조작 시에만 로컬 에셋으로 불러옵니다. 화면별 250KB와 초기 350KB 제한을 유지하며 설명 표시 도구의 별도 예산도 검사합니다. 아직 다른 모든 도메인의 단위·설명을 이전한 것은 아니며 TABLE-014 전체 인수와 Stable 승격은 별도입니다.

## 검증 기록

관련 React 검사 227개와 번들 검증 도구 검사 32개를 통과했습니다. 초기 공통 메타데이터 타입에서 기존 API 키 작업 렌더러 확장을 허용하지 않은 문제를 수정했고, 새 단위 표기와 비동기 에셋 표시를 검사 기대값에 반영했습니다. 브라우저 첫 검사에서는 12개 통과·4개 접근성 실패를 확인해 설명을 기존 본문 또는 대화상자 내부에 연결하도록 수정했습니다. 초기 성능 예산 초과는 설명 도구의 지연 로딩과 표별 명시적 적용으로 해결했으며 예산을 늘리지 않았습니다.

최종 v0.86.171 빌드에서 OpenAPI·린트·서식·엄격한 타입·실제 Go 내장 경로와 기존 관리자·통합 SBOM을 확인했습니다. 초기 압축 전송은 284,295바이트이며 화면 48개와 선택 도구 10개가 기존 예산을 충족합니다. 브라우저 17개와 요청 선택·CSV 회귀 9개를 재시도나 이미지 갱신 없이 통과했습니다. 먼저 의도한 이미지 기준 6개를 갱신하고, 변경 없는 모바일 기준 2개와 실제 설명 화면 4개를 포함한 총 12개 이미지를 직접 검토했습니다. 키보드·터치·초점·접근성·최소 너비·사용자 설정 복원·에셋 지연 후 취소와 원본 CSV 값을 확인했습니다. 원격 후보·메인 검증과 공개 릴리스는 별도입니다.
