# 표의 행 메뉴와 열 설정

v0.86.82 후보는 공통 표의 기존 상세 작업을 더 쉽게 여는 기능과 선택형 열 설정 로딩을 제공한다.
기능별 Preview 상태, 조회 권한, 기존 상세 화면과 서버 API를 재사용한다.

## 행 메뉴

행의 일반 셀 또는 `상세` 버튼을 오른쪽 클릭하면 해당 행의 기존 작업 하나를 표시한다.
`상세` 버튼에 초점을 두고 `Shift+F10`이나 메뉴 키로도 열 수 있다. Enter·Space로 선택하고
Esc로 취소한다. 취소와 상세 창 닫기는 원래 버튼으로 초점을 돌리며 Tab은 다음 조작으로 이동한다.
메뉴가 바깥 상세 창 안에 있어도 Esc 한 번은 행 메뉴만 닫는다.

링크·입력·별도 버튼과 선택한 텍스트의 브라우저 메뉴는 유지한다. 모바일에서는 기존 상세
버튼을 사용할 수 있다. 메뉴는 화면 안으로 위치를 조정하며 표 스크롤 영역에 잘리지 않는다.
조회 실패·로딩·권한 회수·행 교체는 열린 메뉴를 폐기한다. 목록을 복원해도 이전 메뉴는 열리지 않는다.

이 기능은 `onRowClick`과 `getRowActionLabel`을 함께 제공하는 공통 표에 적용한다. 모든 셀의
개별 작업을 메뉴로 복제하지 않으며 삭제·실행·복사·일괄 변경 작업을 추가하지 않는다.
팝오버를 지원하지 않는 브라우저에서는 브라우저 기본 메뉴와 기존 상세 버튼을 사용한다.

## 필요한 도구만 불러오기

행 메뉴와 열 설정은 각각 처음 열 때 로컬 JavaScript를 요청한다. 열 설정의 필수 열 보호,
열 표시·순서·너비와 저장된 사용자 설정은 유지한다. 파일 다운로드 중 다른 곳을 누르거나
키보드로 이동하면 보류한 창을 취소한다. 뒤늦은 응답이 초점을 가져가지 않는다.
다운로드 실패는 한글로 안내하며 목록 조회와 기존 상세 버튼을 계속 사용할 수 있다.

외부 자산이나 추가 npm 의존성은 없다. 초기 350,000바이트 전송 상한과 일반 화면
250,000바이트 원본 상한을 유지한다. 명시적 도구의 전체 의존성에는 별도 상한을 적용한다.

| 도구 | 원본 상한 | 전송 상한 |
| --- | ---: | ---: |
| 행 메뉴 | 8,000바이트 | 4,000바이트 |
| 열 설정 | 12,000바이트 | 6,000바이트 |

이 상한은 도구를 초기·일반 화면에서 제외하기 위한 무조건 예외가 아니다. 정적 가져오기는
실패 처리하고 브라우저 검사에서 조작 전 요청 없음, 지연 취소, 파일 실패를 검증한다.
편집기의 별도 상한은 [편집기 안내](APP_UI_CODE_EDITOR.md)를 따른다.

## 검증 범위

단위 검사는 기존 클릭·링크·입력, 선택한 텍스트, 행·권한 변경, 중첩 상세 창과 구형 브라우저
대체 동작을 확인한다. 브라우저 검사는 실제 팝오버, 첫 열기·재열기, Esc·Tab·스크롤,
상세 왕복 초점, 자산 지연·실패와 열 설정의 기존 동작을 확인한다.
390px·1440px의 밝은/어두운 화면에서 메뉴 위치, 키보드와 axe 검사를 수행한다.
시각 비교는 애니메이션 축소 설정을 사용하며 자동 접근성 검사가 WCAG 전체 수동 검증을 대신하지 않는다.

TABLE-013의 공통 행 작업 범위이며 전체 Phase 0–6 완료나 기능의 Stable 승격을 의미하지 않는다.
