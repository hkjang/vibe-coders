# 긴 목록과 펼칠 수 있는 셀 내용

MCP 도구 화면의 도구 위험 등급·서버 사용량·카탈로그·신뢰 점수는 100행을 넘으면 현재 보이는 구간과 주변 행만 그립니다. API의 조회 상한, 필터, 반환 데이터와 권한은 그대로 사용합니다. 서버 페이지 분할을 대체하거나 화면에 없는 행을 삭제하지 않습니다. 다른 화면은 명시적으로 `VirtualDataTable`을 선택하기 전까지 기존 표를 사용합니다.

## 화면 동작

- 표 안에서 위아래와 좌우로 스크롤합니다. 헤더와 각 열 너비를 유지하며 마지막 행까지 접근할 수 있습니다.
- 긴 서버·도구 식별자는 두 줄로 표시합니다. 펼침 화살표를 클릭하거나 Tab으로 이동해 Enter·Space를 누르면 전체 값을 볼 수 있습니다. 다시 누르면 접힙니다.
- 키보드 초점이 있는 행과 편집창을 연 행은 스크롤 밖에서도 유지합니다. 창을 닫으면 같은 도구의 버튼으로 돌아옵니다.
- 행 높이는 실제 내용과 글자 확대를 반영합니다. 브라우저의 별도 스크롤 보정을 끄고 가상 목록이 높이 보정을 담당합니다.
- 도구 위험 설정과 업스트림 등록·수정 코드는 편집을 시작할 때 로드합니다. 다운로드 중에도 닫을 수 있고, 취소·화면 이동·조회 권한 회수 후 늦은 다운로드가 창을 다시 열지 않습니다.
- 목록 코드 다운로드 실패는 한글 오류와 새로고침을 제공합니다. 권한과 변경 전 비교·저장 직전 확인은 기존 편집 흐름이 담당합니다.

## 공통 구현

`DataTable`은 표 구조·열 설정·정렬·페이지·행 작업을 계속 소유하고, 선택적인 행 렌더러만 받습니다. `VirtualDataTable`이 100행 초과일 때 TanStack Virtual을 지연 로드합니다. native table/tbody/tr/td와 전체 `aria-rowcount`, 실제 위치의 `aria-rowindex`를 사용합니다. 여백용 행은 접근성 트리에서 제외합니다.

`VirtualTableBody`의 범위 추출기는 현재 초점 행을 추가하고 행 키로 식별합니다. 펼친 내용과 헤더 높이는 실제 DOM을 측정합니다. TanStack Virtual v3의 변경 가능한 인스턴스는 이 컴포넌트 안에만 유지하고 `use no memo`로 React Compiler 대상에서 제외합니다. 해당 호출의 알려진 호환성 경고만 설명과 함께 제외하며 다른 린트 검사는 유지합니다.

참고: [TanStack Virtual API](https://tanstack.com/virtual/latest/docs/api/virtualizer), [native table 예제](https://tanstack.com/virtual/latest/docs/framework/react/examples/table), [React의 라이브러리 호환성 검사](https://react.dev/reference/eslint-plugin-react-hooks/lints/incompatible-library).

## 검증 범위와 출고

기존 생산 빌드에서 200행이 모두 렌더링되는 것을 재현했습니다. 합성 브라우저는 실제 MCP 조회 상한 200을 지키고 표시 행 수, 마지막 행, 60회 연속 Tab, 편집 초점 복귀, 필터 축소, 다운로드 오류·취소·권한 회수, 한글·영문 긴 내용, 1440/390px, 밝은/어두운 테마, 글자 확대와 접근성을 검사합니다. 일반 표·홈·요청 표·선택·열 설정·문맥 메뉴의 기존 회귀도 출고 검사에 포함합니다.

초기 350KB와 화면별 250KB 예산을 유지합니다. 실제 편집 동작 이후에만 로드되는 두 기존 폼은 전체 의존성을 포함한 별도 예산으로 검사합니다. 행 렌더러는 편집 도구 예외로 분류하지 않고 화면 예산에 포함합니다. 새 의존성은 잠금 파일과 통합 Go/npm SBOM·라이선스에 포함합니다.

v0.86.172 개발 후보입니다. v0.86.171 공개 검증 이후 후보 리뷰·전체 CI·실제 메인 CI·공식 배포 파일 검증으로 순차 출고합니다. MCP 첫 적용을 모든 화면의 TABLE-008 완료나 운영 Stable 승격으로 간주하지 않습니다.
