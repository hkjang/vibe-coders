# Text2SQL 실행 연결의 현재 설정 적용

v0.86.110 후보. 연결 관리와 실행 API를 그대로 사용하며 `/admin`과 `/app`에 같은 동작을 적용한다.

- 프로필 저장 API가 선택한 실행 DB 식별자를 실제로 저장·반환한다. 기본 연결 문자열이 없어도 이름 있는 연결을 선택한 실행 프로필은 해당 DB에서 조회한다. 선택한 연결 삭제나 프로필 조회 실패는 다른 DB 실행으로 대체하지 않는다. 실행 모드는 `미리보기 (SQL 생성만)`과 `실행 (SQL 조회까지)`로 표시한다.
- 이름 있는 연결을 실행할 때 해당 연결의 드라이버와 DB를 하나의 대상으로 사용한다. 기본 연결이 SQLite이고 선택한 연결이 PostgreSQL이어도 읽기 전용 트랜잭션·제한 시간·메모리 설정·실행 계획 위험 검사를 적용한다. 실행 계획 조회 역시 읽기 전용 트랜잭션에서 수행한다.
- 실행 전 저장된 연결의 현재 상태를 조회한다. 다른 인스턴스에서 바꾼 설정, 비활성화, 삭제를 기존 캐시가 우회하지 않는다. 현재 설정을 읽거나 복호화할 수 없으면 이전 연결로 실행하지 않는다.
- 기본 연결과 검증용 연결은 설정과 드라이버를 함께 읽는다. 설정 반영과 캐시 교체를 함께 처리하며 빈 연결 문자열이 임의의 SQLite DB가 되지 않도록 거부한다.
- 연결 문자열은 캐시의 비교용 메타데이터에 저장하지 않고 해시로 비교한다. 실제 드라이버 내부의 자격 증명 보관을 없애는 기능은 아니다. 교체된 연결 풀은 잠금 밖에서 닫으며 진행 중 작업은 기존 연결에서 마무리될 수 있다.
- 실제 연결 시점까지 지연된 드라이버 오류도 한글 일반 안내로 바꾼다. 취소·시간 초과·잘못된 연결 상태는 유지하고 정상 연결 후 SQL 오류는 보존한다. 연결 풀 종료 시 드라이버의 정리 기능도 호출한다.
- 스키마 수집도 같은 연결·드라이버 쌍을 사용한다. 기존 조회 권한, 변경 권한과 감사 흐름은 유지한다.

## 검증

수정 전 연결 변경·삭제·취소 시 오래된 캐시가 사용되는 실패와, 기본 SQLite/선택 PostgreSQL 조합에서 읽기 전용 설정이 빠지는 실패를 재현했다.

수정 후 SQLite 및 격리된 PostgreSQL 17에서 race 검사를 통과했다. PostgreSQL의 읽기 전용 상태·250ms 제한 시간·1MB 메모리 설정과 실행 계획 거부를 실제 조회했으며, 쓰기 함수가 시퀀스를 변경하지 못하는 것도 확인했다. HTTP 연결 변경·스키마 수집·삭제 후 재사용 거부, 동시 조회의 단일 풀 재사용과 교체 후 자원 정리, 기본·검증 연결 전환을 검증했다. 잘못된 연결 문자열과 정리 오류에서 비밀 표식이 노출되지 않는지 검사했다.

기존 설정 반영 검사는 처음 연결 문자열을 암호화하지 않고 적용 오류도 무시하고 있었다. 실제 암호화된 설정을 저장하고 적용 성공·유효 값을 확인하도록 강화했다. Text2SQL·설정 회귀의 race 검사와 Go vet를 통과했다.

후속 프로필 저장·실행 보완은 수정 전 HTTP 저장 누락과 기본 DB 미설정 시 미리보기 처리 실패를 재현했다. 실제 HTTP 프로필 저장 → 요청 → 선택한 DB 결과·실행 이력 확인을 기본 DB 유무별로 검사했다. 선택한 연결을 삭제한 뒤 다른 DB로 실행하지 않는지와 프로필 조회 실패의 일반 오류 응답도 확인했다. 같은 검사를 SQLite·PostgreSQL 저장소에서 race 검사로 통과했다. 프로필 OpenAPI 입력·응답에 연결 식별자를 명시하고 UI 저장 타입을 생성 계약에서 가져오며 연결 문자열은 계약에 포함하지 않는다.

추가된 테마·프로필 보완을 포함해 관련 React 검사 108개, Go 내장 브라우저 55개와 실제 Go·OIDC·SQLite 인증 검사 46개를 재시도 없이 통과했다. 네트워크 차단 환경에서 기존 관리자·깊은 주소·CSP·에셋 191개의 해시와 캐시를 확인했다. 초기 압축 번들은 261,829/350,000바이트이고 화면 48개·선택 도구 6개가 예산 안이다. 실제 격리 Go 서버의 OpenAPI와 생성 계약을 대조하고 Go 19개·npm 389개 통합 SBOM·라이선스를 갱신했다. 버전·SBOM·배포 기본값 회귀와 기존 관리자 검사도 출고 기준에 포함한다.

프로필 선택 UI 검사는 API 모의 응답을 사용하고, 실제 DB 선택은 별도의 Go HTTP 검사로 확인했다. 실제 브라우저에서 모델 호출까지 연결한 업무 검증으로 확대 해석하지 않는다.

브라우저·실제 인증 검사가 끝날 때까지 소스 해시를 확인했으며 이후 결과 문서만 갱신했다. PR·실제 메인 CI와 공개 출고는 진행 중이다. 실제 MySQL·Oracle 서버에서의 실행 검증은 수행하지 않았으며 전체 Phase 0–6 및 운영 Stable 인수를 완료한 것으로 간주하지 않는다.
