# Text2SQL 실행 설정의 한글 안내와 연결 상태

v0.86.111 후보. 기존 실행 설정 API와 권한을 재사용하며 `/admin`과 실행 처리 방식은 유지한다.

- 선택 기능을 `SQL 추가 검토`, `최근 스키마 활용`, `누적 위험 차단`으로 표시한다. 서버로 보내는 기존 식별자는 유지하며 새 서버 기능은 원래 식별자를 함께 표시해 의미를 임의로 해석하지 않는다.
- 스위치의 접근성 이름에 기능 이름과 화면에 보이는 상태를 함께 담는다. 키보드로 특정 기능을 선택할 수 있고 처리 중 중복 요청과 읽기 전용 변경을 막는다. 목록 갱신 실패 시 이전 상태를 바탕으로 변경하지 않고 수동 재조회 후 복구한다.
- 프로필의 실행 DB는 기본 DB(서버 설정), 조회 중, 상태 확인 불가, 조회 목록의 미등록 연결, 등록된 연결 이름, 중지를 구분한다. 조회 실패를 삭제로 표시하거나 이름 있는 연결을 기본 DB로 표시하지 않는다. 등록된 이름은 실제 DB 통신 성공을 뜻하지 않으며 연결 점검은 기존 명시적 작업으로 제공한다.
- 상태 배지의 의미 색상을 보존하고 기존 표 글자 크기를 유지한다. 작은 화면에서도 스위치의 켜짐·꺼짐 글자를 한 줄로 유지한다. 기능 상태·프로필 연결 표시를 별도 구성요소로 분리한다.

## 검증

관련 React·테마 검사 115개/11파일을 통과했다. 한글 이름으로 키보드 선택한 기능의 정확한 기존 식별자 전송, 중복 전송·읽기 전용 거부, 조회 실패 후 변경 차단·재시도, 기본·조회 중·미등록·중지·실패 구분을 확인했다.

첫 시각 기준 생성은 브라우저 57개를 통과했으나 실제 작은 화면 이미지에서 스위치 글자 줄바꿈을 발견했다. 축소와 줄바꿈을 보완하고 기능 상태 글자의 줄 수를 검사에 추가했다. 후속 생성과 최종 검증은 각각 57개, 재시도·건너뜀·불안정 통과 0이었다. 두 테마·두 화면 폭의 시각 기준 20장 중 14장을 변경했으며 실행 설정 배치, 기존 표 배지 색상, 연결 점검 영역의 위치 변화를 확인했다. PC·작은 화면의 실행 설정과 연결 점검 이미지를 직접 검토했다.

최종 Go 내장 UI에서 접근성·키보드·깊은 주소·기존 관리자·CSP·정적 에셋 193개를 검증했고, 같은 소스의 실제 Go·OIDC·SQLite 인증 46개도 통과했다. 업무 UI 동작은 API 모의 응답 검사이며 실제 운영 DB·Keycloak과 전체 업무 흐름 검증을 대신하지 않는다.

타입 검사·린트·포맷·빌드·번들 예산, 실제 Go 서버와 OpenAPI 스냅샷 대조, 기존 관리자·버전·API 경로 회귀를 통과했다. 초기 압축 번들은 261,824/350,000바이트이고 화면 48개·선택 도구 6개가 예산 안이다. Go 19개·npm 389개 통합 SBOM·라이선스를 v0.86.111로 갱신했다. 최종 브라우저와 인증 검증 중 소스 해시를 보존했고 이후 결과 문서만 추가·갱신했다.

PR·실제 메인 CI·정식 릴리즈 검증은 진행 중이다. 전체 Phase 0–6 및 운영 Stable 인수 완료로 간주하지 않는다. `.gitframe/`, `output/`, `seed.sql`은 출고 대상에 포함하지 않는다.
