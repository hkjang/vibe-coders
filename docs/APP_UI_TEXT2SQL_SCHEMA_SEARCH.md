# Text2SQL 스키마 검색과 읽기 전용 상세

v0.86.107 후보. 기존 `/admin`과 스키마 편집·실행·권한 API를 유지한다.

- 자원 검색에서 스키마 이름을 검색하고 `/app/text2sql/schemas/detail?schema_name=...`으로 이동한다. 한글과 `/`, `?`, `%`, `#`를 포함한 이름도 정확히 선택하며 직접 접근·새로고침을 지원한다.
- 검색은 이름만 선택하며 설명, 허용 테이블, 연결 정보, 소속 팀, 지문을 검색 결과에 포함하지 않는다. 한 종류당 10개와 추가 결과 여부를 제공한다. 민감한 이름은 검색에서 제외한다.
- 조회 범위는 기존 Text2SQL 운영 화면과 같다. 전체 관리자는 전체, 팀 관리자는 공용 스키마와 자신의 팀 ID·기존 팀 이름에 연결된 스키마를 본다. 팀 확인 실패는 조회 범위를 넓히지 않는다. 중지된 스키마도 운영 조회에 포함한다.
- 기존 `GET /admin/text2sql`에 `view=schema&name=...` 조회를 추가한다. 이름을 정확히 일치시키며 기본 스키마로 대체하지 않는다. 없는 이름과 다른 팀의 이름은 같은 일반 404를 반환한다. 중복·잘못된 쿼리는 목록으로 전환하지 않는다.
- 기존 원문 조회 권한이 없으면 설명과 허용 테이블을 내려주지 않는다. 신규 상세는 등록 정보만 표시하며 이를 ‘테이블 제한 없음’으로 오인하지 않게 안내한다.
- 현재 계정·팀·세션·조회 권한·인증정보 접두사가 바뀌면 이전 상세와 늦은 응답을 폐기한다. 조회 실패는 이전 정보를 숨기고 수동 재시도를, 인증·권한 거부는 명시적 권한 재확인을 제공한다.
- 설명은 접어서 시작하고 16,384자보다 큰 본문은 기존 화면에서 확인하도록 안내한다. 허용 테이블은 50개씩 탐색한다. 인증정보로 보이는 문자열은 표시하지 않는다.
- 이전 서버에는 신규 조회를 보내지 않는다. 기존 목록·편집을 유지하며 조회할 수 있는 이름에 상세 링크를 추가한다. 변경·연결 검사·모델 호출·SQL 실행·감사 쓰기는 발생하지 않는다.
- 명령 팔레트·상세·상태·오류·페이지 탐색을 한글로 제공하며, 두 테마·좁은 화면·키보드·접근성을 검증한다.


## 로컬 검증 결과

- 전체 React 5,960개 / 405개 파일, 스키마 집중 26개 통과. 도구 54개 통과와 선택 환경 15개 로컬 건너뜀을 구분한다.
- SQLite·PostgreSQL에서 검색·팀 범위·이름 일치·중지 상태·취소·원문 권한·Legacy Token·기능 비공개·실제 HTTP 계약을 race 검사로 확인했다. 기존 Text2SQL 조회와 관리자 회귀도 통과했다.
- Go 내장·네트워크 차단 브라우저 76개가 최종 재시도·건너뜀 없이 통과했다. 검색·직접 주소·새로고침·실패 복구·권한 거부·키보드와 기존 검색 화면을 함께 확인했다.
- 밝은/어두운 테마, 1440px·390px 시각 기준 4장과 axe·넘침 검사를 통과했다. 초기 모바일 캡처의 스크롤 위치를 고정했고, 한 차례 테마 적용 시점에 발생한 대비 오류는 테마 속성과 실제 글자색 확인 후 검사하도록 보완했다. 대비 기준과 이미지 오차를 완화하지 않았다.
- 실제 Go/OIDC/SQLite 인증 46개에서 스키마 검색·정확한 상세·원문 권한·새로고침을 포함해 검증했다. TypeScript·ESLint·포맷·OpenAPI 생성 계약·프로덕션 빌드가 통과했다.
- 내장 자산 191개, CSP·해시·캐시·MIME·깊은 주소·누락 에셋 404·잘못된 메서드 405·기존 관리자 접근을 확인했다. 초기 압축 261,726/350,000바이트, 화면 48개·선택 도구 6개가 예산 안이다.
- 통합 Go 19개·npm 389개 SBOM과 라이선스를 갱신했다. 검사 중 소스 해시를 비교했으며 결과 문서만 이후 갱신했다. 인증 검사 후의 추가 변경은 합성 브라우저의 테마·스크롤 준비 확인과 시각 기준이다.

PR·실제 메인 CI·정식 컨테이너·공개 배포 파일 검증은 별도 출고 게이트다. 전체 Phase 0–6와 운영 Stable 인수는 계속 진행한다.
