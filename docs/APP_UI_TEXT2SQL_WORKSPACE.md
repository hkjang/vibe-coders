# Text2SQL 운영 화면 갱신·작업 보호

v0.86.108 후보. 기존 `/admin`과 변경 API를 유지한다.

- 7개 탭에서 현재 화면에 필요한 데이터만 읽고 새로고침한다. 자동 갱신은 활성 브라우저에서만 수행하고 마지막 정상 갱신 시각을 표시한다. 연결 점검과 요청 단계 조회는 명시적으로 실행한다.
- 팀·계정·세션·역할·원문 권한이 바뀌면 이전 화면의 데이터와 늦은 결과를 폐기한다. 인증·조회 거부 시 마지막 정상 질문과 SQL도 제거하고 수동 재시도로 다시 권한을 확인한다.
- 일부 조회 실패에도 다른 탭과 정상 패널을 사용할 수 있다. 변경 권한·읽기 전용 설정을 실행 시점에 확인하며 중복 실행을 막는다. 권한을 회수했다가 복원해도 이전 작업의 결과·알림·새 조회는 적용하지 않는다.
- JSON 내보내기는 시작한 화면이 유효할 때만 다운로드한다. 가져오기는 2MB 이하 JSON과 테이블·컬럼 형식을 검증하고, 파일 읽기가 끝난 뒤에도 현재 권한을 다시 확인한다.
- 기준 SQL 검증, 연결 점검, 처리 상태·단계명을 한글로 표시한다. 작은 글자와 좁은 화면의 오류 안내를 조정한다. 긴급 중지의 기존 재확인·감사 흐름을 유지한다.

## 로컬 검증

- 전체 React 5,995개 / 408개 파일, Text2SQL 집중 96개 통과. 도구 54개 통과와 선택 환경 15개 건너뜀을 구분한다.
- 초기 구현에서 현재 탭 밖 조회·잘못된 갱신 대상·조회 거부 후 원문 유지·팀 전환 늦은 읽기를 재현했다. 늦은 삭제 결과의 팀 전환·권한 회수/복원 두 사례도 수정 전 실패와 수정 후 통과를 확인했다.
- 각 탭의 갱신 대상, 자동 갱신·비활성 중단, 403 제거·재시도, 독립 오류 복구, 편집 초안 유지·강제 제출 차단, 파일 읽기 중 권한 변경, 중복 실행, 민감한 DB 진단 마스킹을 검사했다.
- Go 내장·네트워크 차단 브라우저 48개 통과. 직접 주소·새로고침·한글 탭·기존 편집기·긴급 제어·JSON 검증·늦은 내보내기 폐기를 확인했다. 두 테마·1440px/390px 시각 기준 16장, axe·키보드·가로 넘침 검사를 통과했다.
- 초기 시각 검사 8개는 키보드가 이동한 뒤 이전 탭에 다시 키를 보내는 테스트 오류였다. 현재 포커스·선택 상태·실제 패널과 조회 완료를 확인하도록 수정했으며 기준이나 허용 오차를 완화하지 않았다.
- 실제 Go/OIDC/SQLite 인증 46개, 기존 관리자 정적·행위 회귀와 Go App UI 검사가 통과했다. 내장 자산 191개의 해시·CSP·캐시·MIME·깊은 주소·404·405·기존 관리자 접근을 확인했다.
- 초기 압축 261,717/350,000바이트, 화면 48개·선택 도구 6개가 예산 안이다. Go 19개·npm 389개 통합 SBOM과 라이선스를 갱신했다.
- 검사 중 소스 해시를 비교했다. 전체 검사 이후에는 결과 문서와 브라우저 업로드 테스트의 고정 JSON 파일 입력만 정리했으며 애플리케이션·단위 검사 소스는 동일하다. 이후 타입·린트·최종 브라우저 48개를 별도로 통과했다.

PR·실제 메인 CI·정식 컨테이너와 공개 배포 검증은 별도 출고 게이트다. 전체 Phase 0–6와 운영 Stable 인수는 계속 진행한다.
