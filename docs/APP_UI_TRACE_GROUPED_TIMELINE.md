# 추적별 요청 흐름 보기

추적 탐색기의 `시간순 보기`와 `추적별 보기`로 같은 요청 목록을 살펴봅니다. 추적별 보기는 현재 페이지에서 공개된 추적 ID가 정확히 같은 요청을 묶으며, 각 묶음에 요청 수·HTTP 오류 수·상태 미확인 수·최대 기록 지연을 표시합니다. ID가 비공개이거나 없는 요청은 각각 표시합니다. 상단 추적 개수도 공개 ID만 세어, 같은 비공개 안내문을 하나의 추적으로 잘못 계산하지 않습니다. 이 숫자는 전체 추적 집계가 아닙니다.

묶음 제목을 클릭하거나 Enter·Space로 펼칩니다. 펼친 뒤 Tab으로 요청을 선택하면 기존 상세와 단계 기록을 엽니다. 주소로 선택한 요청이나 요청 표에서 선택한 요청이 있는 묶음은 자동으로 펼칩니다. 상세를 닫을 때 원래 묶음이 접혀 있으면 다시 펼쳐 요청 버튼으로 초점을 돌립니다.

`timeline_view=trace`는 목록 조건·선택과 함께 주소에 보존합니다. 보기만 바꾸면 추가 목록 조회를 보내지 않습니다. 필터 재조회·변경·초기화 후에도 선택한 시간순·추적별 보기를 유지합니다. 유효한 단일 보기 값만 다음 주소에 옮기며 조회 조건·페이지·요청 선택은 기존 규칙대로 갱신합니다. 뒤로·앞으로 이동과 로그인·SSO 복귀, 새로고침에서도 표시 방식을 복원합니다. 개별 묶음의 접힘은 현재 화면의 일시적인 상태이며 새로고침 뒤에는 선택한 묶음만 자동으로 펼칩니다.

기록된 시간축과 요청 순번은 시간순 보기와 동일합니다. 두 보기의 눈금은 실제 막대 영역의 양 끝에 맞춥니다. 묶음은 실제 실행 순서나 분산 스팬의 부모·자식 관계를 뜻하지 않습니다. 서버의 기존 `LLMSpan.ParentID`도 요청/도구 기록으로 합성한 관계이므로 이를 전체 분산 스팬 트리의 근거로 사용하지 않습니다. 별도의 추적 수집·계약 검증이 필요한 Phase 1 잔여 항목입니다.

기존 안전한 요청 목록 API·권한·읽기 소유 범위를 재사용합니다. 원문 상세·추가 API·새 런타임 의존성을 추가하지 않으며 `/admin`은 유지합니다. URL의 표시 값은 단일 `time` 또는 `trace`만 허용하고 잘못되거나 중복된 값은 제거합니다. v1 응답의 요청 상세 제한과 권한 회수 시 기록 폐기도 유지합니다.

## 검증

전체 React 6,623개(470개 파일)와 기본 Node 검사 57개를 통과했다. 외부 산출물 선택 검사 15개는 기본 명령의 제외 항목이다. 이후 시각 확인에서 시간 눈금의 279px 어긋남을 브라우저로 재현하고 수정했다. 수정 후 관련 React 559개(21개 파일), 전체 린트·포맷·타입 검사, 새 프로덕션 빌드와 예산 검사를 통과했다. 최종 내장 Go/CSP 브라우저 60개는 기준 이미지 변경·재시도·건너뜀·불안정 결과 없이 통과했다. 새 기준 이미지 8장을 직접 확인했으며 기존 이미지는 바꾸지 않았다. 좌표 검사는 보기 전환 완료 뒤 하나의 레이아웃 스냅샷에서 1px 오차 상한을 확인한다. 실제 내장 Go 서버의 195개 자산 해시·CSP·캐시·MIME·직접 주소·누락 자산 404·POST 405·기존 관리자 200을 네트워크 없는 컨테이너에서 검증했다. 관리 API는 합성 응답이다. 관련 Go 앱·관리자·인증·Keycloak·OpenAPI 검사와 API 표면(424 서버/484 OpenAPI/371 React 연결), 실제 Go OpenAPI 생성 계약을 검증했다. 부모 커밋의 세션 길이 수정은 동일한 소스 해시와 해당 Go·브라우저 검증으로 확인했다. 통합 SBOM은 19 Go/389 npm이며 초기 전송 크기는 268,924바이트다.

 운영 사용자 인수와 기능별 Stable 승격, 전체 Phase 0–6 완료를 의미하지 않습니다.

## 필터 적용 시 보기 유지 보완

동일한 조건으로 흐름을 다시 조회할 때 `timeline_view`가 빠지는 리뷰 지적을 두 구성요소 실패로 재현했다. 수정 뒤 관련 React 561개(21개 파일), 전체 타입 검사와 변경 파일 린트·포맷, 새 프로덕션 빌드·성능 예산을 통과했다. 전체 린트·포맷은 검사 코드의 타입 옵션 정리 전에 통과했고 정리한 파일은 다시 확인했다. 최종 내장 Go/CSP 브라우저 61개는 필터 재적용·변경·초기화·새로고침·뒤로 이동을 포함하며, 기준 이미지 변경·재시도·건너뜀·불안정 결과 없이 통과했다. 최종 초기 전송 크기는 268,895바이트다. 상위 세션·추적 PostgreSQL 바이트 계산과 이전 인덱스 교체는 동일한 SQL 소스를 실제 PostgreSQL race 37개로 검증했다.
