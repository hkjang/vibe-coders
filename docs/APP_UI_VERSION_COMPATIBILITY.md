# 화면과 API 버전 안내

`/app`은 공통 API 클라이언트가 지원하는 API 세대(`v1`)와 로그인 초기 조회에서 받은
`api_version`을 비교한다. 서버의 릴리즈 번호(`v0.86.x`)는 API 세대와 별개다.
지원하지 않는 API 버전이면 현재 화면 위에 한글 안내와 새로고침 버튼을 표시한다.
기존 관리자 접근 권한과 기존 화면 이동 설정이 모두 허용할 때만 `/admin` 링크를 제공한다.
권한이 갱신되면 링크도 갱신한다.

안내는 자동 새로고침이나 화면 이동을 실행하지 않는다. 작업 중인 내용을 보관한 뒤
사용자가 새로고침할 수 있다. API 버전이 아직 없거나 확인되지 않은 기존 인증 경로에서는
불일치를 단정하지 않는다. 서버가 보낸 임의의 API 버전 문자열은 안내 본문에 출력하지 않는다.

지원하는 API이면서 새 UI 릴리즈가 배포된 경우에는 기존의 새 버전 안내를 유지한다.
두 조건이 겹치면 API 호환 안내 하나를 표시한다. API 권한 검사와 기능별 최소 서버 버전
검사는 계속 적용된다.

검증: 관련 컴포넌트·공통 화면·키보드·권한·버전 테스트 44개, 타입 검사, 린트,
포맷, 프로덕션 빌드와 번들 예산 검사 통과. DOM 접근성 자동 검사도 통과했으며,
색상 대비 및 실제 운영 환경의 호환성 인수를 대신하지 않는다.
