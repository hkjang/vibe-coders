# 워크플로 단계 흐름 조회 — v0.86.92 후보

`/app/agents/workflows`에서 정의의 상세를 열고 **흐름 보기**를 선택하면 저장된 단계
순서를 연결된 카드로 확인한다. **표 보기**로 기존 단계 표를 다시 열 수 있다.
단계 선택은 조회 동작이며 저장·게시·드라이런·실행 요청을 보내지 않는다.

## 탐색과 상세

- 단계 카드를 선택하거나 위·아래 방향키, Home·End로 현재 페이지의 단계를 선택한다.
- 긴 정의는 한 번에 25단계씩 표시한다. 이전·다음 버튼으로 전체 정의를 탐색하며,
  버튼이 비활성화되는 첫·마지막 페이지에서는 사용 가능한 버튼으로 초점을 옮긴다.
- 선택한 단계의 이름·종류·참조·등록 시간·토큰·비용 한도와 메모를 확인한다.
- 허용 도구·테이블 목록은 접어서 제공하며 긴 목록은 **25개 더 보기**로 확장한다.
- 다른 정의를 열거나 조회한 정의가 바뀌면 이전 선택을 폐기한다. 부모 상세 화면의
  사용자·팀·권한 수명과 조회 취소 처리를 그대로 사용한다.

버전 이력·실행 영수증·드라이런도 목록과 같은 사용자·팀 조회 수명을 사용한다.
계정·팀 변경 시 이전 캐시를 제거하고 진행 중 요청을 취소한다. 조회가 최종 401/403으로
거부되면 상세를 닫고 **다시 시도**로 권한을 다시 확인한다. 이전 드라이런은 자동 재전송하지
않으며 다른 정의로 이동하면 취소한다. 읽기 전용 전환 시 기존 편집 초안 보존은 유지한다.

등록 한도는 저장된 설정 값이다. 실행 방식·실행기·정책에 따른 실제 적용 여부나 비용을
이 화면에서 보장하지 않는다. 조건·승인을 포함한 카드 연결도 정의의 순서를 나타낸다.
현재 실행기는 승인에서 대기하고 빈 입력 조건에서 멈출 수 있으며, MCP 도구 단계는
건너뛴다. 실제 결과는 기존 실행 이력과 영수증에서 확인한다. 분기 편집이나 실행기 기능을
추가하지 않는다.

## 표시와 접근성

종류·버튼·필드 이름은 한글로 제공하고 실제 자원 식별자는 원래 표기를 유지한다.
알 수 없는 종류, 등록하지 않은 값과 잘못된 음수·비정상 숫자를 구분한다. 비밀정보로
보이는 참조·이름·메모와 자원은 표시를 보호하고 HTML로 삽입하지 않는다. 긴 문자열은
600자까지만 표시한다. 조회 기준과 원본 정의는 수정하지 않는다.

데스크톱에서는 단계와 상세를 나란히, 좁은 화면에서는 세로로 배치한다. 선택한 단계는
테두리와 접근성 선택 상태로 표시하며 화면 읽기 프로그램에 변경된 상세 제목을 알린다.
외부 그래프 라이브러리나 에셋을 사용하지 않고 기존 워크플로 화면에 포함한다.

## 후보 검증

기존 워크플로 목록·편집·소유권 검사 37개와 새 흐름 검사 9개가 통과했다. 새 검사는
키보드·페이지 경계 초점, 정의 변경, 표시 보호, 긴 허용 목록과 axe를 포함한다.
`__proto__` 등 정의되지 않은 종류도 표·흐름에서 한글 안내로 표시한다.
실제 Go 내장 자산과 외부 네트워크가 차단된 브라우저에서 관련 24개 흐름이 통과했다.
밝은·어두운 테마의 데스크톱·모바일 시각 기준 4개를 확인하고 동일 기준으로 재검증했다.
전체 UI 회귀 5,697개 통과 후 누락된 종류를 보완해 해당 9개와 타입·배포 빌드를 다시
확인했다. 후속 상세 조회 검토에서 계정·팀 변경 및 권한 거부 문제 5건을 재현하고 수정했다.
관련 컴포넌트 검사 67개와 브라우저의 팀 변경·권한 복구·요청 취소를 다시 검증했다.
초기 번들은 254,837/350,000바이트, 워크플로 화면은 185,338/250,000바이트다.
최종 CI·정식 이미지·공개 출고와 운영 Stable 승격은 진행 중이다.
기존 `/admin`과 관리 API, 수정·게시·실행 절차 및 Preview 상태는 유지한다.
