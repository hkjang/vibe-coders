# 워크플로 그림 탐색

v0.86.161 개발 후보. 긴 분기 워크플로에서 선택한 단계가 그림 밖에 남는 문제를 보완하고 한글 탐색 도구를 제공한다. 기존 단계 정의·저장·게시 API와 인증·권한, `/admin`을 유지한다.

## 사용 방법

- `그림에서 찾을 단계`로 이동하면 선택한 단계를 원래 크기로 표시한다. 편집 화면의 `편집할 단계` 선택과도 연결된다.
- `축소`·`확대`는 25–200% 범위에서 그림 크기를 바꾼다. `전체 보기`는 긴 그림 전체를 영역에 맞추므로 25%보다 작아질 수 있다. `선택 단계 보기`로 100% 배율과 선택 위치를 복원한다.
- 그림 안의 단계에 초점이 있을 때 위·아래 화살표로 정의 순서의 앞뒤 단계, Home·End로 처음·마지막 단계로 이동한다. Enter·Space로 선택한다. Tab은 선택 단계 한 곳을 거쳐 다음 작업으로 이동한다.
- 조회 화면의 선택과 배율은 화면 탐색 상태다. 정의를 바꾸거나 저장·실행 요청을 보내지 않는다. 그림만 스크롤하며 편집 폼·상세 패널의 스크롤과 초점을 강제로 옮기지 않는다.
- 전체 보기 중 화면 크기가 바뀌면 배율을 다시 맞춘다. SVG의 실제 크기 변경을 관찰해 전체 보기에서 복귀할 때 이전 스크롤 한도에 걸리지 않도록 한다.

그림과 함께 기존 단계 연결 표를 제공한다. 좁은 화면은 도구를 줄바꿈하고 그림·표 각각에서 가로 스크롤한다. 배율은 현재 그림을 연 동안만 유지한다. 그래프 자체의 배치 편집·병렬 실행·승인 재개·게시 버전 고정은 이 개선에 포함하지 않는다.

## 검증과 출고 상태

개발 중 기존 12단계 그림의 마지막 단계 선택이 화면 밖에 남는 문제를 1440px·390px에서 재현했다. 배율 복귀 시 브라우저가 이전 SVG 크기로 스크롤을 제한하는 문제를 확인했고, 실제 크기 관찰로 수정한 뒤 밝은·어두운 테마의 조회·키보드·배율 복귀 및 편집 선택 6개를 통과했다. 최종 고정 소스로 전체 React 6,675개(479파일), 내장 브라우저 45개, 실제 Go/SQLite 저장·게시 업무 4개와 정적 파일 처리 Go 66개를 통과했다. 브라우저 재시도·건너뜀은 없으며 새 탐색 영역 4장과 도구가 추가된 기존 편집 화면 4장의 시각 기준을 확인한 뒤 변경 없이 비교했다. 실제 수정·게시·감사·동시 변경 거부·조회 계정 쓰기 거부를 검증했다.

린트·포맷·타입·실제 Go OpenAPI 생성 계약·빌드·성능 예산과 통합 SBOM(19 Go·389 npm)을 확인했다. Node 검사 64개 통과, 외부 산출물 선택 검사 16개 제외다. 초기 전송은 276,846바이트, 시작 의존성은 3,848바이트다. 앞선 전체 저장소 검사는 아래 선행 커밋의 결과이며 이번 UI 검증에서 전체 Go·인증·Keycloak를 다시 실행한 것으로 표시하지 않는다. 최종 검사 뒤 문서만 갱신했다.

함께 포함하는 SQLite 검사 기반 개선은 기존 빈 마이그레이션 결과를 닫힌 원본 이미지로 준비하고 각 검사에 별도 DB를 복제한다. 각 복제본은 일반 Open 경로로 별도 비밀값·연결·캐시·수명을 만든다. 운영 DB와 마이그레이션 코드는 변경하지 않는다. 기존 481개 Test 함수를 유지하고 7개를 추가했으며 선행 커밋에서 전체 저장소 검사 787개·race 787개와 vet를 통과했다(각각 선택 검사 14개 제외). 이는 로컬 검사 결과이며 원격 CI 시간 단축을 측정한 결과는 아니다.

후보 커밋 CI·리뷰·순차 메인 병합·공식 릴리즈와 운영 Preview 검증은 별도 단계다. 운영 Stable 및 Phase 0–6 전체 완료로 표시하지 않는다.
