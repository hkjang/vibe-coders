# XView 요청 표의 키보드 탐색과 비교

## 사용 흐름

1. XView 산점도 아래의 **표로 보기**를 클릭하거나 Tab으로 이동해 Enter를 누릅니다.
2. **페이지 이동**에서 원하는 페이지를 선택합니다. 한 페이지에 50·100·200건을 표시하며, 현재 산점도에 표시된 최대 6,000건 전체에 접근할 수 있습니다.
3. 행의 **입출력**으로 요청 상세를 엽니다. 체크박스로 여러 페이지에서 원하는 요청을 골라 **선택한 N건 비교**를 사용할 수도 있습니다. 헤더의 전체 선택은 현재 페이지뿐 아니라 표시된 전체 요청을 대상으로 합니다.
4. 상세·비교 창을 닫으면 시작한 행 또는 비교 버튼으로 초점이 돌아옵니다. 긴 요청 ID와 모델명은 펼침 버튼으로 전체를 확인합니다.
5. 표를 닫으면 기존 실시간 설정에 따라 자동 조회가 재개됩니다.

표를 탐색하는 동안 실시간 증분 조회를 멈춰 행과 선택이 자동으로 바뀌지 않게 합니다. 수동 새로고침·조건 변경·권한 변경으로 새 자료가 도착하면 이전 선택을 폐기합니다. 페이지와 표시 건수만 바꾸면 같은 자료의 선택은 유지합니다. 원래 실시간이 꺼져 있거나 종료 시각이 고정된 조회는 표를 닫아도 자동 조회를 시작하지 않습니다.

## 범위와 화면

- 조회 대상은 현재 산점도의 수신 자료와 범례 조건입니다. 전체 이력을 추가 요청하는 기능이 아니며 기존 6,000건 상한·마스킹·모델 목록 제외 설정을 유지합니다.
- 공통 표의 열 너비·순서·표시 설정을 사용합니다. 요청 데이터와 선택 ID는 브라우저 영구 저장소에 저장하지 않습니다.
- 좁은 화면에서는 표 영역만 가로로 이동합니다. 긴 텍스트는 셀 경계를 지키고 펼쳐 볼 수 있습니다.
- 표 코드는 **표로 보기**를 열 때 로드합니다. 차트와 공유하는 순수 지표 함수를 별도 묶음으로 분리하여 표가 XView 화면 전체를 다시 가져오지 않도록 합니다.
- 초기 전송 350KB·화면별 250KB 기준을 유지합니다. 선택 후 로드되는 표는 전체 의존성을 포함해 원본 100KB·전송 40KB의 별도 기준을 검사합니다.

## 검증과 출고

수정 전 v0.86.174의 실제 내장 Go 화면에서 산점도 201건 중 표는 최근 200건만 표시하고, 가장 오래된 요청은 마우스로만 접근할 수 있음을 재현했습니다. 수정 후 검사는 전체 버퍼 페이지·임의의 페이지 간 선택·전체 선택·새 응답 선택 초기화·자동 갱신 일시 정지와 재개·상세 초점 복귀·늦은 표 코드 로드를 포함합니다. 밝은/어두운 테마와 1440/390px 화면의 긴 값·접근성·시각 회귀도 검사합니다.

v0.86.175 개발 후보입니다. 후보 CI와 리뷰·실제 메인 CI·공개 배포 파일 검증은 v0.86.174 공개 이후 순차 진행합니다. XView 범위를 넘는 접근성 인수와 운영 Stable 승격, 전체 Phase 0–6 목표는 계속 진행합니다.
