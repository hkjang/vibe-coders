Universal Enterprise API Proxy Gateway

Functions as a universal enterprise API gateway managing all internal API traffic beyond AI coding tools.

• Dynamic Routing: Dynamic multi-upstream branch routing based on X-Proxy-Provider headers
• AES-GCM Encryption: Secure AES-256 GCM encrypted storage of upstream API keys
• High Availability & Fallback: NDJSON rolling audit recovery (/admin/fallback), health checks (/health, /ready)
• API Access Control: Proxy API Key hash management and IP-based Rate Limiting

// Dynamic Upstream Provider Routing
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Authorization: Bearer vbe_live_key_98a7" \
  -H "X-Proxy-Provider: anthropic-production" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-3-5-sonnet","messages":[{"role":"user","content":"Hello"}]}'

Secret Firewall & Live Quota Control

Datadog-Grade LLM Observability & Prompt Compare

Monitors prompt performance and expenses from an engineering perspective.

Single `/mcp` Unified Gateway

Consolidates distributed upstream Model Context Protocol (MCP) servers into a single endpoint.

• JSON-RPC 2.0 Support: Single /mcp endpoint multi-MCP routing
• Tool Namespace Isolation: Automated <upstream>__<tool> prefixing without tool name collisions
• MCP Policy: Allowlist/denylist policy management and user-attributed telemetry integration
